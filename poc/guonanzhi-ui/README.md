## L1 大地图（R16 新增，手绘雏形）

- **入口**：`http://localhost:8399/l1.html`（纯 ES Module，**零 CDN 离线可用**，无需联网）
- **画风**：三国群英传7 参考——程序化手绘地形（36 条现实山脊晕染/雪线/5 河流/海浪）+ 13 城手绘小景（平安金融中心/东京塔+富士山/悉尼歌剧院等）+ 墨漆描金匾额
- **走查清单**：
  1. 加载序幕 → 全景铺开，13 城全可见，四阵营色正确；
  2. 滚轮缩放（指向性）+ 拖拽平移 + 右下「全景」复位；
  3. 悬停城市 → tooltip（阵营/note/驻守武将）；
  4. 点击深圳 → 右侧城市面板（4 将+初始建筑）→「进入城市内景」→ 跳转 index.html（L2 雏形）；
  5. 地理抽检：太行/秦岭/青藏/长江黄河走向、台湾中央山脉、日本飞驒+富士山、澳洲内陆红心（北移 +18° 后仍在澳本陆内）；
  6. 15 条邻接线四样式区分（内陆实线/跨海蓝虚/架空红虚/远洋金点）。
- **已知可迭代项**（等院长反馈）：澳洲北移幅度（`map-data.js` 的 `AU_SHIFT`，0=真实位置）、雪原/沙漠质感、城市图标精细度、缩放分级标签

## 走查清单（院长验收路径，对应施工单 §六）

1. 打开页面 → 深圳HUD + 网格城市，资源数字正确（金5000/粮3000/军力500/能源0/生产资料1000/生产力+20/回/科技+5/回）；
2. 「👁 网格」开关切换网格线显隐，建筑不受影响；
3. 建造一座公园：选中卡 → 幽灵放置（绿/红反馈）→ 预览弹窗（宜居+2 · 半径1格 + 资源变化）→ 确认 → 金/生产资料扣减 → 建造中 0/1 → 下一回合 → 建成 toast；
4. hover 公园显示圆形覆盖圈；hover 山/河/海/丘显示具名机制提示（梧桐山/深圳河/伶仃洋/深圳湾/莲花山…）；
5. 当回合拆掉刚建成的公园 → 明细显示全额无损返还，资源回滚一致；
6. 建造中拆钢铁冶炼厂 → 返还 9 成生产资料；停工→复工链路可走通；
7. 点击市政府 → 血条 100% 弹窗，无拆除按钮（莲花山就在它东侧）；
8. 把金花到不足 400 → 选商业中心 → 确认按钮禁用并显示差额红字；
9. 点击边界外格子/地形格放置 → 「此处不可放置」；
10. 城市下拉其余 12 城禁用；「返回大地图」弹提示；
11. 放置模式下把幽灵建筑压到海/河/山/丘格 → 红色非法。
