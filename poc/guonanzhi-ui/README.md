# 国男志 · 深圳城市内景 UI 雏形（R-059）

> 定位：**界面雏形**——假数据、不接任何游戏逻辑，验证 L2 城市内景的布局/交互/信息密度。
> 规格：[UI雏形施工单-深圳首城v1.md](../../prd/01-需求文档/08-国男志/07-技术架构/UI雏形施工单-深圳首城v1.md)（v1.2）

## 打开方式（二选一）

1. **双击 `index.html`**（需联网加载 Vue CDN）；
2. 本地静态服务：在 `poc/guonanzhi-ui/` 目录执行 `python -m http.server 8399`，浏览器开 `http://localhost:8399`。

## 走查清单（院长验收路径，对应施工单 §六）

1. 打开页面 → 深圳HUD + 网格城市，资源数字正确（金5000/粮3000/军力500/能源0/生产资料1000/生产力+20/回/科技+5/回）；
2. 「👁 网格」开关切换网格线显隐，建筑不受影响；
3. 建造一座公园：选中卡 → 幽灵放置（绿/红反馈）→ 预览弹窗（宜居+2 · 半径1格 + 资源变化）→ 确认 → 金/生产资料扣减 → 建造中 0/1 → 下一回合 → 建成 toast；
4. hover 公园显示圆形覆盖圈；hover 山/河/海/丘显示具名机制提示（梧桐山/深圳河/伶仃洋/深圳湾/莲花山…）；
5. 当回合拆掉刚建成的公园 → 明细显示全额无损返还，资源回滚一致；
6. 建造中拆钢铁冶炼厂 → 返还 9 成生产资料；停工→复工链路可走通；
7. 点击市政府 → 血条 100% 弹窗，无拆除按钮（莲花山就在它东侧）；
8. 把金花到不足 400 → 选商业中心 → 确认按钮禁用并显示差额红字；
9. 点击边界外格子/地形格放置 → 「此处不可放置」；
10. 城市下拉其余 12 城禁用；「返回大地图」弹提示；
11. 放置模式下把幽灵建筑压到海/河/山/丘格 → 红色非法。
