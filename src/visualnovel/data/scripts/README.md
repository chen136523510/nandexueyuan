## 我要改某句台词，怎么做？

1. 找到对应幕的文件（见下方文件清单）
2. 用编辑器打开，找到那句话（行末有说话人注释帮你定位）
3. 改 `text:` 后面引号里的内容
4. 保存 → 刷新浏览器（`localhost:4396`）→ 看到新台词了

**就这么简单。不用改任何其他文件。**

## 三种写法

### 1. 普通台词（最常见）

```js
{ id: 'pro_011', text: '到了啊。路上怎么样——哦不对，传送没"路"可说。' },  // 院长
```

- `id` 是节点编号，**不要改**（改了游戏找不到这句对应的位置）
- `text` 是显示的台词，**随便改引号里的内容**
- 行末 `// 院长` 是说话人注释，给你看的，改内容时不用管

### 2. 玩家名字（自动替换）

```js
{ id: 'pro_126', text: '{playerName}。好，就叫你{playerName}。那——{playerName}。' },
```

- 文案里的 `{playerName}` 会自动替换成玩家输入的名字
- 你写多少个 `{playerName}` 就替换多少个，不用担心

### 3. 选项文案

```js
{
  id: 'pro_choice_1',
  choices: [
    '如果合作能保护城邦，我同意',               // A
    '我连这个世界名字都没记住，谈什么"合作"',   // B
    '睿帝想要草原，为什么让他要？他是什么人',   // C
    '草原的人自己怎么想',                       // D
  ],
},
```

- 选项是**按顺序**对应的，**不要打乱顺序**（打乱了会选错分支）
- 只改字符串内容，不要增减选项数量
- 选项是"标黄还是标白""选完推进还是返回"这些逻辑，在 `prologue.js` 里，不用你管

### 4. 输入框提示（命名场景）

```js
{ id: 'pro_125', text: '那么，你叫什么名字？', placeholder: '输入你的名字' },
```

- `placeholder` 是输入框里灰色的提示文字，也可以改

## 别碰的文件

| 文件 | 作用 | 为什么别动 |

| `../prologue.js` | 剧本逻辑骨架（背景图/立绘/跳转/好感度/分支条件） | 改了文案不会生效，还可能改坏游戏逻辑 |

那是 `prologue.js` 的事，告诉 AI 来改。

## 常见问题

**Q：我改了文案，刷新没生效？**
A：检查三件事：①文件保存了吗 ②改的是不是 `text:`/`choices` 里的内容 ③`id` 没被误改。如果都对了还
不生效，按 `Ctrl+Shift+R` 强制刷新（清缓存）。

**Q：我想加一句新台词？**
A：这涉及改逻辑（新增节点 + 跳转链），不是纯文案操作。告诉 AI 你想在哪儿加什么，让 AI 在
`prologue.js` 加节点 + 在对应 script.js 加文案。

**Q：为什么用 `.js` 不用 `.md` 或 `.json`？**
A：`.md` 不能被代码直接读取；`.json` 不支持写注释，你改文案时看不到"这句是谁说的"。
`.js` 能写注释、能被代码 import，两全。
