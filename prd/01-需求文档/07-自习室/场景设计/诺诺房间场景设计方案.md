## 一、院长设计裁决记录

### 一轮（2026-10-06 上午，十条原话要点）

简约温馨房间；观众视角左侧桌子+面向右侧的笔记本（无线键鼠、笔记本支架抬高）；桌前人体工学椅；**桌椅高度契合诺诺身材（坐椅脚踩地膝 90°、视线与屏幕齐平）**；右侧柔软的床无床底有被子枕头、床头贴墙有床头板、床尾距椅"两三个人"；床右侧窗户窗外沙滩大海（独栋别墅二楼）；床头墙上 MyGO 海报；靠近观众左右各一门（左=出房间、右=独立卫浴）；天花板有灯。

### 二轮（2026-10-06 下午，11 条裁决，本版已全部落实）

1. **窗户在北墙**，窗底=诺诺坐床上的胸部高度，可把手搭在窗沿
2. **床头朝向东墙**（床沿北墙向西展开）
3. **左门在西墙**南端（左下角）
4. **右门在东墙**南端（右下角）
5. **海报在东墙**床头正上方
6. **鼠标在键盘右边**（左键右鼠）→ 按诺诺右手边=北侧布置
7. **人体工学椅可随意伸缩高度**，建模时调整即可（图纸值 0.556 仅作推导基准）
8. **支架做不到就上机械臂连显示屏，桌下放主机机箱** → v2 已切换为显示屏+机械臂+主机方案（支架矛盾解除，笔记本方案备档）
9. **显示屏微侧**让观众看到部分；**椅子微侧**让观众看到更多侧颜；"全景"=布局矩形、观众视角呈上短下长梯形（**一点透视效果，房间实际矩形**）
10. 资源已提供（见 §五）
11. 疑问尽管提出 → 见 §四

## 二、诺诺实测身体数据（v7 模型，页面 `__poc` 钩子量取，2026-10-06）

> 场景家具高度**以实测为准**，不用人类统计比例——诺诺是动漫比例（长腿），估算会错 10cm+。

| 部位 | 实测值（m） | 说明 |
|---|---|---|
| 站姿眼高 | **1.535** | head 骨 1.475 + lookAt offsetFromHeadBone 0.06 |
| 髋关节高 | 0.964 | leftUpperLeg 关节 |
| **膝关节高** | **0.556** | leftLowerLeg 关节（真人比例约 0.42——诺诺腿长 +13cm） |
| 踝高 | 0.098 | leftFoot 关节 |
| 头顶 | ≈1.59 | head 骨 +0.115 估算（形象设定 165cm，模型实测略矮，以实测为准） |
| 大腿长 | 0.409 | 髋→膝 |
| 小腿长 | 0.458 | 膝→踝 |
| 上臂/前臂 | 0.214 / 0.200 | A-pose 实长 |

**推导的家具尺寸**：

| 家具参数 | 推导值 | 推导逻辑 |
|---|---|---|
| **椅面高** | **0.556**（可伸缩） | 脚掌踩地+小腿垂直+大腿水平 → 椅面=站姿膝高 |
| **坐姿眼高** | **1.127** | 椅面 0.556 +（站姿眼高 1.535 − 髋关节 0.964） |
| **桌面高** | **0.72** | 坐姿肘高 0.742 取整 |
| **窗台高** | **0.72** | =床垫 0.45 + 坐床胸段 ≈0.27（"坐床胸部高度"，区间 0.61~0.85 取中，建模时可微调） |
| 屏幕中心高 | 1.127 | =坐姿眼高（机械臂任意高度可达成，一轮的支架矛盾解除） |
| 椅座深 / 椅背顶 | ≈0.40 / ≈0.96 | 大腿长 0.409 / 椅面+坐姿肩高 |

## 四、院长裁决关闭记录（2026-10-06 三轮）

1. **孤独摇滚海报先不使用**（图上未画，素材留档 `资源/`）
2. **窗台 0.72 等数值：先建模看效果再调整**——白盒已按推导值落地，效果验收后微调
3. **屏/椅微侧角度无所谓：诺诺后续会自己调整角度，我们做的是给她行动力和行动指南**——架构级确认：朝向/姿态不由场景钉死，由大脑语义调用小脑配方决定（锚点/affordance 由场景提供，与施工图 §4.3 语义层同构）
4. 灯效按低饱和暖色 RGB 处理（防光污染破坏简约温馨基调）
5. **继续** → 白盒施工完成（§八）

## 六、技术路线（免费组合优先，成本纪律）

- **白盒先行**：第一版用 three.js 程序化几何按 §三坐标摆房间+家具占位，先验证**构图/机位/透视梯形/诺诺比例**，定稿后再上真资产
- **家具资产**：床/桌/椅/显示屏/机箱 Blender 自建低模为主；人体工学椅可找 CC0 改
- **材质贴图**：Poly Haven / ambientCG CC0；海报直接用 `资源/` 图片做贴图
- **窗外海景**：天幕+程序化海面（three.js Water）或 CC0 全景贴图
- **光照**：北窗主光+天花板暖光补光；角色 MToon 与房间材质分光照组
- **交互**：坐椅子=hips translate+腿部 bend+座位锚点（小脑配方）；看书/打瞌睡等=Phase B 场景化配方清单，全部过六关 gate
