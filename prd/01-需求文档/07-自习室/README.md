## 二、理念：为什么是"大脑 + 小脑"

核心理念一句话（R-058 立项原话）：

> **诺诺是 LLM 大脑自主调用程序执行动作的独立个体，而非被安排的木偶。**

类比机器人行业（院长 2026-10-04 提出）：AI 公司在做大脑（LLM 决策），宇树机器人做小脑（运动生成与执行）。诺诺同样分三层，各层职责清晰、接口唯一：

| 层 | 是什么 | 现状 |
|---|---|---|
| **大脑** | nonoAgent（LLM）：感知弹幕 → 思考 → 产生情绪与意图 → **语义调用**动作；三层记忆（L1 认知/L2 会话/L3 长期） | 直播间形态已上线 v4.1.0（文字互动+记忆实测命中），深化中 |
| **小脑** | 动作运行时：把大脑的语义调用变成骨骼运动，管混合/叠加/打断/心跳 | **施工图已定稿，Phase A 施工中** |
| **身体** | VRM 模型：Humanoid 骨骼 + 表情 morphTarget + SpringBone 头发物理 | 渲染管线 PoC 通过，v7 贴片眼定版 |

三层之间**只通过接口耦合**：大脑→小脑=语义调用；小脑→身体=每帧骨骼驱动；小脑→大脑=完成/打断事件回调。任何一层内部重构不影响其他层。

## 三、"语义到动作"的理念（小脑的核心思想）

传统动画是"动画师排好的时间线"，诺诺的动作是"大脑每一拍自主决策的执行语言"：

1. **基元只有三种**：平移 / 弯曲 / 旋转——骨骼上的原子操作（姿态是合成结果，不是基元）
2. **动作 = 配方**：提前编排好的基元序列，带名字和参数——〔背手〕= 旋转大臂 + 弯曲前臂，角度多少、左手在上还是右手在上，都是参数
3. **clip = 配方的编译产物**：动捕数据（摄像头表演→GVHMR）编译成基元组合，对调用方与手写配方完全一致
4. **LLM 只说语义，永远不碰关节**："她感到伤心" → 情绪映射表查出〔失落表情 + 垂肩配方 + 呼吸变慢〕，一次调用多通道齐发
5. **一切可打断**：150ms 补间平滑滑变、无残姿——**木偶播完整段动画，个体会做一半放下手来回应你**；诺诺做动作时仍在思考，可以中途决定不做了
6. **心跳层永远在跑**：呼吸/眨眼/idle 微晃常驻，诺诺没有静止帧
7. **清冷人格 = 参数**：intensity 幅度上限、微动作频率分布——性格差异落在配置表，不落在引擎

完整技术方案见 **[诺诺小脑架构设计（施工图）](诺诺小脑架构设计.md)**。
