## 一、现状诊断

### 1.1 涉及两个组件

| 组件 | 用途 | 当前 UI |
|------|------|---------|
| **MapPanel.vue** | 世界地图全屏面板（手动查看 / 剧情演出高亮地点） | 全屏暗色遮罩 + 居中地图图片 + 高亮地点用**脉冲圆圈**（3 层动画环）+ 纯文字标签 |
| **HotspotLayer.vue** | 场景内自由探索热点（序章结束/探索态） | 背景图上叠加**圆形脉冲按钮**（暖金光环 + emoji 图标 + 文字标签） |

### 1.2 院长反馈

> "地图系统的UI设置，现在就靠坐标一个圈不好看。调研一下，我希望有类似艺术字和路标UI"

### 1.3 核心问题

1. **脉冲圆圈太通用**：地图高亮和场景热点都用同一种脉冲圆圈，缺乏辨识度和奇幻感
2. **地名标签太朴素**：纯文字 + 半透明黑底 + 圆角，像现代 Web UI 标签，不像奇幻地图标注
3. **缺少"手绘地图"质感**：当前是在一张地图图片上贴 CSS 元素，地图本身有油画质感但 UI 标注完全脱离这个质感
4. **路标元素缺失**：院长明确要"路标UI"，当前完全没有路标/方向指示类的视觉元素

### 1.4 现有数据结构

```js
// locations.js MAP_LOCATIONS（地图地点）
{ x: 25, y: 48, label: '帝桥', ... }  // 百分比坐标 + 文字标签

// locations.js hotspots（场景热点）
{ id, x, y, label, icon, action: {...}, kind: 'exit' }
```

数据结构已就绪（x/y 百分比坐标 + label），UI 层改造不影响数据层。

## 二、行业参考

### 2.1 游戏 / 媒体中的奇幻地图 UI

| 参考 | 风格 | 可借鉴点 |
|------|------|----------|
| **巫师 3 大地图** | 手绘地图 + 地名用花体/哥特体艺术字 + 路标用小图钉/旗帜标记 | 地名艺术字 + 标记图标多样化（不是统一圆点） |
| **上古卷轴 5** | 羊皮纸地图 + 手写地名 + 路径用虚线连接 + 发现地点用图标（城堡/山/城市各不同） | 虚线路径 + 地点图标按类型区分 |
| **艾尔登法环** | 暗色地图 + 金色光点标记 + 地名用古朴衬线体 | 金色标记 + 字体选择 |
| **龙与地下城（D&D）地图** | 羊皮纸手绘 + 罗盘玫瑰 + 路标木牌 + 手写标注 | **路标木牌** + 罗盘 + 手写感 |
| **指环王电影地图** | 旧羊皮纸 + 花体地名 + 路径用红色/金色虚线标注行军路线 | 路径动画 + 花体字 |
| **原神地图** | 区域名称用衬线体浮标 + 地标用图标（不同类型不同图标） | 浮标式标签 + 图标分类 |

### 2.2 "艺术字地名"实现方案

| 方案 | 说明 | 效果 | 成本 |
|------|------|------|------|
| **A. CSS 字体 + 样式** | 用花体/哥特体字体（如 `Cinzel`、`MedievalSharp`），加 text-shadow 光晕/浮雕效果 | 中等 | 低（CDN 引入字体 + CSS） |
| **B. SVG 文字路径** | 地名沿 SVG path 弯曲排列（地图地名常见的弧形排列） | 高 | 中（每个地名需配 path） |
| **C. 图片贴图** | 每个地名用 AI 生成艺术字图片贴上去 | 最高 | 高（每地名出图 + 维护） |
| **D. 混合方案** | 重要城市用图片贴图（C），普通地点用 CSS 花体（A） | 高 | 中 |

### 2.3 "路标 UI"实现方案

| 方案 | 说明 | 效果 | 成本 |
|------|------|------|------|
| **A. CSS 木牌路标** | 用 CSS `clip-path` / `border` 模拟木质指向牌，箭头形状，地名写在牌上 | 中等 | 低 |
| **B. SVG 路标** | 内联 SVG 画木牌/路标（含木纹、钉子细节），地名文字嵌入 | 高 | 中（SVG 绘制） |
| **C. 图片路标** | AI 生成路标木牌图片，作为背景图叠加在地图上 | 最高 | 高 |
| **D. 图标 + 标签组合** | 地点用差异化图标（城市🏛/山脉⛰/森林🌲/学院🏫），配合花体地名标签 | 中等 | 低 |

## 三、方案建议

### 方案一：CSS 花体地名 + SVG 路标图标（推荐，性价比最高）

**核心思路**：不用图片贴图（维护成本高），纯 CSS + SVG 实现奇幻地图标注风格。

**地名标签改造**：
- 字体：引入 `Cinzel`（拉丁哥特体，Google Fonts 免费）或 `MedievalSharp`，配合中文用霞鹜文楷
- 标签样式：从"半透明黑底圆角矩形" → "羊皮纸卷轴标签"
  - 背景：`linear-gradient` 模拟旧纸色（`#e8d5a8` → `#d4c08a`）
  - 边框：`border: 1px solid #8b7355`（旧金色边）
  - 两端用 CSS `::before` / `::after` 做卷轴端饰（小圆点或三角）
  - 文字：深棕色 `#3d2b1f` + 微 `text-shadow` 浮雕
- 高亮态（剧情演出）：标签发光 + 底部出现金色脉冲底线（替代当前的脉冲圆圈）

**地点标记改造**：
- 从统一脉冲圆圈 → 差异化 SVG 图标
  - 城市/据点：🏰 城堡图标
  - 学院（男德学院）：🏫 / 魔法塔图标
  - 山脉：⛰ 山峰图标
  - 河流/桥：🌉 桥图标
  - 当前位置：指南针/箭头图标
- 所有图标用 SVG 线条风格，暖金色 `#c9a96e` 描边
- hover 时图标放大 + 发光

**路标元素**（HotspotLayer 场景出口）：
- `kind: 'exit'` 的热点从脉冲圆圈 → **木质路标箭头**
  - CSS `clip-path: polygon(...)` 画箭头形状
  - 木色渐变背景 + 深色边框
  - 地名写在箭头牌上，字体用花体
  - 指向出口方向（可根据 x 坐标判断箭头朝左/右）

**路径连线**（可选增强）：
- 已解锁的地点之间用 CSS 虚线连接（`border-top: 2px dashed rgba(201,169,110,0.4)`）
- 模拟手绘地图的行军路线

**预估工作量**：2-3 天（字体引入 + 标签 CSS + 5-6 个 SVG 图标 + 路标 CSS + 测试）

**优点**：
- 纯 CSS/SVG，无图片依赖，维护简单
- 效果可见且可迭代
- 数据结构不变，只改渲染层

**缺点**：
- 纯 CSS 模拟材质有上限，不如真实贴图精致

---

### 方案二：AI 生成地图标注贴图（最精致，工作量大）

**核心思路**：用 Seedream 生成一套奇幻地图标注素材（路标木牌、艺术字地名、地点图标），作为图片贴在地图上。

**素材清单**：
- 5-6 个地点图标（城市/学院/山脉/河流/森林/当前位置），透明背景 PNG
- 路标木牌 ×2-3 种（左箭头/右箭头/双向），透明背景 PNG
- 通用艺术字地名底框（透明背景，文字用 CSS 叠加），1 张即可
- 罗盘玫瑰装饰（地图角落），1 张

**技术实现**：
- 图片放 `public/visualnovel/map/markers/`
- MapPanel / HotspotLayer 按 type 加载对应图标图片
- 地名文字仍用 CSS 叠加在底框图片上（避免每个地名都出图）

**预估工作量**：3-5 天（AI 出图 + 抠图 + 入库 + 代码接入 + 调试）

**优点**：
- 视觉效果最好，真实材质感
- 与地图本身的油画风格统一

**缺点**：
- 出图 + 抠图工作量
- 后续新增地点类型需补图
- 图片管理成本

---

### 方案三：混合方案（推荐路径）

**核心思路**：方案一打底（CSS 花体 + SVG 图标），关键元素用方案二补充图片。

**分层实施**：

| 层 | 实现 | 内容 |
|----|------|------|
| 地名标签 | CSS | 花体字体 + 羊皮纸卷轴样式（所有地名通用） |
| 地点图标 | SVG | 5-6 种类型化图标（线条风，暖金描边） |
| 路标出口 | CSS | 木牌箭头 `clip-path`（场景热点出口） |
| 罗盘装饰 | **图片** | AI 生成 1 张罗盘玫瑰，放地图角落（点睛之笔） |
| 路径连线 | CSS | 虚线连接已解锁地点（可选） |

**预估工作量**：2-3 天（CSS/SVG 为主）+ 1 张图（罗盘，黑机出图）

**优点**：兼顾效果和工作量，CSS 部分可快速迭代，图片只做点睛

## 四、推荐路径

| 步骤 | 内容 | 前置 |
|------|------|------|
| 1 | 院长从方案中选定方向（推荐方案三混合） | 本报告 |
| 2 | 引入花体字体（Cinzel / MedievalSharp）+ 霞鹜文楷，出地名标签 CSS 样式原型 | 方案选定 |
| 3 | 找/画 5-6 个 SVG 地点图标（城市/学院/山脉/河流/森林/当前位置） | 标签定稿 |
| 4 | 路标木牌 CSS（HotspotLayer 出口热点） | 图标定稿 |
| 5 | 罗盘装饰图片（黑机出图，白机先留占位） | 主体完成 |
| 6 | 浏览器实测 + 院长验收 | 实现完成 |

**我的建议**：选**方案三（混合）**。理由：
1. CSS/SVG 为主，可快速出原型给院长看效果
2. 罗盘图片只 1 张，不依赖黑机出图也能先完成主体
3. 后续如效果不足，可逐步用 AI 图片替换 CSS 元素（渐进增强）

## 五、字体选择参考

### 拉丁文花体（地图地名/装饰）

| 字体 | 风格 | CDN | 适合场景 |
|------|------|-----|----------|
| **Cinzel** | 罗马碑文风大写，庄重古典 | Google Fonts | 城市名/大区域名（正式） |
| **MedievalSharp** | 中世纪手写体，不规则笔触 | Google Fonts | 手绘地图标注感 |
| **UnifrakturMaguntia** | 哥特黑体，极强风格 | Google Fonts | 标题/装饰（慎用，可读性低） |
| **Pirata One** | 海盗风花体 | Google Fonts | 海盗线相关地点（第四幕） |

### 中文（地图中文地名）

| 字体 | 风格 | CDN | 适合场景 |
|------|------|-----|----------|
| **霞鹜文楷 (LXGW WenKai)** | 手写楷体，古卷感 | jsDelivr（项目已引入） | 所有中文地名 |
| 马善政楷书 | 更正式的楷体 | - | 备选 |

**建议**：拉丁文用 `Cinzel`（庄重 + 可读性好），中文复用项目已有的 `霞鹜文楷`，两者搭配在奇幻地图上效果协调。
