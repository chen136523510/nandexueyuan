## 一、现状诊断

### 1.1 当前实现

| 组件 | 现状 | 问题 |
|------|------|------|
| **QuickMenu** | 左上角竖排 6 个按钮（🎒背包/💾存档/📜回看/▶自动/⚙设置/👁隐藏），emoji 图标 + 文字标签，半透明黑底毛玻璃 | emoji 图标风格不统一（有的彩色有的单色），与奇幻世界观割裂；"原神风格"标签是自评，实际品质差距大 |
| **面板们**（设置/存档/背包/回看） | 统一范式：全屏遮罩 + 居中半透明黑框（`rgba(13,17,23,0.95)`）+ 暖金边框（`rgba(201,169,110,0.2)`）+ 圆角 12px | **"直接用一个框"** -- 院长原话。所有面板长一样，无功能辨识度；黑框太硬，没有奇幻世界的质感 |

### 1.2 核心矛盾

1. **emoji 与世界观割裂**：项目是西方奇幻油画世界观（设定集 v1.4），emoji 是现代扁平卡通风格，放在一起出戏
2. **面板无差异化**：设置面板和存档面板视觉一模一样，玩家缺乏功能直觉
3. **缺少材质感**：当前 UI 是纯 CSS 几何形状（圆角矩形），没有奇幻 UI 应有的材质（羊皮纸/金属/木板/魔法纹路）
4. **设计系统断层**：社区站有完整的莫兰迪 token 体系，VN 页面被标注「🔒 不动」自有设计语言，但实际上这个"自有设计语言"只是零散的硬编码 rgba 值，没有系统化

### 1.3 VN 现有视觉语言提取

从现有组件中提取出一致的视觉元素：

| 元素 | 当前值 | 语义 |
|------|--------|------|
| 主背景色 | `rgba(13, 17, 23, 0.95)` | 近黑深灰，营造暗色氛围 |
| 强调色 | `#c9a96e` (暖金/古铜金) | 奇幻 + 古老感 |
| 文字色 | `#e8e0cc` (暖米白) | 羊皮纸/旧书页文字感 |
| 次要文字 | `#8b95a8` (冷灰蓝) | 旁注/次要信息 |
| 圆角 | 8-12px | 温润不尖锐 |
| 毛玻璃 | `backdrop-filter: blur(4-8px)` | 层次感 |
| 字体 | 系统无衬线（未用霞鹜文楷） | **缺口**：社区站用了霞鹜文楷，VN 没用 |

## 二、行业参考

### 2.1 商业 VN / RPG 游戏菜单设计

| 参考 | 菜单风格 | 可借鉴点 |
|------|----------|----------|
| **巫师 3** | 全屏羊皮纸卷轴展开，手绘纹饰边框，暗色金属铆钉 | 材质感 + 主题统一（所有面板都是羊皮纸变体，但功能区分明确） |
| **博德之门 3** | 暗色石板纹理 + 金色描边，图标用 SVG 勾线风 | 暗色奇幻 + 图标风格统一（全 SVG 线条，非 emoji） |
| **原神** | 左上竖排菜单（当前参考目标），SVG 图标 + hover 展开文字 | 竖排布局本身没问题，问题在 emoji 图标和粗糙实现 |
| **Eternum（永恒世界）** | 顶部横排胶囊菜单，半透明底 + SVG 图标 | 胶囊形菜单 + 图标风格简洁统一 |
| **火焰纹章系列** | 底部菜单栏，纹章风格边框，金色装饰角 | 装饰角元素增强奇幻感 |
| **Fate/stay night** | 底部半透明菜单条，极简文字 + 晶蓝强调色 | 极简方案：不用图标，纯文字 + 字间距 |

### 2.2 图标方案对比

当前用 emoji，这是最大的风格割裂点。替代方案：

| 方案 | 说明 | 成本 | 效果 |
|------|------|------|------|
| **A. SVG 线条图标（推荐）** | 用 stroke 线条勾画（背包/存档/齿轮等），统一 1.5px 线宽，颜色用暖金 `#c9a96e` | 中（需找/画 6 个 SVG） | 与博德之门/原神风格一致，奇幻感强 |
| B. SVG 实心图标 | filled 风格，类似 FontAwesome Solid | 低（图标库现成） | 偏现代 UI 感，奇幻感稍弱 |
| C. 手绘风图标 | 仿羊皮纸手绘风格（ink drawing），不规则线条 | 高（需出图或手画） | 奇幻感最强，但与暗色背景搭配需调试 |
| D. 继续用 emoji | 现状 | 零 | 不推荐，风格割裂 |

## 三、方案建议

### 方案一：暗色奇幻 + SVG 图标精修（推荐，性价比最高）

**核心思路**：保持现有暗色 + 暖金基调，但把"粗糙实现"升级为"精致实现"。

**QuickMenu 改造**：
- emoji 图标 → SVG 线条图标（统一 1.5px stroke，暖金色 `#c9a96e`）
- 按钮形状从纯圆角矩形 → 带装饰角的微盾形（左上/右上微小切角，暗示奇幻盾牌元素，不过度）
- 按钮间距 + 微动画优化（hover 时 SVG 图标颜色提亮 + 底部出现细金线分隔）
- 隐藏状态浮动按钮同样换 SVG

**面板改造（统一框架 + 功能差异化）**：
- 所有面板保留暗色遮罩 + 居中布局（基础范式不变）
- 面板边框升级：从 1px 实线 → 双线边框（外细金线 + 内细暗线，间距 2px），模拟金属镶框
- 面板标题区加装饰：标题左右各一条短金色渐隐线（`─── 标题 ───`），用霞鹜文楷 display 字体
- 面板内部按功能微调：
  - 设置面板：滑块用暖金色 accent，开关按钮改为拨杆式
  - 存档面板：槽位卡片加左侧色条（自动存档金色 / 手动蓝色）
  - 背包面板：物品格用细金线网格，已有
  - 回看面板：对话记录用左侧竖线时间轴

**字体**：VN 面板标题引入霞鹜文楷 `--md-font-display`（社区站已有 CDN 加载），统一古卷学院感。

**预估工作量**：1-2 天（SVG 图标找/画 6 个 + 面板 CSS 精修 + 测试）

**优点**：
- 不改架构，纯 CSS + 图标替换，风险低
- 即刻可见效果提升
- 与现有暗色 + 暖金基调完全兼容

**缺点**：
- 本质还是"精致版方框"，材质感有限（没有羊皮纸纹理等）

---

### 方案二：羊皮纸/古卷材质风格（奇幻感最强，工作量大）

**核心思路**：所有面板改为羊皮纸/古卷视觉，与世界观设定集的"古老魔法世界"主题统一。

**QuickMenu**：改为竖排卷轴条样式，每个按钮像一个小印章/蜡封。

**面板**：全屏展开时背景从黑色遮罩 → 暗色羊皮纸纹理（CSS 生成或贴图），边框为仿手撕边缘 + 金色纹饰角（四个角的装饰花纹）。

**技术实现**：
- 羊皮纸纹理：CSS `radial-gradient` + `noise` 模拟，或用一张小尺寸羊皮纸纹理图 repeat
- 装饰角：SVG 内联或 CSS `border-image`
- 字体全部用霞鹜文楷

**预估工作量**：3-5 天（纹理调试 + 装饰元素 + 全面板适配 + 响应式）

**优点**：
- 奇幻沉浸感最强
- 与世界观高度统一

**缺点**：
- 工作量大
- 羊皮纸在暗色 VN 场景中需要精心调试明暗对比，否则文字可读性下降
- 后续新增面板都要遵守这套材质规范，维护成本高

---

### 方案三：极简文字菜单（最快，风格统一但朴素）

**核心思路**：放弃图标，纯文字 + 字间距 + 装饰线，类似 Fate/stay night 的底部菜单条。

**QuickMenu**：底部居中横排，纯文字（背包 / 存档 / 回看 / 自动 / 设置 / 隐藏），用霞鹜文楷，字间距加大，hover 下划金线。

**面板**：保持暗色遮罩，面板边框极简化（只保留底部金线），标题用 display 字体。

**预估工作量**：0.5 天

**优点**：极快、风格统一、无图标依赖
**缺点**：不够"有设计感"，可能不符合院长对"好看"的期待

## 四、推荐路径

| 步骤 | 内容 | 前置 |
|------|------|------|
| 1 | 院长从三个方案中选定方向 | 本报告 |
| 2 | 找/画 6 个 SVG 线条图标（背包/存档/回看/自动/设置/隐藏），先出草图给院长过目 | 方案选定 |
| 3 | QuickMenu + 面板框架 CSS 精修 | 图标确认 |
| 4 | 各面板内部功能差异化 CSS | 框架定稿 |
| 5 | 浏览器实测 + 院长验收 | 实现完成 |

**我的建议**：选**方案一**。理由：
1. 性价比最高 -- 不改架构，纯视觉升级，1-2 天可见明显效果
2. 风险最低 -- 暗色+暖金基调不变，不会出现"改完更丑"的情况
3. 可渐进 -- 先做 QuickMenu + 面板框架，效果满意再逐个面板精修内部
4. 如果方案一效果院长仍不满意，再升级到方案二（羊皮纸材质）也只是在方案一基础上加纹理，不浪费工作
