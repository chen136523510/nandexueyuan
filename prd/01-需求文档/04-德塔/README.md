## HUD 布局（R-010 五栏）

```
[角色信息 180px] [装备+技能槽 160px] [背包 160px] [聊天 flex:1] [小地图 146px]
```

- **角色信息**：头像（点击打开角色面板弹窗）/ 昵称 / HP 条 / MP 条 / buff 槽
- **装备+技能槽**：2行×4列 → 第一行装备（头/胸/腿/靴），第二行技能（1/2/3/4）
- **背包**：4列×2行 = 8 格
- **聊天**：消息列表 + 输入框
- **小地图**：130×90 canvas

## 角色面板弹窗（博德之门风格）

点击 HUD 头像打开，三栏布局：
- **左侧**：当前形象完整立绘
- **中间**：5 格装备栏（武/头/胸/腿/靴）+ 属性面板（基础值）
- **右侧**：8 格背包网格

2. 部署脚本：`deploy.sh`（种子数据 + 版本公告）
