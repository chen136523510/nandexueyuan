## 第一章 世界基调

### 1.1 双重交织 `[锁定]`

德塔世界观由两种看似矛盾的基调编织而成：

**第一重：外部世界 = 黑深残**

虚空裂隙撕裂世界，怪物横行，文明虽未完全灭亡但深受重创。土地被腐蚀，幸存者在绝望中挣扎。空气中弥漫腐化气息，大地龟裂出散发幽光的裂隙。

- 腐败无处不在：土地、水源、生物甚至记忆都在被缓慢腐蚀
- 文明虽存续但残破：几大势力勉强维持，但虚空仍是悬在头顶的剑
- 怪物是常态：不是突然入侵的敌人，而是世界的"新生态"
- 绝望感渗透日常：人们已忘记"没有虚空的世界"是什么样子

**第二重：冒险小队 = 戏谑反差**

约20名来自"男德学院"的成员闯入这个世界。他们不是苦大仇深的救世主，而是一群"来都来了，干一票"的冒险者。在黑暗得令人窒息的世界里，这20个人吵吵闹闹地存在，本身就是极其诡异的画面。

**核心原则：笑点不消解悲壮，戏谑不践踏严肃。**

### 1.2 核心母题 `[锁定]`

**探险与改造 = 把黑深残的世界一点点变成适合生存的地方。**

这不是一条主线任务，而是一个长期的世界状态变化。男德学院净化虚空、建立根据地、收容难民，给玩家持续探索的动力。

### 1.3 虚空的本质与净化原理 `[锁定]`

> **本节是世界观的底层支柱**，解释了"为什么118年来没有任何势力能彻底清除虚空""为什么只有男德学院能净化"。所有势力设定、剧情逻辑、学院独特性的根源都在这里。

#### 1.3.1 三位面与裂隙的本质

本世界存在**三个位面**：

| 位面 | 说明 |
|------|------|
| **异世界位面** | 本故事的舞台。玩家所见的大陆、海洋、各国均在此位面 |
| **虚空位面** | 与异世界相交的另一维度。虚空生物、虚空能量均源自此处 |
| **地球位面** | 男德学院（玩家）的来源。第三位面，与前两者均不同源 |

**裂隙 = 位面相交的空间虫洞**：A.V.0 虚空降临，本质是异世界位面与虚空位面发生碰撞/相交，产生大量空间虫洞（即"裂隙"），使两个位面相通，虚空生物涌入异世界。

#### 1.3.2 同源相交机制（为什么本世界无法根除虚空）

两界相交已达118年，形成**同源相交机制**：异世界与虚空位面在长期接触中已深度耦合，无论是本世界的**魔法**（帝国）还是**科技**（共和国），都属于"同源"力量——它们源自这两个已相交的位面之内，因此**注定无法彻底关闭裂隙**，只能限制、封锁、利用。

> 这就是创作铁律第2条的底层原因：各国手段（驻兵/科技灭杀/蓝网/据点防守）都只是"限制"，不是"根除"。不是它们不够强，而是**同源力量在原理上就无法切断同源连接**。

#### 1.3.3 学院净化原理：异质充能缝合裂隙 `[锁定]`（v1.4 修订）

> ⚠ **v1.4 重大修订**：原 v1.3 设定为"地球人存在即净化"（辐射式）。院长 2026-07-30 修订为**"需通过虚空晶石充能"**机制——解决"地球人需分居世界各地才有效"的逻辑漏洞，使机制更合理、更具游戏性。

男德学院来自**地球（第三位面）**，与前两个位面均不同源。地球人本身携带一种**位面层面的异质能源**（与生俱来，非具体物品）。

**但异质能源不是"存在即辐射"，而是需要载体——虚空晶石。** 净化裂隙的完整流程：

1. 地球人将自身携带的异质能源**充入虚空晶石**（详见 1.3.5）
2. 充能后的晶石部署在裂隙旁 / 塔楼核心
3. 异质能源在晶石中缓释，介入异世界与虚空位面的接口之间
4. 产生类似**水油分层**的效果——两个同源相交的位面被第三位面的异质属性隔离
5. 位面接口被分层切断 → 裂隙被**缝合** → 该区域虚空被净化

> **关键区分（创作铁律）**：
> - 本地人（帝国/共和国/汪神）也能给晶石充能，但他们的能源与虚空**同源**，只能消灭虚空生物、驱动装置，**对裂隙无效**
> - 只有地球人的**异质充能**才能缝合裂隙——这是"同源相交机制"（1.3.2）的直接推论
> - 地球人的魔法是**在异世界学来的**（同源力量），用于战斗；缝合裂隙靠的是**异质充能**，两者是不同的东西。玩家可以选择不学魔法，但依然能缝合裂隙

#### 1.3.4 虚空的真相：虚空女皇与层级结构 `[锁定]`

虚空并非纯粹的混沌与无意识。以下是被观察到但尚未被完全理解的现象：

- **虚空位面存在高智生物**：虚空生物并非全部无理智。存在一个层级结构——低级虚空生物受高级虚空生物的遥感指挥，呈现协调行动
- **虚空女皇**：虚空位面的最高意志/统治者。长期隐藏，当异世界残留裂隙足够多（关闭率 <30%）时，她能**降临异世界**，是末日级威胁（详见第十章结局 3）
- **虚空女皇的能力**：能感知到威胁虚空存在的人（如掌握蜂巢思维的沐阳），并派出精锐虚空生物猎杀
- **⚠ 虚空位面可能与地球位面也存在某种未知的联系**（长期悬念，待主线展开）
- 这是世界观最深层的悬念之一

#### 1.3.5 虚空晶石：能源载体 `[锁定]`（v1.4 新增）

虚空晶石是裂隙的副产品（裂隙活动时析出的结晶体），也是**异世界各国的公共能源基础**。

**各国对晶石的应用（本地充能，同源能源）**：

| 势力 | 应用方式 | 效果 |
|------|---------|------|
| 睿意志帝国 | 晶石作为**魔法驱动力** | 驱动魔法阵、魔法屏障、民用魔法 |
| 民主共和国 | 晶石作为**类电物质** | 为科技装置充能（虚空步枪、灭杀系统） |
| 海盗联合王国 | 汪神用**阵法+魔法回路**充分激发晶石 | 形成"蓝网"系统，防住海域虚空 |

> **关键**：以上三种应用，晶石充入的都是**异世界同源能源**，因此**只能消灭虚空生物**，攻击虚空裂隙时没有反应。

**地球人的异质充能（核心差异）**：
- 地球人将自身异质能源充入晶石后，该晶石能**缝合裂隙**
- 这是全大陆118年来从未有过的能力，只有男德学院成员能做到
- 充能过程需要地球人**贴身长时间携带/冥想注入**（非即时），持续输出异质能源对身体是**慢性透支**

**充能代价（叙事核心） `[锁定]`**：
- 长期持续输出异质能源，对地球人的身体造成不可逆的透支
- 这解释了"见"（院长）25岁却少年老成的原因——他充能最久、最猛（3年），透支最严重
- 见的项链（第一次闭合裂隙时掉落的晶石碎片）是这段代价的物证
- **学院净化不是免费的，是用命在换**——这是全作的情感核心

### 2.1 世界形态 `[锁定]`

### 2.2 核心地标：云顶山脉 `[锁定]`

云顶山脉是地图正中心，其存在显著影响世界格局：

| 方位 | 地标 |
|------|------|
| 西 | 睿河（帝国东界） |

| 西南 | 大草原（城邦） |

云顶山脉阻挡水汽，导致东北侧形成大沙漠。

山河走廊原型为**丝绸之路**：是帝国与共和国之间的贸易大动脉，也是帝制战争时期的争议地带。

#### 2.3.1 帝桥（睿帝得意之作）`[锁定]`（v1.4 新增，院长 2026-08-05 定）

> 第一章·第一幕剧情核心道具。设定依据：

1. **本质**：帝桥说是一座桥，其实是**刻满魔法回路的一道平台**，按时按点传送一端到另一端，将多端衔接，构成一座横跨睿河（大河）的快速通道，用于运输人和物品。由魔法师团队定期维护。是**睿帝的得意之作**，**A.V.115（三年前）建成**。
2. **帝桥之前**：草原依托睿河天险，不太畏惧帝国武装。帝国要穿越睿河到草原并不便捷，需依托大量人力物力和魔法资源。
3. **控制力**：帝桥显著提高了帝国对草原的控制力。
4. **便利面**：帝桥也为草原人民提供了便捷——帝国有着更优质的教育、就业、医疗资源。睿帝不限制草原的人进入帝国，因为名义上草原人也是帝国子民。
5. **通行证新政（良民证）**：睿帝最近下发新文件，**限制没有办理通行证的人不得使用帝桥**。通行证类似"良民证"。细则：
   - **一人一证**：通过魔法关联到帝国民本（人口数据库）中的数据。证件上有身份标识，出了事找得到人。
   - **基层发放、效率不高**：颁布通行证依靠基层（村/镇），进度慢，没拿到证的人（如桥上被拦的老人）不允许过桥。
   - **分批发放**：由帝国进行人口普查、风险评估后分批发放。故部分城邦抵触。
6. **学院定位**：在男德学院还未展示实力时，睿帝并不在意草原是否诚信臣服——经济和国力压制足够使草原的人才外流到帝国。但学院的存在、虚空教团的控制使得草原部分城邦蠢蠢欲动。
7. **法刺盲区**：由于身居草原腹地，帝国法刺并没有第一时间察觉到男德学院这股势力。当帝国开始重视时，男德学院已经在国际上有较高知名度了。
8. **第二幕契约（院长 2026-08-06 定）**：帝国派幸携**羊皮卷合同**（有字+魔法印记）赴塔楼谈判——学院若出任草原过渡期的**秩序维持者**，则学院在帝国境内享**治外法权**。契约内容因选择②分支而异（接=帝国合同工；有条件=防卫协约/底线试探/庇护协约/技术协约；不接/拖=未签约）。签约后学院获得道具**草原治属文书**（睿帝亲自颁布，纹满魔法回路）。

> 剧情落点：第一章·第一幕（帝桥）——老人带孩子过桥求医被通行证新政卡住；睿帝令（令牌）> 通行证（核心选择① A 分支亮令牌放行）。

### 2.5 睿意志帝国·地理细化

**地貌**：西北大陆，以平原与丘陵为主，地势西高东低。睿河自北向南纵贯东部边境，是帝国天然边界。

**气候**：温带气候。因虚空裂隙受控率高达90%+，帝国核心区气候稳定、土地肥沃，是全大陆最适宜居住的区域之一。

**裂隙区分布**：
| 区域 | 裂隙密度 | 说明 |
|------|---------|------|
| 帝都周边 | 极低 | 皇家虚空研究院驻地，魔法屏障覆盖 |
| 西北腹地 | 低 | 收复失地计划已清理，残留少量封印裂隙 |
| 东部边境 | 中 | 与山河走廊接壤处，残留裂隙区，驻军把守 |
| 睿河沿线 | 低 | 河流本身是天然屏障，裂隙沿河零星分布 |

**主要城市与据点**：
- **帝都**：帝国政治与魔法中心。睿帝宫廷、皇家虚空研究院、魔法学院均坐落于此。虚空原液民用化枢纽。
- **东部要塞群**：沿睿河修建的军事要塞链，防范共和国+封印边境裂隙。A.V.100睿帝政变后大幅扩建。
- **魔法哨站网络**：A.V.118吞并大草原后，哨站网络扩展至大草原，监控各地虚空裂隙动态。

- **内陆工业城市群**：军工复合体大本营，虚空充能武器生产线。

### 2.7 巴拉巴拉部落·地理细化

**地貌**：云顶山脉东北侧大沙漠，广袤沙丘+戈壁+零星绿洲。西南面被云顶山脉包围，水汽无法进入。

**气候**：极端干旱，昼夜温差极大。但正因如此，虚空裂隙极少——虚空生物不适应沙漠环境。

## 第八章 学院颠覆性分析

### 8.1 人类与虚空共处118年形成的"既有秩序" `[锁定]`

1. **虚空是常态**：裂隙永远存在，只能控制无法根除（**根因：同源相交机制**，详见1.3.2）
2. **各国手段有极限**：帝国驻兵成本高、共和国科技因党争失控、海盗蓝网维护难、草原据点只能被动防守--没有任何手段能主动净化土地。**这不是技术不够强，而是同源力量在原理上就无法切断同源连接**
3. **虚空能量是资源**：帝国靠它繁荣，共和国靠它赚钱（军工），邪教靠它获信徒
4. **魔法是精英特权**（帝国）：平民虽受益但无法接触高阶魔法
5. **科技解决不了根本问题**（共和国）：只能武器化虚空，无法消除虚空
6. **势力平衡脆弱但稳定**：与虚空共存的秩序已维持百年+

### 8.2 学院带来的变量

| 既有秩序 | 学院的颠覆性 |
|----------|--------------|
| 虚空只能限制，无法根除（同源相交） | 学院作为**第三位面（地球）来源**，可通过晶石异质充能缝合裂隙、净化土地（详见1.3.3）。118年来人类从未拥有的能力 |
| 各国手段只能被动防御 | 学院能主动出击净化裂隙（通过晶石异质充能+激发，详见1.3.3），从"避难所"变成"净化者" |
| 虚空能量是稀缺资源 | 学院净化能力可能消除虚空能量稀缺性，威胁帝国垄断和共和国军火市场 |
| 邪教靠虚空崇拜获信徒 | 学院证明虚空可以被战胜，动摇邪教教义根基 |
| 各大势力保持脆弱平衡 | 学院作为新变量打破平衡 |
| 人们已接受"与虚空共存"的绝望 | 学院带来"彻底清除虚空"的希望 |

### 8.3 学院为何"既有颠覆性又具曲折性" `[锁定]`

**各大势力不会欢迎学院**：
- 帝国：净化技术可能削弱虚空垄断优势
- 共和国：军工复合体视学院为威胁
- 虚空教团：学院是教义死敌
- 海盗国：政局混乱，无法判断敌友
- 只有杰可能持开放态度

**但学院也不可或缺**：
- 虚空裂隙仍在，怪物仍在，难民仍在受苦
- 各大势力虽强，但都无法彻底解决虚空问题
- 学院是唯一可以"真正净化"的力量
- 难民会主动涌向学院据点

**学院目标"拯救更多人"**：
- 不参与政治斗争，但必然被卷入
- 净化土地 = 动了帝国的虚空垄断蛋糕、共和国的军火生意、邪教的信仰根基
- 这就是"颠覆性和曲折性"的核心

## 第十章 结局分支框架 `[锁定]`（v1.4 新增 / v1.5 视觉小说适配）

> 结局由**两个独立维度**共同决定：①玩家在剧情中推进的**裂隙净化进度** ②关键人物的生死 + 国际关系调停的**剧情选择结果**。
>
> **视觉小说适配说明**：原 v1.4 的"关闭率百分比"（>90%/30%~90%/<30%）是 2D 游戏时代的数值驱动设计。视觉小说改为——**裂隙净化进度由关键剧情节点的选择决定**（是否去净化某条裂隙、是否花时间充能晶石、是否优先救人而非缝合裂隙），而非数值累积。每个关键选择都会影响最终落在哪一档。

### 10.1 双维度矩阵

| 维度A：裂隙净化进度（剧情选择驱动） | 维度B：关键人物/国际调停状态（剧情选择驱动） |
|---|---|
| **高进度**（主线裂隙基本缝合） | 见/沐阳/丘/汪神/杰 生死 + 帝国-共和国调停 + 部落统一 + 汪神解救 |
| **中进度**（部分缝合，部分搁置） | 同上 |
| **低进度**（几乎未缝合，被各方博弈搁置） | 同上 |

> **如何从视觉小说选择映射到进度档位**：游戏中的关键节点（每章末尾）会给玩家"裂隙相关选择"——比如优先缝合裂隙 vs 优先救人 vs 优先外交斡旋。这些选择的累积结果决定维度A落在高/中/低。维度B则由各人物线的剧情选择直接决定（救了谁、杀了谁、调停了什么）。

### 10.2 结局1：净化进度·高（主线裂隙基本缝合）

**10.2.1 好结局·世界和平** `[锁定]`
- 条件：关键人物全员生还 + 调停帝国-共和国矛盾 + 帮助巴拉巴拉部落统一独立 + 在阿瓦隆救出汪神
- 结果：各国打通贸易线，百姓安居乐业

**10.2.2 坏结局·全面战争** `[锁定]`
- 条件：关键调停失败，国际形势恶化
- 结果：睿帝（联合附属国城邦+巴拉巴拉部落）发动对共和国全面战争，海盗隔岸观火趁机打劫草原和共和国
- 人物后果：**迅病逝**（未被治愈）、**沐阳战死**（救迟/被卡兹克猎杀）、**丘被刺杀**、**汪神被永恒禁锢阿瓦隆**

**10.2.x 中间结局·暗潮汹涌** `[锁定]`
- 条件：部分调停成功，部分失败
- 结果：世界未毁灭但暗流涌动。各分支后果（独立叠加）：
  - 迅和沐阳死亡 → 睿帝暴怒
  - 丘被刺杀 → 共和国高层被虚空教团腐蚀，企图重新撕裂裂隙
  - 汪神未解救 → 海盗王国分裂内战
  - 未调停共和国-部落 → 杰截断山河走廊，与共和国保持战争状态

### 10.3 结局2：净化进度·中（慢性溃烂）

> 这是最危险的国际博弈状态：裂隙没逼死人，但够用来当政治筹码。

**走向推理** `[建议]`（待剧本细化）：
1. **争夺学院**：各国对"唯一能缝合裂隙的男德学院"争夺动机最强。帝国施压（睿帝令伏笔兑现）、共和国软硬兼施、海盗可能直接抢人——学院从"中立调停者"变成"战略资源"
2. **军工复合体反扑**：共和国军工复合体不希望裂隙被完全解决（虚空是军火收入来源），暗中阻挠学院继续缝合，甚至资助虚空教团
3. **虚空教团崛起**：裂隙还在，教团有存在土壤，半缝状态让被遗弃地区的难民更易被极端信仰吸收，教团从恐怖组织升级为有群众基础的势力
4. **部落夹缝**：大草原是裂隙最密集区。杰若统一则切断山河走廊自保阻断贸易；杰若未统一则草原成各方缓冲战场
5. **汪神变量**：解救则稳住南方制衡；未解救则蓝网崩溃南方海域失控

**基调**：不是毁灭，是绝望的日常化——每条线都在恶化，但每国都"还撑得住"

### 10.4 结局3：净化进度·低（末日降临）

**虚空女皇降临** `[锁定]`
- 触发：主线裂隙几乎未缝合，虚空位面能渗透过来
- 虚空女皇在**云顶山山顶降临**，破坏云顶山
- **山河走廊断联**（地理格局剧变）
- **睿河水面上涨**，淹没草原大部分城邦和帝国沿岸城池
- 巴拉巴拉部落元气大伤

**人物后果** `[锁定]`：
- 若未调停部落-共和国 → **杰死于虚空女皇之手**
- **沐阳被反向操控**（试图用蜂巢思维对付虚空女皇级别的意志时被反噬），失去理智
- **丘完全抛弃贫民区**，收归所有人力物力退守共和国东部
- 丘若被刺杀 → 共和国全面沦陷
- 汪神解救则王国隔岸观火；汪神不在则内战 + 蓝网崩溃

**定性**：坏结局，末日级灾难
