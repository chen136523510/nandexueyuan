## 第一章 世界基调

### 1.1 双重交织 `[锁定]`

德塔世界观由两种看似矛盾的基调编织而成：

**第一重：外部世界 = 黑深残**

虚空裂隙撕裂世界，怪物横行，文明虽未完全灭亡但深受重创。土地被腐蚀，幸存者在绝望中挣扎。空气中弥漫腐化气息，大地龟裂出散发幽光的裂隙。

- 腐败无处不在：土地、水源、生物甚至记忆都在被缓慢腐蚀
- 文明虽存续但残破：几大势力勉强维持，但虚空仍是悬在头顶的剑
- 怪物是常态：不是突然入侵的敌人，而是世界的"新生态"
- 绝望感渗透日常：人们已忘记"没有虚空的世界"是什么样子

**第二重：冒险小队 = 戏谑反差**

约20名来自"男德学院"的成员闯入这个世界。他们不是苦大仇深的救世主，而是一群"来都来了，干一票"的冒险者。在黑暗得令人窒息的世界里，这20个人吵吵闹闹地存在，本身就是极其诡异的画面。

**核心原则：笑点不消解悲壮，戏谑不践踏严肃。**

### 1.2 核心母题 `[锁定]`

**探险与改造 = 把黑深残的世界一点点变成适合生存的地方。**

这不是一条主线任务，而是一个长期的世界状态变化。男德学院净化虚空、建立根据地、收容难民，给玩家持续探索的动力。

## 第二章 地理格局

### 2.1 世界形态 `[锁定]`

- 世界为球体，与地球类似
- **南北极皆海洋，无大陆**
- 以云顶山脉为地图正中心

### 2.2 核心地标：云顶山脉 `[锁定]`

云顶山脉是地图正中心，其存在显著影响世界格局：

| 方位 | 地标 |
|------|------|
| 西 | 睿河（帝国东界） |
| 北 | 山河走廊（通向共和国） |
| 东 | 大沙漠（巴拉巴拉部落） |
| 南 | 大草原（城邦） |

云顶山脉阻挡水汽，导致东侧形成大沙漠。

### 2.3 主要通道 `[锁定]`

| 通道 | 连接 | 用途 |
|------|------|------|
| 睿河 | 睿意志帝国东界 | 帝国天然边界 |
| 山河走廊 | 帝国 与 民主共和国 | 贸易通道（原帝制战争争议区） |
| 冥道 | 民主共和国 与 海盗联合王国 | 贸易通道 |
| 原道 | 海盗联合王国 与 大草原 | 开采矿产香料运回 |

### 2.4 各势力地理分布 `[锁定]`

```
            西北：睿意志帝国        东北：民主共和国
                 (睿河) |  (山河走廊)
                       云顶山脉
                 (大沙漠) |  (大草原)

                                        男德学院塔楼（大草原附近）
```

## 第三章 六大势力

### 3.1 睿意志帝国 `[锁定]`

**位置**：西北大陆

**政体**：魔法师独裁政权

**历史沿革**：
- 前身为君主立宪制，曾与共和国开战（帝制战争，发生在虚空降临前）
- 极强魔法师"睿"发动政变弑君，大清洗收兵权财政权后自立为帝
- 建立魔法教育体系，培养一代代魔法师；改革魔法体系，首次大规模应用于民用和军用
- 不断开疆拓土，几乎统一大陆西北，境内虚空裂隙被牢牢限制
- 将帝国东边的河命名为"睿河"
- 穷兵黩武，帝国内部评价两极分化

**内部派系（暗潮汹涌）**：
| 派系 | 立场 |
|------|------|
| 复辟派 | 前任君主追随者，带幼子出逃，企图复辟 |
| 改革派 | 前任政府遗老，不满独裁，企图改革 |
| 狂热追随者 | 拥护睿帝 |

**虚空处理手段**：`[锁定]` 驻兵军事化封印裂隙，驻军把守

**对外关系**：
- 与共和国：目前未起明显冲突，通过山河走廊贸易，但睿帝似乎有更大谋划
- 与大草原城邦：城邦附庸于帝国，但睿帝近期似乎对这块地盘感兴趣

---

### 3.2 民主共和国 `[锁定]`

**位置**：东北大陆（东南沿海有港口）

**政体**：美利坚式民主政体（联邦制 + 两党制 + 军工复合体）

**国策**：推崇科技强国，高科技武装军队

**民生**：人民生活水平略高于帝国，但贫富差距 + 环境污染严重

**隐患**：政治党争导致虚空裂隙不能有效控制，底层人民水深火热。军工复合体不希望虚空问题被彻底解决（那是军火收入来源）

**虚空处理手段**：`[锁定]` 科技预警 + 全自动灭杀系统

**贸易网络**：
- 通过山河走廊与帝国、沙漠巴拉巴拉部落贸易
- 东南沿海港口经冥道与海盗联合王国贸易

**外交手段**：经常支援沙漠部落，但也派间谍特务干扰部落和平，阻碍其统一

---

### 3.3 巴拉巴拉部落 `[锁定]`

**位置**：云顶山东侧大沙漠

**性质**：非单一部落，是无数部落的统称，由原始部落演化而来

**特长**：保留部分原始社会习性，近身格斗和冷兵器水平冠绝大陆

**地理制约**：南面被云顶山脉包围，水汽无法进入，大片区域为沙漠

**虚空处理手段**：`[锁定]` 大沙漠虚空不严重，基本不用处理

**外部干预**：共和国经常支援但也派间谍干扰，导致部落迟迟不能统一

**当前变数**：新领袖"杰"--受过良好教育，既有魔法天赋也精通科技，企图摆脱共和国控制，统一大沙漠

---

### 3.4 海盗联合王国 `[锁定]`

**位置**：远海岛屿

**起源**：几块漂浮海上的小岛；海盗前身多为共和国逃犯、帝国政斗失败者、寻求发财的平民

**演变**：各占山为王的海盗团体 -> 一代雄主"汪神"统一各岛

**统治者"汪神"**：以"水"和"王"加冕。用魔法连接各岛屿，建立行省制度（每岛给自治权），建屏障防御体系

**虚空处理手段**：`[锁定]` 蓝网（汪神建立的魔法屏障防御体系）

**贸易**：经冥道与共和国贸易，经原道前往大草原开采矿产香料

**危机**：共和国环境污染致海平面上升，危及国家安全，近年外交冲突不断

**当前变数**：汪神前往南极寻求"阿瓦隆"的无尽能源，至今下落不明，各岛为最高领导权蠢蠢欲动

---

### 3.5 虚空教团 `[锁定]`

**性质**：跨国邪教，崇拜虚空

**背景**：虚空入侵摧毁不少人心理防线，寻求宗教庇护，各大邪教崛起，最具影响力的是虚空教团

**活动**：几乎潜伏在各大势力，尤其是虚空最多的大草原；搞恐怖袭击

**各国态度**：
| 势力 | 态度 |
|------|------|
| 睿意志帝国 | 下令清洗邪教 |
| 民主共和国 | 悬赏邪教成员 |
| 大沙漠 | 暂无明显渗透 |
| 海盗联合王国 | 敌视邪教徒 |

各国国内均被渗透不少。

---

### 3.6 大草原城邦 `[锁定]`

**位置**：西南大陆

**现状**：只有零星几个小城邦，都依附睿意志帝国，政变后仍选择附庸但几乎完全自治

**虚空处理手段**：`[锁定]` 据点形式防守，守住居住区

**矛盾**：虚空肆虐，只有城邦附近区域可居住

**优势**：资源矿产丰富，气候舒适，人民生活质量全大陆最高

**变数**：最近睿帝似乎对这块地盘感兴趣

## 第五章 男德学院

### 5.1 定位 `[锁定]`

- 男德学院**来自这个世界之外**，来到这片大陆
- 初降临时建立**塔楼**作为根据地（塔楼只是建筑形态，不是系统/魔法装置）
- 学院的根据地叫**"德塔"**
- 不断**净化虚空**，建立新根据地**收容难民**
- **不参与政治斗争**，但仍然会被卷入
- 在各大势力和虚空之间**寻求平衡点**
- **终极目标：拯救更多的人**

### 5.2 冒险小队 `[锁定]`

约20名成员，来自男德学院。

**集体性格**：
- 嘴上不正经，手上靠得住
- 极强的归属感
- 冒险者心态：对未知有好奇心
- 改造的自觉："把这里变好"已成默契

**叙事原则**：
- 小队不是"被选中的英雄"，是"恰好在这里的冒险者"
- 取得的成就是玩家一步步打出来的，不是剧情给的

## 第八章 学院颠覆性分析

### 8.1 人类与虚空共处115年形成的"既有秩序" `[锁定]`

1. **虚空是常态**：裂隙永远存在，只能控制无法根除
2. **各国手段有极限**：帝国驻兵成本高、共和国科技因党争失控、海盗蓝网维护难、草原据点只能被动防守--没有任何手段能主动净化土地
3. **虚空能量是资源**：帝国靠它繁荣，共和国靠它赚钱（军工），邪教靠它获信徒
4. **魔法是精英特权**（帝国）：平民虽受益但无法接触高阶魔法
5. **科技解决不了根本问题**（共和国）：只能武器化虚空，无法消除虚空
6. **势力平衡脆弱但稳定**：与虚空共存的秩序已维持百年+

### 8.2 学院带来的变量

| 既有秩序 | 学院的颠覆性 |
|----------|--------------|
| 虚空只能限制，无法根除 | 学院可直接净化土地、封印裂隙，115年来人类从未拥有的能力 |
| 各国手段只能被动防御 | 学院能以塔楼为据点向外推进，从"避难所"变成"前进基地" |
| 虚空能量是稀缺资源 | 学院净化能力可能消除虚空能量稀缺性，威胁帝国垄断和共和国军火市场 |
| 邪教靠虚空崇拜获信徒 | 学院证明虚空可以被战胜，动摇邪教教义根基 |
| 各大势力保持脆弱平衡 | 学院作为新变量打破平衡 |
| 人们已接受"与虚空共存"的绝望 | 学院带来"彻底清除虚空"的希望 |

### 8.3 学院为何"既有颠覆性又具曲折性" `[锁定]`

**各大势力不会欢迎学院**：
- 帝国：净化技术可能削弱虚空垄断优势
- 共和国：军工复合体视学院为威胁
- 虚空教团：学院是教义死敌
- 海盗国：政局混乱，无法判断敌友
- 只有杰可能持开放态度

**但学院也不可或缺**：
- 虚空裂隙仍在，怪物仍在，难民仍在受苦
- 各大势力虽强，但都无法彻底解决虚空问题
- 学院是唯一可以"真正净化"的力量
- 难民会主动涌向学院据点

**学院目标"拯救更多人"**：
- 不参与政治斗争，但必然被卷入
- 净化土地 = 动了帝国的虚空垄断蛋糕、共和国的军火生意、邪教的信仰根基
- 这就是"颠覆性和曲折性"的核心
