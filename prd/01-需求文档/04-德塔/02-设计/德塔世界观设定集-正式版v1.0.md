## 第一章 世界基调

### 1.1 双重交织 `[锁定]`

德塔世界观由两种看似矛盾的基调编织而成：

**第一重：外部世界 = 黑深残**

虚空裂隙撕裂世界，怪物横行，文明虽未完全灭亡但深受重创。土地被腐蚀，幸存者在绝望中挣扎。空气中弥漫腐化气息，大地龟裂出散发幽光的裂隙。

- 腐败无处不在：土地、水源、生物甚至记忆都在被缓慢腐蚀
- 文明虽存续但残破：几大势力勉强维持，但虚空仍是悬在头顶的剑
- 怪物是常态：不是突然入侵的敌人，而是世界的"新生态"
- 绝望感渗透日常：人们已忘记"没有虚空的世界"是什么样子

**第二重：冒险小队 = 戏谑反差**

约20名来自"男德学院"的成员闯入这个世界。他们不是苦大仇深的救世主，而是一群"来都来了，干一票"的冒险者。在黑暗得令人窒息的世界里，这20个人吵吵闹闹地存在，本身就是极其诡异的画面。

**核心原则：笑点不消解悲壮，戏谑不践踏严肃。**

### 1.2 核心母题 `[锁定]`

**探险与改造 = 把黑深残的世界一点点变成适合生存的地方。**

这不是一条主线任务，而是一个长期的世界状态变化。男德学院净化虚空、建立根据地、收容难民，给玩家持续探索的动力。

### 1.3 虚空的本质与净化原理 `[锁定]`

> **本节是世界观的底层支柱**，解释了"为什么118年来没有任何势力能彻底清除虚空""为什么只有男德学院能净化"。所有势力设定、剧情逻辑、学院独特性的根源都在这里。

#### 1.3.1 三位面与裂隙的本质

本世界存在**三个位面**：

| 位面 | 说明 |
|------|------|
| **异世界位面** | 本故事的舞台。玩家所见的大陆、海洋、各国均在此位面 |
| **虚空位面** | 与异世界相交的另一维度。虚空生物、虚空能量均源自此处 |
| **地球位面** | 男德学院（玩家）的来源。第三位面，与前两者均不同源 |

**裂隙 = 位面相交的空间虫洞**：A.V.0 虚空降临，本质是异世界位面与虚空位面发生碰撞/相交，产生大量空间虫洞（即"裂隙"），使两个位面相通，虚空生物涌入异世界。

#### 1.3.2 同源相交机制（为什么本世界无法根除虚空）

两界相交已达118年，形成**同源相交机制**：异世界与虚空位面在长期接触中已深度耦合，无论是本世界的**魔法**（帝国）还是**科技**（共和国），都属于"同源"力量——它们源自这两个已相交的位面之内，因此**注定无法彻底关闭裂隙**，只能限制、封锁、利用。

> 这就是创作铁律第2条的底层原因：各国手段（驻兵/科技灭杀/蓝网/据点防守）都只是"限制"，不是"根除"。不是它们不够强，而是**同源力量在原理上就无法切断同源连接**。

#### 1.3.3 学院净化原理：第三位面的分层隔离

男德学院来自**地球（第三位面）**，与前两个位面均不同源。地球存在本身具有一种**位面层面的异质性属性**（非具体物品/装置，而是"存在本身的属性"）。

学院净化裂隙的原理：
1. 学院（玩家/学院成员）存在于裂隙接口处时，其"地球属性"介入异世界与虚空位面的接口之间
2. 产生类似**水油分层**的效果——两个同源相交的位面被第三位面的异质属性隔离
3. 位面接口被分层切断 → 裂隙关闭 → 该区域虚空被净化

> **关键**：不是学院带来了某种"净化装置"或"净化魔法"，而是**学院成员本身（作为地球位面的存在）就是净化的媒介**。只要他们在，地球属性就能产生分层隔离。这也是为什么学院必须"以塔楼为据点向外推进"——净化范围取决于学院存在的辐射范围。

#### 1.3.4 虚空的真相（长期伏笔）

虚空并非纯粹的混沌与无意识。以下是被观察到但尚未被理解的现象：

- **虚空之中确实存在有理智的生物**：某次虚空入侵中，人们发现虚空生物似乎受到了某种命令而整体行动，呈现出协调性，而非随机涌出
- 这意味着虚空背后可能存在某种意志、指挥者或层级结构
- **⚠ 虚空位面可能与地球位面也存在某种未知的联系**（长期悬念，待主线展开）
- 目前人类对此知之甚少，各势力均无确切结论
- 这是世界观最深层的悬念之一，留待主线长期展开

## 第二章 地理格局

### 2.1 世界形态 `[锁定]`

- 世界为球体，与地球类似
- **南北极皆海洋，无大陆**
- 以云顶山脉为地图正中心

### 2.2 核心地标：云顶山脉 `[锁定]`

云顶山脉是地图正中心，其存在显著影响世界格局：

| 方位 | 地标 |
|------|------|
| 西 | 睿河（帝国东界） |
| 北 | 山河走廊（西连帝国，东连共和国，南接壤大沙漠） |
| 东北 | 大沙漠（巴拉巴拉部落） |
| 西南 | 大草原（城邦） |

云顶山脉阻挡水汽，导致东北侧形成大沙漠。

山河走廊原型为**丝绸之路**：是帝国与共和国之间的贸易大动脉，也是帝制战争时期的争议地带。

### 2.3 主要通道 `[锁定]`

| 通道 | 连接 | 用途 |
|------|------|------|
| 睿河 | 睿意志帝国东界 | 帝国天然边界 |
| 山河走廊 | 帝国 与 民主共和国（南接壤大沙漠） | 贸易通道（丝绸之路原型，原帝制战争争议区） |
| 冥道 | 民主共和国 与 海盗联合王国 | 贸易通道 |
| 原道 | 海盗联合王国 与 大草原 | 开采矿产香料运回 |

### 2.5 睿意志帝国·地理细化

**地貌**：西北大陆，以平原与丘陵为主，地势西高东低。睿河自北向南纵贯东部边境，是帝国天然边界。

**气候**：温带气候。因虚空裂隙受控率高达90%+，帝国核心区气候稳定、土地肥沃，是全大陆最适宜居住的区域之一。

**裂隙区分布**：
| 区域 | 裂隙密度 | 说明 |
|------|---------|------|
| 帝都周边 | 极低 | 皇家虚空研究院驻地，魔法屏障覆盖 |
| 西北腹地 | 低 | 收复失地计划已清理，残留少量封印裂隙 |
| 东部边境 | 中 | 与山河走廊接壤处，残留裂隙区，驻军把守 |
| 睿河沿线 | 低 | 河流本身是天然屏障，裂隙沿河零星分布 |

**主要城市与据点**：
- **帝都**：帝国政治与魔法中心。睿帝宫廷、皇家虚空研究院、魔法学院均坐落于此。虚空原液民用化枢纽。
- **东部要塞群**：沿睿河修建的军事要塞链，防范共和国+封印边境裂隙。A.V.100睿帝政变后大幅扩建。
- **魔法哨站网络**：A.V.118吞并大草原后，哨站网络扩展至大草原，监控各地虚空裂隙动态。

### 2.6 民主共和国·地理细化

**地貌**：东北大陆，东部沿海平原，西部内陆丘陵。东南沿海有大型港口城市（冥道起点）。

**气候**：温带海洋性气候，但工业化环境污染严重。海平面上升导致沿海城市面临淹没危机，部分地区已修筑防海堤坝。

**裂隙区分布**：
| 区域 | 裂隙密度 | 说明 |
|------|---------|------|
| 国会城（首都） | 中 | A.V.118空袭后裂隙封印受损，正在修复 |
| 富人区/核心商业区 | 低 | 军工复合体出资维护，科技灭杀系统覆盖 |
| 贫民窟区 | 极高 | 虚空失控重灾区，政府几乎放弃治理。虚空教团半公开活动 |
| 沿海港口区 | 中 | 冥道贸易枢纽，灭杀系统维护优先级最高 |
| 内陆城市外围 | 高 | 党争导致灭杀系统年久失修，裂隙持续扩散 |

**主要城市与据点**：
- **国会城**：共和国政治中心，A.V.118空袭后重建。丘大统领就任后推行「丘明」「丘序」国民教育。国防系统由丘亲自修复加固。
- **贫民窟区**：虚空教团温床，丘大统领清剿的重点目标。也是丘发家的基本盘。
- **冥道港口**：东南沿海最大港口，通往海盗联合王国的贸易枢纽。A.V.118后贸易量锐减。
- **内陆工业城市群**：军工复合体大本营，虚空充能武器生产线。

**地貌**：云顶山脉东北侧大沙漠，广袤沙丘+戈壁+零星绿洲。西南面被云顶山脉包围，水汽无法进入。

**气候**：极端干旱，昼夜温差极大。但正因如此，虚空裂隙极少——虚空生物不适应沙漠环境。

**裂隙区分布**：
| 区域 | 裂隙密度 | 说明 |
|------|---------|------|
| 七核心部落绿洲 | 几乎无 | 绿洲有天然净化属性，虚空难以渗透 |
| 沙漠腹地 | 极低 | 零星小型裂隙，部落战士可轻松处理 |
| 沙漠边缘（靠山河走廊） | 低 | 与走廊接壤处有少量裂隙 |
| 地下遗迹区 | 未知 | 沙漠深处发现过古文明遗迹入口，裂隙活动异常 `[伏笔]` |

**主要据点**：
- **七核心部落绿洲群**：巴拉巴拉部落的心脏。杰的统一宣言在此签署。每个绿洲是一个部落自治中心。
- **杰的营地**：杰的指挥中枢，流动性大。融合帝国魔法+共和国科技+部落传统。
- **地下遗迹** `[伏笔]`：沙漠深处偶现的古代建筑残骸。有人认为与塔楼系统同源。杰曾提及"大沙漠下面藏着秘密"。可能与虚空背后的意志有关联。

### 2.11 男德学院·德塔据点

**位置**：大草原附近（学院降临地）。选址原因：大草原是全大陆裂隙最密集的区域，也是学院"净化土地"使命的最前线。

**塔楼据点结构** `[系统]`：
- **安全区**：塔楼内部，禁止战斗。玩家休整、切换装备、接取任务。
- **内环探索区**：塔楼周边，普通怪刷新。新手区，净化后可扩展。

## 第八章 学院颠覆性分析

### 8.1 人类与虚空共处118年形成的"既有秩序" `[锁定]`

1. **虚空是常态**：裂隙永远存在，只能控制无法根除（**根因：同源相交机制**，详见1.3.2）
2. **各国手段有极限**：帝国驻兵成本高、共和国科技因党争失控、海盗蓝网维护难、草原据点只能被动防守--没有任何手段能主动净化土地。**这不是技术不够强，而是同源力量在原理上就无法切断同源连接**
3. **虚空能量是资源**：帝国靠它繁荣，共和国靠它赚钱（军工），邪教靠它获信徒
4. **魔法是精英特权**（帝国）：平民虽受益但无法接触高阶魔法
5. **科技解决不了根本问题**（共和国）：只能武器化虚空，无法消除虚空
6. **势力平衡脆弱但稳定**：与虚空共存的秩序已维持百年+

### 8.2 学院带来的变量

| 既有秩序 | 学院的颠覆性 |
|----------|--------------|
| 虚空只能限制，无法根除（同源相交） | 学院作为**第三位面（地球）存在**，产生分层隔离，可直接关闭裂隙、净化土地（详见1.3.3）。118年来人类从未拥有的能力 |
| 各国手段只能被动防御 | 学院能以塔楼为据点向外推进，从"避难所"变成"前进基地"（净化范围=学院存在辐射范围） |
| 虚空能量是稀缺资源 | 学院净化能力可能消除虚空能量稀缺性，威胁帝国垄断和共和国军火市场 |
| 邪教靠虚空崇拜获信徒 | 学院证明虚空可以被战胜，动摇邪教教义根基 |
| 各大势力保持脆弱平衡 | 学院作为新变量打破平衡 |
| 人们已接受"与虚空共存"的绝望 | 学院带来"彻底清除虚空"的希望 |

### 8.3 学院为何"既有颠覆性又具曲折性" `[锁定]`

**各大势力不会欢迎学院**：
- 帝国：净化技术可能削弱虚空垄断优势
- 共和国：军工复合体视学院为威胁
- 虚空教团：学院是教义死敌
- 海盗国：政局混乱，无法判断敌友
- 只有杰可能持开放态度

**但学院也不可或缺**：
- 虚空裂隙仍在，怪物仍在，难民仍在受苦
- 各大势力虽强，但都无法彻底解决虚空问题
- 学院是唯一可以"真正净化"的力量
- 难民会主动涌向学院据点

**学院目标"拯救更多人"**：
- 不参与政治斗争，但必然被卷入
- 净化土地 = 动了帝国的虚空垄断蛋糕、共和国的军火生意、邪教的信仰根基
- 这就是"颠覆性和曲折性"的核心
