# 地图系统设计

> 状态：白机初稿，待黑机+院长打磨 | 创建：2026-07-29
> 关联：设定集 v1.3（地理格局/势力）、序章剧本设计（男德通Q&A/出门选点）
> ⚠️ 大地图美术基于院长线稿由黑机生成。地点名称和解锁条件部分待定。

---

## 一、概述

地图系统分两层：
- **大地图**：世界级地点选择，玩家选择前往哪个区域
- **小地图**：区域内具体地点选择，进入某个城邦/哨站/城区

地图在两个场景使用：
1. **男德通 Q&A**：讲解世界格局时展示大地图（纯展示，不可移动）
2. **出门移动**：玩家选择前往地点，进行后续场景移动（可交互选点）

### 大地图移动逻辑

- 初始只能去 **草原北部**（学院所在）
- 去帝国边界哨站：默认需途径城邦（草原北部 -> 城邦 -> 帝国边界哨站）
- 好感度达标后触发传送节点剧情 -> 可直接传送至帝国边界哨站
- 其他地点随剧情解锁

## 四、学院与各方势力当前关系（A.V.118 序章时间线）

> 以下信息影响男德通 Q&A 时对玩家的回答内容。男德通只说学院已知的情报。

### 帝国
- **关系状态**：有接触，但不多
- **已知信息**：帝国是魔法独裁政权，睿帝很强，有暗探（法刺）。学院知道帝国对草原有野心。
- **未知信息**：法刺正在搜索牧羊人、睿帝知道关于牧羊人的某些事（学院不知）

### 草原城邦
- **关系状态**：接触最多
- **已知信息**：部分城邦表示友善，部分城邦在观望，少数几个被虚空教团完全渗透的城邦暗地里敌视学院
- **男德通会说**：有些城邦欢迎我们，有些在观望，还有几个--小心点，那帮人不对劲

### 沙漠
- **关系状态**：几乎无接触
- **已知信息**：有某个年轻人异军突起的传闻，但学院认为现在还是部落割据状态
- **未知信息**：杰已统一七大核心部落、签了统一宣言（学院不知，只听到传闻）

### 联合王国
- **关系状态**：不多，偶尔的贸易往来
- **已知信息**：海上国家，有蓝网防御体系，偶尔做点贸易
- **未知信息**：汪神已失踪5年（学院不知，只认为汪神还在远航。汪神失联目前只有海盗王国核心成员和各大岛海盗头子知道）

### 共和国
- **关系状态**：有接触，但不多
- **已知信息**：科技强国，民主政体
- **未来钩子**：丘就任大统领并稳定局势后会给学院写信（序章时丘尚未就任或刚就任局势未稳）

## 五、引擎改动预留

| 改动 | 说明 | 优先级 |
|------|------|:--:|
| MapPanel.vue | 大地图组件，展示地点节点 | P2 |
| SubMapPanel.vue | 小地图组件，展示区域内地点 | P2 |
| store: currentLocation | 当前所在大地图位置 | P2 |
| store: unlockedLocations | 已解锁地点列表 | P2 |
| store: travelTo(locationId) | 移动到指定地点 | P2 |
| 剧本节点: map 交互 | 出门选点时打开大地图 | P2 |
| 男德通 Q&A 地图展示 | 讲解世界格局时展示大地图（只读） | P2 |

> 地图系统对应需求 R-022，属于 M-G3 里程碑。
