# 德塔剧情钩子总框架

**设计哲学声明**
本框架服务于「探险与改造」核心母题。所有钩子不是"让玩家去干一件事"，而是"在一个大势已定的黑深残世界里，窥见一个可以撬动的裂缝，让玩家决定要不要伸进撬棍"。主线提供方向，支线提供深度，势力互动提供后果——三者交织，让德塔世界从"可探索"升级为"可改变"。

---

## 一、剧情核心理念

| 维度 | 说明 |
|------|------|
| **主线定位** | 不是"拯救世界"，而是"在大势中找一个能下手的裂缝"。三条帝国/共和国/海盗国大势并行推进，学院在夹缝中净化虚空、收容难民 |
| **核心张力** | A.V.118三线剧变开启世界新格局，学院恰好扎根3年有了根基——**外部世界在崩坏，但我们刚好能出手** |
| **驱动方式** | 玩家选择优先封印哪个区域的裂隙 -> 开启不同势力线 -> 获得不同势力支援 -> 面对不同势力的纠缠 |
| **终极悬念** | 虚空背后有理智意志、牧羊人能与虚空沟通、睿帝在找牧羊人 -> 三层嵌套悬念，逐步揭示 |

### 节奏控制
| 阶段 | 内容 | 时长 |
|------|------|------|
| 序章（A.V.118初） | 三线剧变爆发，学院收到多方求援/警告，添分析形势 | 引导期 |
| 第1章 | 玩家选择优先净化路线，建立第一个外围据点，获得对应势力初步认可 | 探索建设期 |
| 第2章 | 对应势力深入纠缠，学院面临第一次重大抉择，发现虚空教团渗透痕迹 | 冲突升级期 |
| 第3章 | 发现虚空教团真正目标（阻止净化），解锁大草原腹地方向，与帝国外围接触 | 真相浮现期 |
| 第4章 | 草原腹地区域解锁，接触虚空有理智存在的证据，睿帝法刺出现 | 终极悬念开启 |
| 后续 | 牧羊人、虚空意志、汪神下落/阿瓦隆线索逐步揭示 | 长期更新 |

> 添看着裂隙流动的数据：「这不是自然裂隙。自然裂隙是破口，水往外涌。这个是……水流被引导到固定的方向。就好像有人在裂隙那头修了引水渠。」他抬头，眼镜反光：「草原深处有人在做我们无法理解的事。」

## 三、支线任务体系

### 支线设计原则
| 原则 | 说明 |
|------|------|
| **非填充** | 每个支线必须有叙事价值——揭示世界观细节/展现NPC性格/打开新区域/提供装备选择 |
| **多触发** | 主线进度、势力好感、特殊条件（携带特定装备/探索特定地点）、时间触发四类 |
| **有后果** | 支线选择影响后续解锁、势力态度、某些NPC是否存活 |
| **可回溯** | 不能永久错过的支线在条件满足后可重新触发 |

> 添把打磨好的镜片举到光下，晶矿内部的纹路像被冻结的漩涡。「这不是普通的矿物。」他推了推眼镜，「这种能量排列……和裂隙边缘的波动是同一个频率。这块石头在地下被虚空'浸泡'了一百多年，已经和裂隙共振了。如果我们能弄懂这个共振，也许能找到更高效的封印方法。」

## 四、势力互动总框架

### 4.1 势力关系动态网络
**核心机制**：势力好感不是线性增长，而是**动态平衡**。帮助一方可能触发另一方的反应。

| 势力 | 初始态度 | 影响因素 | 可争取状态 |
|------|----------|----------|------------|
| 帝国 | 无视 | +净化帝国边境裂隙 / +帮助哨站 / +接受睿帝邀请；-深入草原太快 / -接触牧羊人 | 警戒->中立->军事合作->战略盟友（睿帝欠人情） |
| 共和国 | 未知（忙于内部） | +净化贫民窟裂隙 / +协助丘训练部队 / +揭露军工 / -过于接近帝国 | 未知->公开认可->有限合作->正式结盟 |
| 海盗国鸽派 | 关注 | +修复蓝网薄弱区 / +救援航线 / +寻找汪神线索；-帮助鹰派 | 关注->请求->信赖->依托 |
| 海盗国鹰派 | 敌视 | -帮助鸽派；+提供贸易资源（两难） | 敌视->中立->可交易（但始终不信任） |
| 大沙漠 | 好奇 | +净化裂隙能力展示 / +帮助勘探遗迹 / +统一事业支持 | 好奇->认可->坦诚->战略伙伴 |
| 虚空教团（激进派） | 敌视 | -始终敌视，但存在可对话的温和派（⚠需谨慎：温和派立场不明，可能已深度被虚空渗透） | 敌视 |
| 骑小马协会 | 天然亲近 | +任何净化成果 | 亲近->盟友->执行共同任务 |
| HU（人类联合） | 观望 | +跨国行动/难民收容/公开成果 | 观望->背书->外交合法性保障 |
