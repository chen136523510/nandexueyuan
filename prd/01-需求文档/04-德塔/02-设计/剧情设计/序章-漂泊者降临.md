## 一、核心设定

| 要素 | 内容 |
|------|------|
| 时间线 | A.V.118，三线剧变前夕，学院已扎根 3 年 |
| 玩家称谓 | **漂泊者** -- 来自地球的异世界来客 |
| 玩家定位 | 第二批传送来的地球成员，刚到，对异世界一无所知 |
| 院长 | 第一批先行者领袖 NPC，黑机设计形象。平等关系非主从，第二批传送的发起者 |
| 法刺·幸 | 女性，法刺二号人物，表面帝国外交部部长。负责外交和情报收集。**独自一人**来访（非大张旗鼓），因情报得知今天有新传送人到达，来试探学院实力和来历 |
| 法刺·荣 | 女性，法刺头号人物，表面禁卫队队长。执行刺杀/颠覆政权。序章不出场，形象留黑机设计 |
| 睿帝令 | 信物令牌。同意分支获得，既是剧情flag（帝国友方标识）、可查看物品（放储物空间）、且后续触发帝国线专属分支 |

### 法刺设定补充（待归档至设定集）

> 院长 2026-07-29 口述补充，待黑机设计形象后归档至设定集 v1.4

- **幸**：法刺二号人物。表面身份=帝国外交部部长。职能=外交事务+收集外部情报。性格基调=试探为主（对学院好奇，观察能力和来历，谈判是顺带）。单独行动，不暴露法刺身份，以帝国大臣名义接触。
- **荣**：法刺头号人物。表面身份=禁卫队队长。职能=刺杀政要、颠覆政权（脏活）。序章不出场。
- 两人形象设计：留给黑机。

## 二、序章范围

**序章 = 第一幕（降临）→ 第二幕（法刺来访）→ 第三幕（储物发放）→ 第四幕（自由探索）**

三线剧变及后续剧情**不在序章范围内**，由黑机+酒馆AI设计后扩充为第一章。

### 三线剧变的情报节奏（院长口述，供黑机参考）

实际事件顺序：共和国国会事变 → 帝国闪电战 → 贸易线断 → 海盗掠夺

学院感知顺序（循序渐进，非一次性爆发）：
1. 先感知到帝国闪电战（地理近，草原就在脚下）
2. 玩家去处理帝国和城邦的关系（消耗数月）
3. 得知共和国的事情，准备去调研时，发现零星海盗
4. 处理海盗事情时，从海盗口中得知贸易线路问题
5. 后续剧情待黑机设计

> 注：帝国和海盗王国不能提前预知国会事变，但帝国的行动速度快。

## 三、场景流程

### 第一幕：降临

```
背景: bg/void_world → bg/grassland → bg/tower_day

旁白: 虚空降临第118年。裂隙如旧，世界如旧。
旁白: 三年前，一座塔楼拔地而起，此后草原裂隙开始消散——118年来从未有过的事。
旁白: 塔楼名"德塔"。一群自称男德学院的人，从另一个位面而来。

[背景切换: 塔楼内部]
院长: 迎接第二批传送者。
院长: 简述情况——三年前降临，建了塔楼，发现裂隙会因学院成员的存在而闭合。但人手不够，把你们叫来了。
院长: "先到处看看，熟悉一下。不过——今天可能要有客人来。"
```

**设计意图**：玩家 = 刚到的第二批次，自然身份 = 不了解世界 → 后续问男德通成为合理的信息传递。

---

### 第二幕：法刺来访（核心冲突）

```
背景: bg/tower_day

旁白: 院长话音刚落，一个人影从晨雾中走来。没有仪仗，没有旗帜，只有一个人。
旁白: 来者自称帝国外交部部长，名"幸"。

幸: （礼貌微笑）"院长阁下，久仰。睿帝陛下让我代为问候。"
幸: "三年前贵学院降临以来，草原裂隙消散大半。陛下非常……欣赏。"

[进入正题]
幸: "睿帝有一桩请求。大草原诸城邦虽名义附庸帝国，实则各自为政。裂隙肆虐，百姓流离。"
幸: "陛下希望学院能出面，促成城邦归顺帝国。有学院的力量，城邦不会有异议。这对所有人都有好处。"

院长: （转向玩家）"这件事……我不能替所有人做主。学院成员来去自由，这是我们的规矩。"
院长: "你刚到，但你是学院的人。怎么回应，你自己决定。"

幸: （注意到玩家，打量）"哦？新面孔。"
幸: "你叫什么名字？"

[输入框: 玩家输入名字]  ← 自我命名环节，名字后续可变更

幸: "那就由你来说吧，[玩家名]。"
```

**玩家选择**：

```
┌─────────────────────────────────────────┐
│  A. 同意 —— 城邦归顺帝国，学院做中间人   │
│  B. 拒绝 —— 学院不参与政治               │
│  C. 询问 —— 睿帝是什么人？帝国是什么？   │
│  D. 询问 —— 城邦自己愿意吗？             │
└─────────────────────────────────────────┘
```

**C/D 询问分支**（幸以试探态度回答，回答后回到选择）：

- **C「睿帝是什么人」**: 幸眼中闪过复杂 → "睿帝……是这个时代最强的人。118年前世界面临虚空毁灭，是他用魔法给帝国争取了生存空间。你可以说他是暴君，也可以说他是救世主。取决于你站在哪边。"（试探：看玩家对强权的态度）
- **D「城邦愿意吗」**: 幸微笑 → "城邦？城邦连裂隙都挡不住。帝国给了他们一百年的庇护，他们欠帝国的。归顺只是走个形式。"（试探：看玩家是否同情弱者）
- 回答后 → 回到选择（同意/拒绝/另一个询问）

**A 同意分支**：
```
幸: （微笑加深）"明智。陛下会记住你的善意。"
幸: （取出一块令牌）"这是睿帝令。持此令者，帝国视为友邦。"
[获得物品: 睿帝令]
幸: "后会有期。"（离去）
```

**B 拒绝分支**：
```
幸: （微笑不变）"可惜。不过——睿帝的耐心是有限的。"
幸: "你们在草原上净化裂隙，帝国不会干涉。但城邦的事，帝国志在必得。"
幸: "到时候，希望你们能做出正确的选择。"（离去）
```

### 第三幕：储物空间发放

```
背景: bg/tower_interior

院长: "不管你怎么选，你刚到，总得有个行装。"
院长: （递出一个物件）"这是纳戒。学院造的，能装不少东西。"
院长: "以后捡到什么、收到什么，都放这里面。点一下就能看。"

[系统提示: 储物空间已解锁，按 B 键打开]
[若同意分支: 纳戒中已有「睿帝令」]
[若拒绝分支: 纳戒为空]

院长: "去跟男德通聊聊吧。你对这个世界还一无所知，他什么都知道。"
```

### 第四幕：自由探索（男德通 Q&A）

```
背景: bg/tower_interior

男德通: "哟，新人！我听院长说你刚到。有什么想知道的尽管问。"

[选择对话话题]（玩家可反复询问，不消耗推进）:

┌──────────────────────────────────┐
│  📌 这是什么地方？               │
│  📌 我们是谁？学院是干什么的？   │
│  📌 世界局势？有哪些势力？       │
│  📌 刚才那个人是谁？             │
│  📌 裂隙是什么？我们能做什么？   │
│  📌 我接下来该干嘛？             │
│  ✅ 了解得差不多了               │
└──────────────────────────────────┘
```

**各话题内容方向**（男德通以轻松戏谑口吻讲解，具体台词待黑机打磨）：

- **这是什么地方**: 异世界，跟地球完全不同的位面。118年前裂隙降临，怪物横行。学院三年前到的，在大草原西南建了塔楼。
- **我们是谁**: 男德学院，二十来号人。从地球来的。来了之后发现——我们的存在本身就能关闭裂隙。算是这世界的净化器吧。
- **世界局势**: 六大势力。西北睿意志帝国（魔法独裁，就是刚才那帮人）、东北民主共和国（科技强国）、大沙漠部落联盟、远海海盗国、大草原城邦（就在我们脚下）、还有一个跨国邪教虚空教团。
- **刚才那个人**: 帝国外交部部长？信你个鬼。那气质，那眼神，八成是法刺——睿帝的暗探。来摸我们底的。
- **裂隙是什么**: 虚空和这个世界相交产生的裂缝，会渗出腐化和怪物。118年了没人能关掉。然后我们来了，关掉了。
- **我该干嘛**: 先活下来。然后净化裂隙、帮帮难民、看看这个世界。院长说了，来去自由，但既然来了——干一票？

> ⚠️ 以上问答内容为白机初稿方向，需黑机与酒馆AI打磨具体台词。问答应体现男德通"嘴上不正经手上靠得住"的集体性格。

**玩家选择「了解得差不多了」后**：
```
男德通: "行，那慢慢来。这地方虽然破，但好歹能住人。有事随时找我。"

[序章结束画面: "序章·漂泊者降临 —— 完"]
```

## 四、新功能需求

### 4.1 自我命名系统

| 项目 | 说明 |
|------|------|
| 触发时机 | 第二幕，幸问玩家名字时 |
| 交互方式 | 对话框内弹出输入框，玩家输入名字 |
| 约束 | 名字后续可变更（设置面板或男德通处改） |
| 用途 | 角色对话中称呼玩家（`[玩家名]` 占位符） |
| 引擎改动 | store 增加 `playerName` 状态；dialogue 节点文本支持 `{playerName}` 模板替换；新增 input 类节点类型或 choice 扩展 |

### 4.2 储物空间系统

| 项目 | 说明 |
|------|------|
| 快捷键 | **B 键** 打开/关闭 |
| UI | 背包面板组件（InventoryPanel.vue），网格布局展示物品图标 |
| 物品详情 | 点击物品 → 弹出详情弹窗（物品图标 + 名称 + 描述文字） |
| 数据结构 | store 增加 `inventory` 状态（数组）；event 节点支持 `grantItem` 动作 |
| 物品数据 | 新建 `src/visualnovel/data/items.js`，定义物品 id/名称/图标/描述 |

**物品数据结构**：
```js
{
  id: 'rui_emblem',
  name: '睿帝令',
  icon: 'items/rui_emblem.png',    // 美术资源，黑机提供
  description: '帝国皇帝睿赐予的信物令牌。持此令者，帝国视为友邦。令牌正面刻有帝国徽记，背面铭文"睿之信"。',
  type: 'key_item',                 // key_item(关键道具) / consumable(消耗品) / material(材料)
}
```

**美术预留位置**：

| 美术需求 | 说明 | 优先级 |
|---------|------|:--:|
| 纳戒图标 | 物品栏 UI 内小图标 | P2 |
| 睿帝令图标 | 物品栏 + 获得时全屏展示 | P2 |
| 睿帝令获得演出图 | 同意分支获得时展示 | P3 |
| 背包面板背景 | 弹窗底图 | P3 |
| 物品详情弹窗背景 | 详情面板底图 | P3 |
