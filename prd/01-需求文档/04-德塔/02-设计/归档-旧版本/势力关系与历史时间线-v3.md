## 【重点展开】人类与虚空长期共处的115年

### 阶段一：虚空灾难期（A.V.0-10）
**“世界几乎终结的十年”**

| 年份 | 事件 |
|------|------|
| A.V.0 | 虚空裂隙首次大规模出现。天空撕裂，虚空生物涌入。各国军队仓促应战，常规武器对虚空生物效果有限。前帝国与共和国紧急停战（帝制战争被迫中止）。 |
| A.V.1 | 人口锐减40%。城市沦陷，幸存者退守天然屏障地带。巴拉巴拉部落因沙漠地理隔绝损失较小。大草原城邦几乎全灭，仅余少数据点。 |
| A.V.2 | 前帝国皇家魔法师团发现：魔法对虚空生物有显著效果。首次成功封印小型裂隙。魔法师地位急剧上升。 |
| A.V.3 | 共和国科学家发现：虚空生物死后残留的“虚空结晶”蕴含能量。【虚空生物研究·起步】 |
| A.V.4 | 前帝国建立第一批“安全区据点”，以魔法屏障维持。共和国靠城墙+科技武器死守沿海城市。 |
| A.V.5 | 远海岛屿：虚空裂隙较少，成为逃亡者目的地。第一批海盗团体形成，起初只是幸存者互助组织。 |
| A.V.7 | 【塔楼系统首次出现】不知来源的古老守护力量在世界各地显现。某些特定建筑（多为古文明遗迹）成为绝对安全区——虚空怪物无法侵入。这些建筑后来被称为“塔楼”。幸存者围绕塔楼重建据点。 |
| A.V.9 | 人口降至虚空前30%。但人类已学会基本生存法则：①塔楼安全 ②魔法有效 ③虚空结晶可被利用。绝望中燃起微弱希望。 |
| A.V.10 | 虚空中期稳定：大规模裂隙不再新增，现有裂隙进入“稳定渗出”状态。人类从濒死阶段进入“与虚空共存”阶段。 |

**阶段成果：魔法压制虚空的方法确立；虚空结晶被发现；塔楼系统出现；人类认识到必须与虚空长期共处。**

## 【学院到来的颠覆性】人类既有秩序 vs 学院变量

### 人类与虚空共处115年形成的“既有秩序”
1. **虚空是常态**：虚空裂隙永远存在，只能控制无法根除
2. **塔楼有极限**：塔楼是安全区，但无法主动净化土地，只能被动防御
3. **虚空能量是资源**：帝国靠它繁荣，共和国靠它赚钱（军工），邪教靠它获信徒
4. **魔法是精英特权**（帝国）：帝国平民虽受益但仍无法接触高阶魔法
5. **科技解决不了根本问题**（共和国）：只能武器化虚空，无法消除虚空
6. **势力平衡脆弱但稳定**：帝国、共和国、海盗国、沙漠部落，谁也无法消灭谁，与虚空共存的秩序已维持百年+

### 学院带来的变量
| 既有秩序 | 学院的颠覆性 |
|----------|--------------|
| 虚空只能限制，无法根除 | **学院可直接净化土地、封印裂隙**。这是115年来人类从未拥有的能力 |
| 塔楼只能被动防御 | **学院能以塔楼为据点向外推进**，把塔楼从“避难所”变成“前进基地” |
| 虚空能量是稀缺资源 | **学院的净化能力可能消除虚空能量的“稀缺性”**，帝国靠虚空垄断建立的国力优势被威胁，共和国军工复合体的虚空武器市场被挑战 |
| 邪教靠虚空崇拜获信徒 | **学院证明虚空可以被战胜**，动摇邪教教义根基（“虚空不可战胜所以只能崇拜”） |
| 各大势力保持脆弱平衡 | **学院作为新变量打破平衡**。帝国警惕（净化技术可能威胁其虚空垄断），共和国觊觎（想获取技术），海盗国观望（可能重新洗牌），杰好奇（可能获得摆脱超级大国的新路径） |
| 人们已接受“与虚空共存”的绝望 | **学院带来“彻底清除虚空”的希望**。这本身就是对既有秩序的颠覆——习惯了绝望的人，突然看到希望，会恐慌也会狂热 |

### 学院为何“既有颠覆性又具曲折性”
- **各大势力不会欢迎学院**：
  - 帝国：学院净化技术可能削弱帝国虚空垄断优势
  - 共和国：军工复合体视学院为威胁（净化土地=虚空武器市场萎缩）
  - 虚空教团：学院是教义死敌（“虚空可���战胜”否定教义基础）
  - 海盗国：政局混乱，无法判断学院是敌是友
  - 只有杰可能持开放态度（他需要摆脱超级大国控制的新路径）
  
- **但学院也不可或缺**：
  - 虚空裂隙仍在，怪物仍在，难民仍在受苦
  - 各大势力虽强，但都无法彻底解决虚空问题
  - 学院是唯一可以“真正净化”的力量
  - 难民会主动涌向学院据点，这是各大势力无法阻止的

- **学院的目标：“拯救更多人”**：
  - 不参与政治斗争，但必然被卷入
  - 净化土地=动了帝国的虚空垄断蛋糕、共和国的军火生意、邪教的信仰根基
  - 在各大势力和虚空之间寻求平衡点
  - 这就是“颠覆性和曲折性”的核心——学院是好意的外来者，但既有秩序会抵抗
