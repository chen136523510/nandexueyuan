## 一、项目概况

**项目名称**：德塔（Deta）-- 男德学院视觉小说

**核心定位**：黑深残世界 × 戏谑反差冒险者。玩家以轻松冒险者姿态闯入黑暗世界，净化虚空、改造土地。

**当前形态**：**视觉小说**（叙事驱动 + 立绘 + 背景 + 对话 + 分支世界线）。原 2D 动作游戏方向（Phaser/Colyseus）已全部废弃。

**技术栈**：Vue 3 自研引擎（非 Ren'Py/KiriKiri），`/nde` 路由直接进入

## 四、序章核心设定（黑机创作必读）

> 完整设计见 `剧情设计/序章-漂泊者降临.md`，以下为要点速查。

| 要素 | 内容 |
|------|------|
| 时间线 | A.V.118，三线剧变前夕，学院已扎根 3 年 |
| 玩家 | 第二批传送来的地球成员（漂泊者），刚到 |
| 院长 | 第一批先行者领袖 NPC，黑机设计形象，平等关系非主从 |
| 法刺·幸 | 女性，法刺二号人物，表面帝国外交部部长。**独自一人**来访，试探学院 |
| 法刺·荣 | 女性，法刺头号人物，表面禁卫队队长。执行刺杀/颠覆。序章不出场 |
| 睿帝令 | 同意分支获得，剧情flag + 可查看物品 + 后续帝国线分支 |

**四幕结构**：降临 → 法刺幸来访（含自我命名+选择分支）→ 储物空间发放 → 添Q&A自由探索

**序章范围到自由探索为止**，三线剧变是第一章内容。

### 三线剧变情报节奏（供黑机参考）

实际事件顺序：共和国国会事变 → 帝国闪电战 → 贸易线断 → 海盗掠夺

学院感知顺序（循序渐进）：
1. 先感知帝国闪电战（地理近）
2. 玩家处理帝国城邦关系（消耗数月）
3. 得知共和国的事情，准备调研时发现零星海盗
4. 从海盗口中得知贸易线路问题
5. 后续剧情待黑机设计

> 帝国和海盗王国不能提前预知国会事变，但帝国行动速度快。

## 六、创作铁律（易错点，必须遵守）

1. **塔楼是建筑**（砖头水泥），不是系统/魔法装置，根据地为「德塔」
2. **各国自有虚空手段**，不依赖塔楼。底层原因：同源相交机制，本位面魔法/科技同源，注定无法根除裂隙
3. **大沙漠在东北**，**大草原在西南**，山河走廊在北面南接大沙漠
4. **帝制战争在虚空降临之前**（B.V.），虚空后帝国与共和国未爆发全面战争
5. **虚空后历史118年**，当前年份/游戏主线起点 = A.V.118（学院A.V.115降临，扎根3年）
6. **虚空有理智生物**，整体协调行动，背后可能有意志（长期伏笔）
7. **学院净化原理**：学院来自第三位面（地球），地球属性产生"水油分层"隔离关闭裂隙。学院成员本身就是净化媒介
8. **法刺有两人**：幸（二号，外交/情报，表面外交部部长）+ 荣（头号，刺杀/颠覆，表面禁卫队队长）
9. **语气**：除代码和专业术语外，回答内容必须是中文
