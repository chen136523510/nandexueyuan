## 三、操作流程

### 3.1 登录

1. 打开 https://seedream.pro/zh/ai-photo-editor
2. 如未登录，点击右上角"登录"，用 Google 账号登录
3. 登录后右上角显示"退出登录"

### 3.2 单角色换动作/换场景（最常用）

**适用场景**：已有角色立绘，需要生成该角色在不同动作/场景下的插画

1. **输入提示词**：在提示词输入框填写修改需求
2. **上传参考图**：点击"拖拽图片到此，或点击上传"，上传角色立绘（最多4张）
3. **选择风格**：下拉框选择"油画"（与项目画风一致）
4. **选择比例**：根据需要选择（方图1:1 / 竖图9:16 / 横图16:9）
5. **点击"编辑图片"**：等待约20-30秒生成
6. **下载**：点击结果区的"下载"按钮，图片保存为 JPG

### 3.3 多人同框（2-3角色）

**适用场景**：多个角色出现在同一张插画中

1. **上传多张参考图**：依次上传2-4张角色立绘（标记为"主参考"+"参考图2"等）
2. **提示词关键**：必须强调以下要素，否则会变成拼图：
   - "两个角色并肩站在**同一个**场景中"
   - "统一光线，统一透视"
   - 分别描述每个角色的位置（左侧/右侧）和特征
3. **选择横图比例**：多人场景用 16:9 横图
4. 生成+下载

### 3.4 纯文生图（无参考图）

**适用场景**：设计新角色，无现有立绘参考

1. **切换到生成器**：访问 https://seedream.pro/zh/ai-image-generator
2. **输入提示词**：描述角色外观、服装、场景
3. **选择风格**：油画
4. **生成+下载**

## 四、提示词技巧

### 4.1 提示词公式（官方推荐）

```
[目标区域] + [具体改动] + [保持不变约束] + [风格/光线/质量细节]
```

### 4.2 换动作模板

```
保持角色面部特征、发型（[发色发型描述]）、服装（[服装描述]）完全不变，
将角色姿势改为[新动作描述]。
背景改为[新场景描述]。
油画风格。
```

**实测示例**（法刺幸：站立→伏案批阅）：
```
保持角色面部特征、发型（黑色长直发）、服装（深蓝色双排扣军装金色纽扣白色衬衫红宝石胸针）完全不变，
将角色姿势改为坐在书桌前伏案批阅文件，手中拿着笔，表情严肃专注。
背景改为皇宫办公室，有书架和暖色台灯光线。
油画风格。
```
✅ 结果：服装完全保留，动作自然改变，背景切换干净

### 4.3 多人同框模板

```
两个[性别]角色并肩站在同一个[场景]中。
左侧角色（参考图1）：[发色发型]、[服装描述]、[动作/表情]。
右侧角色（参考图2）：[发色发型]、[服装描述]、[动作/表情]。
两人面朝观众，背景是统一的[场景描述]。
同一场景，统一光线，统一透视。
油画风格。
```

**实测示例**（法刺幸+法刺荣同框）：
```
两个女性角色并肩站在同一条皇宫走廊中央。
左侧角色（参考图1）：黑色长直发，深蓝色军装，金色肩章纽扣，白衬衫，红宝石胸针，双手交叉胸前。
右侧角色（参考图2）：黑色短发，黑色军装，金色流苏肩章，红色腰带，手握剑柄。
两人面朝观众，背景是统一的宫殿走廊，两侧有石柱，地面大理石。
同一场景，统一光线，统一透视。
油画风格。
```
✅ 结果（第二次尝试）：两角色在同一场景中，统一光线透视

> ⚠️ **多人同框注意**：第一次尝试如果不强调"同一场景统一透视"，可能会生成左右拼接的拼图效果。务必在提示词中明确"同一场景，统一光线，统一透视"。

### 4.4 新角色文生图模板

```
[性别]，[年龄]岁，[外貌描述：发色发型/眼色/肤色]，
穿着[服装描述：颜色/材质/款式/配饰]，
[动作/姿态描述]，
背景是[场景描述]。
油画风格，奇幻插画，高质量。
```

## 五、注意事项

1. **广告遮挡**：页面有 Google 广告，可能遮挡按钮。用浏览器控制台执行以下代码移除：
   ```js
   document.querySelectorAll('.adsbygoogle').forEach(el => el.remove());
   document.querySelectorAll('iframe[id*="aswift"]').forEach(el => el.remove());
   ```
2. **生成时间**：约20-40秒，耐心等待
3. **文件格式**：下载为 JPG
4. **历史记录**：登录后可查看生成历史
5. **"继续改"功能**：生成结果可点击"继续改"进行迭代修改
6. **参考图上限**：最多4张参考图
7. **文件大小**：单张参考图不超过 10MB，支持 PNG/JPG/WEBP
