# 德塔（NDO）演出设计输出规范 v1.1

> **定位**：把「定稿台词」翻译成「可执行的视觉演出脚本」。演出设计是台词剧本与代码实现之间的桥梁——黑机按它出图、白机按它写码、院长按它验收。
> **适用范围**：所有章节/幕（序章四幕、第一章各幕、后续章节）。
> **提炼依据**：序章四幕落地实践 + 第一章第一幕落地实践（2026-08-06）。
> **校验状态**：v1.0 按第二幕演出设计实践校验，3 处缺口已补入 v1.1（见文末「实践校验记录」）。

## 1. 输出时机与流程

```
台词定稿（院长逐句过）→ 输出演出设计（本文档格式）→ 院长确认 → 黑机出图（按美术需求表）+ 白机写码（按演出设计）→ 联调验证
```

- 台词未定稿**不得**进入演出设计
- 演出设计**不改变台词**（发现演出与台词冲突时，回台词阶段处理）
- 院长确认演出设计后，黑机/白机才可并行开工

## 2. 输出物总览（每幕 5 件套）

| # | 输出物 | 内容 | 主要使用方 |
|---|--------|------|-----------|
| 1 | 🎭 立绘与表情设计表 | 本幕每个立绘键的触发节点/情绪/视觉表现 | 黑机（差分出图）、白机（portrait 字段）、院长（验收） |
| 2 | 舞台调度 | 站位图 + 入场/退场/表情更新时序（enter/exit/characters） | 白机（stage 字段） |
| 3 | 场景清单 | 每段背景图（复用/新出/占位）+ 切换点 | 黑机（出图）、白机（background 字段） |
| 4 | 内联演出标注 | 台词间 `[立绘: x → y]` / `[切背景]` / `[音乐]` / `[特效]` / `[CG]` | 白机（精确到节点的演出实现） |
| 5 | 美术需求表 | 新资产（立绘差分/背景/道具/CG）+ 优先级 + 出图提示 | 黑机（排期出图） |

## 3. 各输出物格式

### 3.1 🎭 立绘与表情设计表

置于每幕演出设计开头。表头固定：

| 立绘键 | 触发节点 | 情绪 | 视觉表现 | 备注 |

规则：
- **立绘键** = `角色id/表情键`（如 `dean/calm`、`xing/deal`），资产路径 `public/visualnovel/portraits/<角色>/<表情>.png`
- **触发节点** = 本幕中首次使用（或关键切换）该立绘的节点 id；跨幕复用的立绘也列出并标注「复用」
- **表情键命名**：normal/calm/serious/gentle/smile/cold/official/deal/warning 等（见《美术设计规范》§4.3）
- 每行末尾标注该立绘的资产状态：✅ 已有 / 🆕 待黑机出图（对应美术需求表条目）
- 立绘位置规则：脚部超出屏幕底、小腿中部对齐屏幕底（AGENTS.md 立绘纪律第 6 条），本表不重复描述

### 3.2 舞台调度

两部分：

**(a) 站位图**（ASCII）：每场戏谁在左/中/右，玩家视角居中。

```
【场次名】
   角色A(左)        角色B(中)        角色C(右)
```

**(b) 舞台时序表**：

| 节点 | 动作 | 内容 | 说明 |

- **动作**：`enter`（登场，带 portrait/position）/ `exit`（退场）/ `表情更新`（同角色换 portrait）/ `characters`（绝对声明重置）/ `延续`（无变化）
- **分支内表情节奏**（v1.1 新增）：核心选择的分支树内部，各子分支的表情起伏用「表情节奏附注」列出（独立小节，跟在时序表后）——格式：`| 子分支 | 角色表情变化 | 关键点 |`。适用于幸谈判态这类"态度随谈判起伏"的长戏
- 规则：
  - 角色一旦登场**持续在场**（舞台状态机制，见《美术设计规范》§4.4.1），直到显式 `exit`
  - **跨场景切换**（如塔楼→草原）用 `characters` 绝对声明重置舞台，不依赖上一幕状态
  - **同场景内**用 `enter`/`exit` 增量调度
  - `exit` 先于 `enter` 处理（避免同帧进出闪烁）

### 3.3 场景清单

| 段/节点 | 背景键 | 类型 | 说明 |

- **类型**：复用（已有资产）/ 新出（列入美术需求表）/ 占位（BG_FALLBACK CSS 渐变）
- **CG 复用背景的判定标准**（v1.1 新增）：CG 定稿图可复用为对话背景，需同时满足——①构图可承载对话（主体不居中挡字）②无需 HUD 遮挡适配 ③场景与剧情一致（如 CG-1 班走廊看月亮 ↔ 衔接段走廊夜）。不满足则列入新出需求（如「XX 背景（班入画）」）
- 规则：
  - 新背景**未出图前** → 占位（CSS 渐变），**不列 REAL_BG_MAP**（BUG-57 教训：会被当成有真实图而指向不存在的文件）
  - 出图后从 BG_FALLBACK 移入 REAL_BG_MAP
  - 切换粒度 = 节点；同段连续多节点同背景可合并行

### 3.4 内联演出标注

写在台词文本之间（剧本的演出设计副本中），格式：

- `[立绘: x → y]`：立绘切换（省略 x 表示登场，如 `[立绘: xing/deal 登场]`）
- `[切背景: bg/xxx]`：背景切换（节点 background 字段承担，此处标注视觉节奏）
- `[道具: xxx]`：道具演出（v1.1 新增）——关键道具的弹出/展示/签署等，如羊皮卷合同弹出、契约签署、纹路发亮
- `[音乐: xxx]` / `[音效: xxx]`：音频（可选，引擎能力范围内）
- `[CG: xxx]`：全屏 CG 演出
- `[特效: xxx]`：震屏/闪光等（引擎能力范围内）

### 3.5 美术需求表

| 需求 | 说明 | 优先级 | 出图提示 |

规则：
- 立绘差分**必须基于已定稿脸模/定版基准图**（表情差分原则，AGENTS.md 立绘纪律第 2 条）
- 带背景原图必须留存（AGENTS.md 立绘纪律第 4 条）
- **连幕防疲劳原则**（院长 2026-08-03 定）：同角色在相邻章节/连续两幕出场时，立绘至少变更一项（姿态基准/表情差分/服装细节），不得整套复用
- 新背景/道具/CG 同表列示，标注用途节点

## 4. 红线

1. 演出设计阶段**不产生新台词**（对话/旁白改动一律回台词阶段）
2. 未定稿台词不得进入演出设计
3. 演出设计需院长确认后才进入出图/写码
4. 立绘位置、三态交互、舞台状态等引擎/美术既有规则不在此重复，冲突时以《美术设计规范》与 AGENTS.md 为准
