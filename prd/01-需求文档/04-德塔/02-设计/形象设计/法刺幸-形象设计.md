## 2. 设计理念

**一句主轴**：「精致体面是她的壳，锐利试探是她的魂——一个每个细节都在微笑，但每个细节都在判断你的人。」

**这个角色与其他角色的不同点**：
- 与睿帝的区别：睿帝是权力的显性拥有者（银灰霸气，佩剑/法杖），幸是权力的隐性行使者——她不握剑，但她的话能让人低头。
- 与丘/杰的区别：丘和杰都带英雄气（游侠/领袖），幸不是英雄——她是大厅里最体面的客人，但走了之后你才发现她问走了你所有底牌。
- 与汪神/沐阳的区别：汪神和沐阳偏超然（元素/隐士），幸是入世的——她的精致是对世界的态度，是武器，不是装饰。

---

## 3. 命名哲学

「幸」—— 幸运的幸，谐音「信」与「芯」。

- **表层**：外交官是帝国的幸运，带来和平与友谊（表面人设）
- **中层**：「信」——她是睿帝的信使，传递的是暗探的情报，不是外交部公文
- **底层**：「芯」——她是法刺的核心之一，法刺二号，系统的「芯」，比表面的外壳更重要

**视觉转化**：信物中融入「芯/核」意象（见贯穿信物部分），暗示她不只是表面看到的外交官。

---

## 4. 贯穿信物

### 「芯核胸针」

| 项目 | 内容 |
|------|------|
| 形制 | 一枚指纹大小的古铜色圆形胸针，别在西服左领。中央镶嵌一粒深红玛瑙，玛瑙内嵌极细的秘银丝，在光下呈「芯状网络」纹路 |
| 材质 | 古铜底托 + 深红玛瑙（主石）+ 秘银丝（内嵌）+ 黑钢卡扣（背面） |
| 质感 | 表面磨砂哑光（不反光，不引人注意），但侧光可见玛瑙内部秘银丝如电路般细微发光 |
| 佩戴位置 | 左领，位置固定——从不更换，与每一套正式着装搭配 |
| 使用方式 | 表面是家族徽章/外交官身份装饰；实际是法刺微型通讯器——按压玛瑙可激活短距离密语传输（魔法+机械混合技术） |
| 象征意义 | 「芯」——她是法刺的核心，也是帝国的眼睛。玛瑙如凝固的血，秘银丝如她的网——优雅外壳下布满无形的线 |
| 识别标志 | 对普通人：一枚精致但不张扬的古董胸针；对同行/法刺同僚：玛瑙内闪烁的秘银网纹，是「自己人」的暗号 |

### 无武器
幸的外交官身份不允许公开携带武器。但她右手无名指戴一枚**素面黑银戒**——看似装饰，实为旋转式暗器（挤出毒针），极隐蔽。

## 5. 基础造型

### 整体印象
深色系高级套装，剪裁极为合身，面料质感上乘但色彩克制。远看是体面外交官，近看细节全是伏笔。

### 上衣

|------|------|------|------|------------|
| 外层 | 深靛蓝收腰长西装外套 | 深靛蓝（接近黑，偏蓝调） | 羊毛混纺 + 暗纹缎里 | 合身剪裁，肩部微垫不夸张，腰线明显但不紧身。翻领为平驳领，左领别芯核胸针。袖口内绣淡金色繁密帝国纹样（举手时隐约可见） |

## 6. 色彩与材质总表

| 部位 | 颜色 | 材质 | 质感关键词 |
|------|------|------|-------------|
| 发 | 深棕（近黑） | 直发，顺滑 | 丝光，自然垂落 |
| 眼 | 深灰蓝 | 虹膜偏灰蓝色 | 清澈，锐利，微笑时眼角微弯 |
| 皮肤 | 浅象牙白 | 细腻，薄妆 | 无瑕但非假面，颧骨微光泽 |
| 外套 | 深靛蓝 | 羊毛混纺 + 暗纹缎里 | 哑光，挺括，腰线合身 |
| 衬衫 | 珍珠白（暖调） | 真丝混纺 | 柔光，微透光不透视 |
| 西裤 | 深靛蓝 | 羊毛混纺 | 哑光，笔挺，九分收脚 |
| 短靴 | 纯黑（哑光） | 小牛皮 | 素面，尖头，静音底 |
| 胸针 | 古铜+红玛瑙+秘银 | 金属+宝石 | 磨砂哑光底，内部微光 |
| 袖扣 | 黑玛瑙 | 宝石+银托 | 素面光滑，无反射 |
| 戒指 | 黑银 | 硫化银 | 磨砂哑光，素圈 |
| 公文包 | 深棕 | 植鞣革（旧化感） | 有使用痕，黄铜件有氧化 |

**配色逻辑**：幸的配色整体偏深蓝+珍珠白+哑黑——冷静、克制、不张扬。唯一的色彩点缀是胸针的深红玛瑙，如一滴凝固的血，暗示她体面外表下的暗面。整体色彩饱和度低，不跳脱，是高级感的来源，也是暗探职业需求——不引人注目。

## 7. 上身顺序

1. 内搭（无）
2. 珍珠白暗纹衬衫（穿着顺序：穿 → 扣扣子到领下第二颗 → 法式袖扣扣好黑玛瑙袖扣）
3. 深靛蓝收腰长西装外套（穿上 → 左领别芯核胸针 → 调整胸针位置）
4. 深靛蓝长西裤 + 黑色尖头低跟短靴（检查裤脚银线是否在正确位置）
5. 右手无名指戴黑银戒（旋转检查毒针是否在位，锁定保险）
6. 检查深棕色皮质公文包（包底夹层密信/通讯石在位）
7. 最后检查：袖口内绣纹在举手时是否隐约可见 → 确定「体面但暗藏细节」的效果到位

**穿衣逻辑**：「先内后外，先装后饰。所有配饰最后检查，因为每件都有功能——不是装饰，是工具。」
