## 设计准则

1. **矛盾感优先**:每个角色的核心魅力来自内在矛盾(如睿的圣洁表象 vs 狠辣手段;丘的法外之徒 vs 体制顶端)。所有设计细节服务于这个矛盾。
2. **信物贯穿**:每个角色有一件贯穿所有形态/状态的信物,作为识别锚点。
   - 睿 → 黑玛瑙食指戒(指向施法)
   - 丘 → 箭羽(指向诛恶/立法)
   - 杰 → 弯刀「逸」(武力) + 臂环「九沙」(法理) [双信物]
   - 汪神 → 汪印(王权) + 阿瓦隆古卷(学者执念) [双信物]
3. **可执行性**:穿搭文档需含色彩材质表、上身顺序清单,可直接给造型师/画师/裁缝使用。
4. **形态切换**:多形态角色需提供状态切换表(同一套衣物的气场变化)。
5. **主线时间对齐**:角色的"在场形态"必须与游戏主线时间点(A.V.118)一致;已退场/失踪角色需提供"谜团形态"(肖像/回忆/重现剪影)。
