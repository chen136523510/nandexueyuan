# 见 · 形象设计（男德学院院长）

> 创作工具：院长口述 + AI 撰写

> 状态：v2 院长修订版（补命名哲学 + 贯穿信物 + 双面性格 + 结构对齐其他角色）

> 一位穿褪色黑袍的年轻魔法师。黑袍是壳，暖是骨，笑是刀。
> 兜帽一放，远客；兜帽一摘，院长；手一抬，天裂了。
> **对外是"让人不敢轻视的年轻院长"，对内是"让人哭笑不得的抽象大哥"。**

## 二、设计理念

**一句主轴**：「黑袍是异世界的保护色，英俊是上天的恩赐。对外，他是让人不敢轻视的年轻院长；对内，他是能把添聊到接不上话的抽象大哥——25岁的脸两副画，全看你是熟人还是生客。」

**设计关键词**：**少年老成 + 双面反差**。他才25岁，对外要有年轻人的朝气但比同龄人沉稳太多；对内则暴露本性——一个能让人笑、也能让人愣住的抽象人。穿搭要做的是：让他这身"务实随意"的黑袍，能同时承载"可靠领袖"和"搞怪大哥"两种状态——衣服不变，变的是他。

### 与其他角色的差异

| 角色 | 气质 | 与「见」的区别 |
|------|------|---------------|
| **睿帝** | 白袍 · 帝王威仪 · 权力宣示 | 睿帝的白袍是权力的显性宣示，见的黑袍是务实的隐忍选择。黑色耐脏、低调、适合在裂隙边缘活动——一个穿白袍治国，一个穿黑袍打仗 |
| **法刺幸** | 深蓝西装 · 精致外交 · 锐利试探 | 幸的精致是武器（外交场合试探），见的随意是真诚（他真不在意这些）。她每句话都在测量，他对外每句话都在定调 |
| **添** | 西装魁梧 · 东北大哥 · 热情外放 | 添的热情是外放喧闹的（拍肩说"走"），见的搞怪是冷峻抽象的（抬眼说一句让你愣三秒的话）。一个热得直白，一个怪得含蓄 |
| **法刺荣** | 半甲短发 · 军事统帅 · 冷厉寡言 | 荣的冷是磨出来的杀气，见的严肃是身份压出来的得体——本质不同。荣不笑是因为杀，见不笑是因为在"对外模式" |

**辨识度策略**：让他在一群"精致角色"中是一个"看不透"的存在——外人觉得他沉稳可靠，熟人觉得他抽象离谱。这种落差本身就是辨识度。

## 三、命名哲学

**「见」**——看见的见，远见的见。

- **表层·看见**：他是第一批降临者，是这群人里第一个「看见」这个世界真相、第一个发现"我们待着的地方裂隙会自己合上"的人。他看见了别人还没看见的可能。
- **中层·远见**：务实沉稳、话不多但句句到位。他不只是看见了当下，还看见了远处——把第二批漂泊者叫来，是因为他知道"人太少，草原的裂隙关了，远处还有"。这是一个有远见的人。

**视觉转化**：栗色的眼睛是他最亮的辨识点——那是一双"看见了什么"的眼睛。施法时瞳孔泛起的灰蓝微光，是"看见虚空本质"的视觉外化。他的项链（见贯穿信物）也是这层意思的物证。

## 四、贯穿信物

### 「虚空晶石项链」

| 项目 | 内容 |
|------|------|
| **形制** | 一根黑色编织绳，末端系一块**不规则形状的虚空晶石碎片**（约拇指盖大小），灰蓝色微光。不是打磨过的宝石，是天然碎裂的断面 |
| **材质** | 黑色编织棉绳（手编，非机制）+ 虚空晶石碎片（灰蓝色，半透明，内部有流动感微光） |
| **质感** | 绳子磨得发亮（3年没摘过），晶石断面锋利但被长期握持磨圆了棱角。整体朴素，不像首饰，像遗物 |
| **佩戴位置** | 套头戴上，垂于胸口。里衣领口微敞时露出 |
| **来历** | A.V.115 学院降临那年，他第一次成功闭合裂隙时，从裂隙残骸里掉落的碎片。他自己编了绳子穿上，3年没有摘过 |
| **象征意义** | ① 他的"第一次"——第一次证明地球位面的存在能闭合裂隙；② 他的"看见"——这块石头是裂隙闭合后的产物，是他看见这个世界本质的物证；③ 他的"远见"——随身带着它，是提醒自己"我们是有用的"，也是召唤第二批人的底气 |
| **识别标志** | 对普通人：一根旧项链，不引人注意；对学院成员：都知道这块石头的来历，是院长身份的隐性徽章。新来的漂泊者（玩家）会在剧情中得知它的故事 |
| **双面彩蛋** | 对外，他会下意识握一下晶石再开口（像在确认什么）；对内搞怪时，他可能把晶石含嘴里叼着、或拿晶石敲桌子打拍子——老成员看到就知道"院长又犯病了" |

## 五、核心造型：那件黑袍

不是普通的黑袍，要让它"旧"且"暖"。

| 维度 | 设计 |
|------|------|
| **廓形** | 宽松直身，不是收腰款（他不在意剪裁）。肩线自然，袖口微微收窄但不紧。整体感觉像一件被穿了三年的外套——有使用痕迹，有故事感 |
| **长度** | 及小腿中段。走动时下摆微微扬起，但不拖沓。比睿帝的白袍短一些——干实事的人袍子短一点 |
| **兜帽** | 中等大小，通常放下堆在肩颈。需要时可以戴上遮风挡雨（草原的天气说变就变） |
| **材质** | 外层深灰色粗纺棉麻混纺（哑光、有纹理感、耐脏耐磨）。内衬一层深棕色的棉布（保暖、有温度感） |
| **黑色** | 不是纯黑——是**洗褪的炭黑色**，带一点点灰调，像穿了三年从黑色褪成的深炭灰。有生活气息，不是崭新的 |
| **细节** | 左肩有一处缝补过的痕迹（用粗线缝合，不完美但结实）。袖口有轻微磨损。这些细节说明：这是一件被穿出来的衣服，不是道具 |

**黑袍的双面用法**（呼应性格）：
- **对外模式**：袍子相对整齐地敞开，兜帽放下堆好——看着得体可靠。
- **对内模式**：袍子可能半滑下一侧肩膀、袖子卷得一高一低、兜帽歪着没理——同一个抽象人穿出邋遢感。

## 六、黑袍里面的东西

黑袍微微敞开时（他从不系到顶），露出内搭：

- **里衣**：灰白色圆领棉质T恤（没错，就是T恤——从地球带来的）。领口微敞，露出锁骨和项链。面料柔软，有生活感。
- **项链**：见「四、贯穿信物」。

## 七、下装与足部

| 部位 | 品名 | 颜色 | 材质 | 细节 |
|------|------|------|------|------|
| 下装 | 直筒工装裤 | 深灰/炭色 | 厚棉帆布 | 裤腿塞进靴筒。侧面有大口袋（装东西用——他是务实的人）。膝盖处有轻微磨损 |
| 足部 | 及踝户外短靴 | 深棕色 | 磨砂皮 + 橡胶底 | 有使用痕迹，鞋带是更换过的（颜色略有不同）。厚底、抓地、适合在草原行走 |

---

## 八、手：施法的手

- **双手**：不戴手套。手指修长但有力，指节微粗（干过活的手）。手背有一道浅浅的旧疤（3年异世界留下的痕迹）。
- **施法姿态**：右手前伸，掌心向上，灰蓝色的光在掌心凝聚。姿态自然，不像睿帝那样有仪式感——他的魔法是工具，不是表演。
- **无首饰**：不戴戒指、不戴手链。25岁的年轻人 + 实用主义者 = 不搞这些。

---

## 九、头部与面部

| 部位 | 描述 |
|------|------|
| **发型** | 黑色短发，微微卷曲（自然卷），不刻意打理。额前有碎发，风吹过会乱。两侧收短，后脑自然生长。整体感觉：不用管也好看的那种 |
| **面部** | 英俊。五官立体但不过分锋利。下颌线清晰。眉毛浓但不粗。嘴唇薄，**对外默认状态下微微上扬（不是笑，是"看起来好相处"）；对内熟络时会露出抽象表情——挑眉、歪头、嘴角一抽，说些让人接不上的话** |
| **眼睛** | 栗色，温暖。看人时很专注，让人觉得被重视。施法时瞳孔边缘会泛出淡灰蓝色的光（虚空净化的视觉特征）。**同一双眼：对外是"我在听你说"，对内是"我又有主意了"** |
| **皮肤** | 小麦色，健康。不是养尊处优的白，是常年在草原户外活动晒出来的 |
| **胡须** | 干净。25岁不需要蓄须，他也没有那个习惯。偶尔忙起来会有一天的胡茬 |

## 十、色彩与材质总表

| 部位 | 颜色 | 材质 | 质感关键词 |
|------|------|------|-------------|
| 发 | 黑色（微卷） | 短发，自然卷 | 碎发，不驯服 |
| 眼 | 栗色（施法时灰蓝微光） | — | 温暖，专注 / 对内狡黠 |
| 皮肤 | 小麦色 | — | 健康，户外感 |
| 黑袍 | 炭黑色（洗褪感） | 粗纺棉麻混纺 | 哑光，有纹理，有使用痕 |
| 黑袍内衬 | 深棕色 | 棉布 | 保暖，有温度感 |
| 里衣 | 灰白 | 棉质T恤 | 柔软，生活感 |
| 工装裤 | 深灰 | 厚棉帆布 | 耐磨，实用 |
| 短靴 | 深棕色 | 磨砂皮 | 有使用痕，户外感 |
| 项链 | 黑色编织绳 + 灰蓝晶石 | 绳+晶石 | 低调，纪念意义，磨亮 |

**配色逻辑**：院长整体配色偏暗——炭黑+深灰+深棕。这不是为了酷，是因为深色耐脏、低调、适合在裂隙边缘的草原活动。唯一的亮点是琥珀色的眼睛和灰蓝色晶石碎片——温暖的底色和魔法的暗示。整体色彩饱和度低，是务实主义者的选择。

## 十一、上身顺序

1. 灰白圆领棉T恤
2. 黑色编织绳系虚空晶石碎片（套头戴上，调整到胸口位置）
3. 深灰直筒工装裤 + 深棕色户外短靴（裤腿塞进靴筒）
4. 炭黑色长袍（套入，敞开不系，兜帽放下堆在肩颈）
5. 整理：确认袍子下摆不绊脚 → 碎发是否遮眼 → 晶石是否在正确位置

**穿衣逻辑**：「先实用后装饰，先内后外。所有衣服都是为了在草原上活动——不是为了好看，但好看是附带的。」（注：对内搞怪时第5步的"整理"经常被跳过——于是就有了歪兜帽、卷错袖口的抽象造型。）

## 十二、状态切换

| 状态 | 场景 | 姿态 | 黑袍 | 表情 | 给人的感觉 |
|------|------|------|------|------|------------|
| **对内·学院内** | 和添/老成员相处 | 随意：靠墙、蹲着、抱臂、坐桌沿 | 敞开但可能半滑下肩、袖子卷得一高一低、兜帽歪着 | 放飞：挑眉、歪头、嘴角一抽、憋笑 | 把气氛搅成谜的搞怪大哥，卸了甲的25岁年轻人 |
| **对外·迎接生客** | 接待新漂泊者/外人 | 自然站立，双手下垂或抱臂 | 整齐敞开，兜帽放下堆好 | 微微上扬的嘴角，目光温和专注 | 让人放下戒备又不敢轻视的年轻院长 |
| **施法·净化裂隙** | 闭合裂隙 | 右手前伸掌心向上 | 随风飘动 | 专注沉静 | 年轻但可靠的魔法师 |
| **严肃·面对威胁** | 面对外部威胁 | 挺直站立 | 微微收紧 | 笑容收敛，目光沉静 | 25岁的脸，40岁的眼神 |

## 一句话总结

> **黑袍洗褪成了炭灰，T恤是从地球带来的旧物。对外，琥珀色的眼让人安心交托；对内，同一双眼能翻出让你愣三秒的抽象——院长不是靠袍子称王的，是靠"外人面前扛事，自己人面前卸甲"让人信的。**
