# 丘 · 形象设计

> 一个从林间走出,坐进议会的男人。
> 游侠时,他用箭指向恶人;总统时,他用笔指向律法。
> 箭与笔,是同一种"指向"。

---

## 一、角色档案

| 字段 | 内容 |
|------|------|
| 姓名 | 丘 |
| 性别 | 男 |
| 身份 | 游侠 / 总统(双形态) |
| **发色** | **黑色** -- 英文提示词 `black hair` |
| 原型参考 | 罗宾汉 |
| 性格关键词 | 嫉恶如仇 · 体贴平民 · 学识渊博 · 能文能武 |
| 能力标签 | 弓术 · 论文写作 · 律法制定 |
| 核心矛盾 | 法外之徒 vs 体制顶端;感性诛恶 vs 理性立法;草根出身 vs 精英学识 |

### 形象设计理念

丘最迷人的地方,是**他没有变成自己曾经反对的人**。

大多数"游侠登基"的故事会走向两种俗套:要么被权力腐蚀成圆滑政客,要么挂冠而去回归山林。丘两条都不走--他把游侠时期的锋利带进了议会,又把议会的学识带回了民间。

所以两套造型不是"前 / 后"的割裂,而是**同一个人的两面**。设计上必须有一条贯穿的线索,让人在总统形态里依然认得出那个林间的弓手。

### 贯穿三要素(两种形态都保留)

1. **绿色**:游侠是林绿,总统是墨绿--同一个绿,从鲜活到沉淀,像酒。
2. **箭羽**:游侠的箭羽,变成总统胸前的胸针、钢笔帽上的饰纹。**箭(诛恶)与笔(立法)是同一种指向。**
3. **左手腕的疤**:游侠时期留下的,总统形态也不遮。他不让权力洗掉过去,平民看见这道疤才信他。

## 二、游侠形态

> 林间 · 草根 · 随时拔箭

### 2.1 整体廓形

不对称、行动派、有修补痕迹。重点不是"帅",是"能跑能射能蹲下来和农夫说话"。

### 2.2 上身分层(由内到外)

| 层次 | 单品 | 细节 |
|------|------|------|
| **里衣** | 粗麻衬衫,本色偏黄 | 敞领,袖口卷至前臂。露出左手腕的疤。布料有洗到发白的地方,但不脏。 |
| **皮甲** | 轻甲,胸前整块鞣皮 | 护住心口与前胸,肩部有皮护肩但不连体--不影响拉弓。颜色是**深棕,用旧了发亮**。 |
| **斗篷** | 林绿色短斗篷,及腰 | **单侧搭肩,不对称**(右肩搭扣,左侧自由摆动)。方便右手拉弓。里侧有几个暗袋,装药草和干粮(体贴平民:他随身带药)。 |

### 2.3 兜帽

林绿色,比袍子的兜帽更浅、更轻。
- 戴上时只遮头顶,不遮脸--**他要让被劫的恶人和被救的平民都看清他的脸**。
- 嫉恶如仇的人不屑于藏。

### 2.4 腰带与挂件(关键)

宽皮带,棕色,磨损明显。挂件是这个人设的"身份证":

- **箭袋**:斜挂后腰,羽箭尾羽朝上,颜色鲜艳(林绿 + 一抹红羽)。
- **短刀**:左侧,直刃,朴素。割绳、切干粮、必要时补刀。不装饰。
- **卷轴筒**(学识标志):右侧,皮制,防潮。里面装的是他写的**律法草稿与论文笔记**。这是他和草寇的根本区别--他在林间就在思考秩序应该长什么样。

### 2.5 下身与足部

| 部位 | 设计 |
|------|------|
| **裤** | 收腿皮裤,深棕,膝部加强(常蹲常跪,和农夫平视)。 |
| **靴** | 及膝绑带靴,软底,无声。绑带是皮绳,不讲究。鞋头有泥--他不避泥土。 |

### 2.6 武器

- **长弓**:单体木弓,深色,弓身有使用包浆。背在身后,斜跨。
- 弓把处缠皮,防滑。没有任何雕花--这不是礼器,是工具。

### 2.7 游侠形态气质小结

> 走进村庄,农夫不怕他,孩子会围过来;走进恶人的庄园,守卫会下意识按住剑柄。
> 他蹲下来和老人说话时,斗篷上的泥点和腰间卷轴筒的皮革味同时存在。

## 三、总统形态

> 议会 · 律法 · 笔与印

### 3.1 整体廓形

合身、立挺、有威仪,但**不镶金、不缀宝石**。他的权力来自律法,不来自排场。

### 3.2 主服:墨绿立领长礼服

| 维度 | 设计 |
|------|------|
| **颜色** | 墨绿。从游侠的林绿沉淀而来,像陈年松针色,沉稳不黑。 |
| **剪裁** | 收腰、有垫肩。他的从容是打出来的,垫肩是他后天习得的"执政骨架"--游侠时期不需要撑,总统时期需要立。 |
| **长度** | 及膝下十公分,接近风衣长度,但更合身。下摆不开衩,庄严感。 |
| **领型** | 立领,扣到喉下第二颗。不敞--议会场合,他不卖弄英俊。 |
| **材质** | 优质羊毛,哑光,有垂坠感。不闪。 |
| **门襟** | 暗扣,一排五颗,扣面是哑光黑铁。 |

### 3.3 内搭与领部

- **衬衫**:本色白,高支棉,领口硬挺。
- **领巾**:暗墨绿色,丝质,窄版,在领口打一个**平结**(不打温莎--温莎太贵族,他不是)。领巾末端绣极细的箭羽暗纹,要凑近才看见。

### 3.4 胸前:那枚箭羽(贯穿信物)

左胸口袋上方,一枚**箭羽形胸针**:

- 材质:哑光黑铁,羽轴处镶一颗极小的**林绿珐琅**。
- 造型:一支向下的箭羽--向下,是"落下、落地、扎根民间"的意思。
- 这是游侠时期他箭袋里最后一支箭的羽,留下来的。从此不再射人,改作律法。

### 3.5 腰间

- **腰带**:黑色,窄,哑光皮。带扣是方形黑铁,极简。
- 不挂刀。**总统不挂刀,挂笔。**

### 3.6 手:笔与印

| 物件 | 设计 |
|------|------|
| **钢笔** | 哑光黑金属杆,笔帽顶端雕一支**微型箭羽**(与胸前胸针呼应)。这支笔签律法、批论文。 |
| **印章** | 不用蜡封,用按压式墨印。印面是一支**箭穿过一本翻开的书**--武与文、诛与立,都在一个符号里。 |

### 3.7 左手腕:那道疤(不遮)

袖口会微微露出左手腕内侧一道**陈年箭伤疤**。
- 不遮、不解释。
- 议会里有人质问他出身,他就把袖口往上卷一寸。无需多言。

### 3.8 下身与足部

| 部位 | 设计 |
|------|------|
| **裤** | 同色墨绿羊毛长裤,中缝熨线笔直。 |
| **鞋** | 黑色高帮皮靴,方头,光面。比游侠时的靴硬挺,但同样是靴不是皮鞋--**他骨子里还是那个会随时站起来的人**。 |

### 3.9 总统形态气质小结

> 他签署律法时,笔尖没有犹豫。旁人看他庄重,平民看他熟悉。
> 因为胸前那枚箭羽、腕上那道疤,都在提醒所有人:这个坐在这里的人,是从林子里来的。

## 四、两形态对照表

| 维度 | 游侠形态 | 总统形态 |
|------|----------|----------|
| **主色** | 林绿 + 深棕 | 墨绿 + 黑铁 |
| **廓形** | 不对称、行动派 | 合身、立挺、庄严 |
| **领部** | 敞领,粗麻 | 立领扣到喉下,丝质领巾 |
| **腰间** | 宽皮带 + 箭袋 + 短刀 + 卷轴筒 | 窄黑皮带 + 钢笔 + 墨印 |
| **武器 / 工具** | 长弓、箭 | 钢笔、印章 |
| **足部** | 及膝绑带软底靴,有泥 | 黑色方头光面高帮靴,硬挺 |
| **气质** | 可蹲下和农夫说话,可拔箭诛恶 | 可签署律法,可发表论文 |
| **共同信物** | 箭羽(箭袋里的羽) | 箭羽(胸前胸针 + 笔帽饰纹) |
| **共同伤痕** | 左手腕箭伤疤 | 左手腕箭伤疤(不遮) |

## 五、贯穿主线:箭 → 笔

这个角色所有设计的"题眼"是**箭羽**。

| 阶段 | 箭羽的形态 | 含义 |
|------|------------|------|
| 游侠 | 箭袋尾羽,鲜红一抹 | 诛恶的指向 |
| 过渡 | 最后一支箭,留下不射 | 决定不再用暴力解决 |
| 总统 | 胸前胸针 + 笔帽饰纹 | 指向转化为书写,诛恶转化为立法 |

> **他不是放下了箭,是把箭变成了笔。** 箭射一个人,笔护一片人。

---

## 六、学识的视觉表达(贯穿两形态)

"学识渊博、能发论文、能定律法"不能只是台词,要让人**看见**:

- **游侠形态**:腰间的卷轴筒(随时写)、里衣袖口常有墨痕(刚写完字就出林)、斗篷暗袋里有一小本册子(记录民情,这是律法的源头)。
- **总统形态**:案头永远有翻开的书(不是摆设,书页有折角有批注)、签署律法前会引用某篇论文(他自己的)、议事时手边有一本厚笔记。

> 他制定的律法之所以让平民信服,是因为那些条文是他蹲在田埂上写出来的。

## 七、双形态切换场景示例

| 场景 | 形态 | 关键动作 |
|------|------|----------|
| 林间伏击贪官押运 | 游侠 | 兜帽戴上(虽不遮脸),长弓上弦,箭羽轻响 |
| 农舍探望病重老人 | 游侠 | 斗篷暗袋取药,蹲下喂药,卷轴筒记下病情 |
| 议会签署新律法 | 总统 | 立领扣紧,箭羽钢笔落款,墨印按下 |
| 大学宣读自己的论文 | 总统 | 立领解开一颗,袖口微卷露出腕疤,讲到激动处以笔代箭指黑板 |
| 深夜灯下批注律文 | 总统(便装) | 礼服脱下搭椅背,只着白衬衫,左手腕疤在灯下清晰 |

## 一句话总结

> **箭是昨天的笔,笔是今天的箭。**
> **他不换颜色,只换工具;他不洗过去,只续律法。**
