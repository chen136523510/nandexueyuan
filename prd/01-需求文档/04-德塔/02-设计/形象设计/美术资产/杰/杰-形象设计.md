# 杰 · 形象设计

> 一个在帝国学过魔法、在共和国玩过齿轮、最后回沙漠建了国的年轻人。
> 他笑着,敞着领,刀随手挂着——
> 但他笑的时候在数你眨了几次眼,敞领下贴着软甲,那把"随手挂着"的刀只有他能一瞬出鞘。

| 出身 | 沙漠 |

| 能力标签 | 体术 · 近身格斗 · 冷兵器 · 魔法 · 科技 · 军事 · 立国 |

### 形象设计理念

杰的设计主轴只有一句话:

> **每一个看起来"狂傲"的细节,底下都藏着一个"警惕"的结构。**

他不是"有时狂傲、有时警惕"——他是**同时**狂傲和警惕。敞领不是为了帅,是为了让暗扣一扯就开能拔刀;刀明挂不是为了显摆,是诱饵,真正的杀招在暗处;笑得放肆的时候,眼睛在扫全场。

所以这份设计不用"前后两个形态",而是用**"表象 ↔ 内核"逐项对照**的主轴,外加四类场合的外层切换——因为他身上沙漠、魔法、科技、体术四重身份是**同时并存**的,不是时间线。

### 复合背景的视觉融合(关键)

四重背景不平均分配,而是有主次:

| 背景 | 视觉占比 | 体现位置 |
|------|----------|----------|
| **沙漠**(底色) | 60% | 整体色系、面料、廓形、信物 |
| **体术/冷兵器**(骨架) | 25% | 贴身剪裁、护具、武器——决定衣服"能不能打" |
| **魔法**(暗线) | 10% | 护具上的符文刻槽、武器上的导流纹 |
| **科技**(暗线) | 5% | 武器卡扣、护具的精密铰接结构 |

> 魔法和科技不抢戏,它们藏在沙漠的粗粝之下,是"懂行的人凑近才看得见"的细节。这正呼应他的警惕——真正厉害的东西,他不外露。

## 二、贯穿信物:弯刀「逸」

杰是冷兵器大师,他的信物就是他的主武器。

| 维度 | 设计 |
|------|------|
| **形制** | 短弯刀,刃长约45cm,沙漠游牧型,弧度优雅。 |
| **材质** | 沙漠星砂铁锻打,刀身呈暗银带极细砂纹——像被风沙磨过的月光。 |
| **魔法线** | 刀脊刻一道**幽蓝导流纹**(帝国研究院所学),施法时魔力可沿纹路汇聚至刀尖,使斩击附带魔法冲击。纹路平时暗淡,只有他注入魔力时才亮。 |
| **科技线** | 刀柄与刀鞘之间是共和国精密的**黄铜卡扣机关**,常人拔不出,他拇指一压即解,出鞘无声。这是"科技"的体现——别人以为刀是随手挂着,其实它被机械锁着,只有主人能瞬解。 |
| **狂傲 ↔ 警惕** | 狂傲:刀就明挂在腰侧,谁都能看见。警惕:它被锁着,且这把"明刀"是用来吸引注意的,他真正的近身杀招另见他处(见第七节)。 |
| **命名** | **「逸」**--一字两面,详见下文命名释义。 |

### 「逸」命名释义

「逸」一个字,同时住着杰的表象与内核。这不是明暗双名,是一个字的自洽。

**表象面(狂傲,世人所见)**

- **飘逸**:刀法身法飘逸放肆,少年意气飞扬,看着像在玩。
- **逸出常轨**:不守成规,不拜礼法--帝国研究院的魔法、共和国的科技,他都不守规矩地拿来用。
- **逸兴飞扬**:狂傲不羁,靠墙、喝酒、笑得放肆,正是"逸士"做派。

> 世人见刀名「逸」,见他其人,以为这是个飘逸不羁的少年。这正是他要的。

**内核面(警惕,死者方知)**

- **逸即不逸**:看着飘逸,实为锁杀。刀越飘逸,杀机越收得紧--飘逸是结构,不是散漫。
- **生机逸失**:沾刀者生机逸散。想逃的人,逸不出去。名字是安宁,效果是终结。
- **自警**:杰本人是**最不"逸"的人**。他建国、立法、统一九部落,把自己焊死在最重的责任上。刀名「逸」,是他放弃了的那条逸路,握着"逸"却选了"不逸",提醒自己--**松即死。**

> 一字之内,前半是他演给世界看的,后半是他活给自己用的。

### 「逸」与武器机制的呼应

| 机制 | 逸的体现 | 表/里 |
|------|----------|--------|
| 科技卡扣 | 出鞘如**逸**出,无声无息,刀"逸"出鞘 | 表(飘逸) |
| 魔法导流纹 | 刀芒如**逸**,逸出刃身,难以捉摸 | 表(飘逸) |
| 明挂诱敌 | 刀看着随意挂着,飘逸不设防 | 表(飘逸) |
| 真正杀招在暗刃 | 杀机**不逸**出视线,锁死必中 | 里(警惕) |

前三"逸"是表象的飘逸,第四"不逸"是内核的警惕--与杰"狂傲表象↔警惕内核"的主轴同构。

## 三、基础底装(内核层,所有场合共用)

这是杰的"第二层皮肤",无论外面套什么,里面永远是这一套。因为他是体术格斗家,底装必须能打。

### 3.1 里衣

- **款式**:无领、交叉襟、收袖的紧身短上衣,下摆齐腰(不盖过腿,方便踢扫)。
- **颜色**:灼白(沙漠烈日色,也是他狂傲的亮色)。
- **材质**:沙漠高密棉麻,贴身、吸汗、有骨感。洗得发亮但不脏。
- **领口**:交叉襟敞开至胸骨——**这是"狂傲"的最大视觉符号**,但底下紧接着是软甲(见3.2)。

### 3.2 软甲(警惕的内核)

藏在里衣之下、贴着皮肤的一层薄甲,是"敞领"之所以敢敞的底气:

- **覆盖**:喉口、锁骨下、前胸、肋侧、脊椎沿线。
- **材质**:沙漠鞣制的薄牛皮,内衬锁子甲细环(共和国精密锻造工艺,环极细,不显臃肿)。
- **魔法线**:胸口甲片内侧刻**幽蓝防护符文**(研究院所学),受击时符文微亮,可抵消一次魔法伤害。他从不告诉别人这事。
- **厚度**:薄到穿里衣看不出来——除非他主动扯开领口,没人知道他随时甲不离身。

### 3.3 下装

- **裤**:灯笼型收腿裤,沙漠棉麻,赭红色(血脉与战争色)。膝部以下收紧绑腿,利落不绊腿。
- **绑腿**:砂洗皮革,交叉缠绕至膝下,既是护具也是为了在沙地行军防磨。绑带末端塞入靴筒。

### 3.4 足部

- **靴**:及踝,沙漠高帮,硬底(踩碎石用)但靴筒软(不影响脚踝活动)。
- **颜色**:深棕,磨损明显,鞋头有沙痕。
- **隐藏**:左靴外侧暗袋插一柄**投掷短匕**(见武器谱)。

### 3.5 手部(体术家的手)

- **缠手带**:双手指节至手腕缠砂洗皮条——格斗家的标配,护指、防滑、增力。
- **不戴手套**:他要感受刀柄和对手骨骼。缠手带而非全包手套,是"既要护手又要触感"的取舍。

## 四、主轴:狂傲表象 ↔ 警惕内核(逐项对照)

这是杰所有设计的题眼。下面这张表是这份文档的灵魂:

| 狂傲(别人看见的) | 警惕(别人看不见的) | 设计意图 |
|------|------|----------|
| 交叉襟敞开至胸骨,露大片皮肤 | 敞领下贴身软甲+魔法防护符文 | 露是为了诱人攻击要害,攻击了才发现砍不动 |
| 衣服不系扣,松松垮垮 | 暗扣设计,一扯即开完全不影响拔刀/起腿 | 松散是"我随时能动"的预备姿态,不是散漫 |
| 弯刀「逸」明挂腰侧 | 刀被科技卡扣锁着,且是诱饵,近身杀招在暗处 | 明刀吸引注意,暗处才是致命 |
| 步伐大、随意、靠墙站着 | 重心永远在前脚掌,脚位随时能弹射 | 慵懒是演的,发力结构是真的 |
| 笑得放肆,言语张狂 | 笑时眼球在扫描全场、数人、记方位 | 狂是社交武器,眼睛是真正的武器 |
| 发型不羁,碎发挡额 | 碎发只挡额头不挡眼眶,视野永远清 | 造型不影响0.1秒的反应 |
| 不穿大君礼服招摇过市(平时) | 礼服随时在随从处备着,需代表国体时瞬换 | 该狂时狂,该立时立,切换权在他 |
| 随身带酒囊,时不时喝一口 | 酒囊里大半是水,且他从不真喝醉 | "酒鬼"是人设,清醒是底线 |

> **一句话:他的每一处"松",都是一种"紧"的预备。**

## 四点五、少年急躁的破绽(必须保留的真实感)

> ⚠ **与设定集对齐**:杰现在才20岁（主线A.V.118），建国刚起步（统一宣言A.V.113，主线A.V.118仅5年），设定集明确写"**有年轻人的急躁**""**对建国模式仍在摸索**"。他不是算无遗策的老狐狸——警惕是他的天赋,但急躁是他的年龄。这些"破绽"不是bug,是让这个少年大君真实可信的关键。

警惕是骨,狂傲是皮,**少年急躁是会从骨缝里漏出来的血**。设计上必须留几处"漏出来"的痕迹:

| 破绽(别人偶尔能看见的) | 设计意图 | 出现时机 |
|----------------------|----------|----------|
| **腰带上的空铭牌位** | 七核心部落已签,但还有部落没拿下。腰带上预留的空位,是他急躁的具象——"还没统一完" | 议事场合,不经意露出 |
| **国印按歪过一次的痕迹** | 印面边缘有一道被磨平的旧痕——他第一次盖国印时手抖了。现在盖得稳,但那道痕他没换印 | 签协议特写时可见 |
| **袖口/指节的墨渍** | 议事前他还在偷偷翻笔记、背流程。他建国模式仍在摸索,得现学 | 议事、外交场合 |
| **偶尔的握拳/咬唇** | 警惕是常态,但遇到触及"统一"核心议题时,少年锋芒压不住——握拳、咬唇、眼神过亮 | 谈判僵局、被质疑法理时 |
| **弯刀「逸」的无意识把玩** | 思考或焦躁时,拇指会反复按压卡扣(出鞘机关)。这是个坏习惯——暴露了卡扣位置,但他改不掉 | 等待、思考时 |
| **比法定年龄更重的黑眼圈** | 24岁的人,眼下却有熬夜的青痕。建国不是请客吃饭,他在硬撑 | 近景特写 |

> **警惕让他活到24岁,急躁证明他确实只有24岁。** 一个没有破绽的少年君主是假人;一个漏着急躁却依然没人能杀他的少年,才是杰。

### 生图时的优先级

- **标准像/正式场合**:警惕+狂傲为主,急躁破绽克制(只露一处,如黑眼圈或空铭牌)
- **私下/疲惫状态**:急躁破绽加重(墨渍、咬唇、把玩卡扣),展现"少年扛着不该扛的重量"
- **绝对禁止**:把杰画成"完全成熟的中年谋士脸"——他必须看起来年轻,锋利但未定型

## 五、四类场合外层切换

杰的身份同时并存,不像游侠登基有前后转变。他根据场合在底装外**套不同外层**,体现不同身份侧重。底装(第三节)永远在场。

### 5.1 沙漠行军(军事/征战)

> 身份侧重:大君 + 军事统帅

- **外罩**:**沙暴斗篷**,赭黄色,及膝,带兜帽。面料是沙漠粗织,防风沙、白日遮阳、夜里御寒。
- **兜帽**:戴或不戴取决于沙况,不是装酷——务实。
- **肩甲**:左肩一片锻铁护肩(仅左肩,持刀手一侧),铁面有沙漠部落的**赭红几何纹**。右肩无甲,保证右手灵活。
- **腰封**:宽皮带,挂「逸」+ 水囊 + 行军干粮袋。皮带上缀各部落协议时赐予的**小铭牌**(每签一个部落加一块),这是他"统一者"的身份证明,也是外交成绩单。
- **气场**:尘土满身,但眼神比沙暴更利。士兵见他,信的不是他的头衔,是他靴上的沙和腰上的部落铭牌。

### 5.2 议事建国(国体/外交)

> 身份侧重:大君 + 立法者

- **外罩**:**沙金色立领长袍**,及小腿,外层沙漠羊毛,内衬一薄层丝(唯一的奢侈,藏在内里不外露)。
- **领型**:立领,但**不扣**(狂傲),领口敞一颗,露出底装灼白领口的层叠——这是他"我是大君但我不端着"的宣言。
- **臂环**(大君信物):左上臂一枚**锻铁臂环**,粗犷,环面铸沙漠统一的**九部落图腾**合并纹样。这是沙漠部落首领的传统信物,他戴铁不戴金——金是别国的王,铁是沙漠的王。
- **腰间**:不挂「逸」(议事场合),换一条窄皮带挂**国印**——印章为方形锻铁,印面是"日、沙、刀"三符号合一的国徽。
- **气场**:他靠在王座扶手上,一条腿搭着,不像个王。但他开口定国体、落印签协议时,全场没人敢出声。

### 5.3 研究院/工坊(魔法+科技)

> 身份侧重:魔法师 + 科技钻研者

- **外罩**:**深褐工坊长衫**,及大腿,袖口可卷可放,布料上总有洗不掉的试剂痕和油渍——他不介意,这是学者的勋章。
- **护臂**(魔法+科技融合件,重点):双前臂各戴一只**复合护臂**——
  - 主体:砂洗皮,贴前臂,不妨碍格斗。
  - 魔法面:外侧刻三组**幽蓝符文槽**,可临时嵌入魔法石,用于施法时增幅。
  - 科技面:内侧有一排**黄铜微型铰接关节**,使护臂能随握拳自动收紧——这是共和国机械学的应用,让护具"会动"。
- **腰挂**:一排精密小工具(镊、钳、放大镜)+ 一本皮面笔记,封面是他手写的魔法-机械融合公式。这本笔记是他能"发论文"的依据。
- **气场**:工坊里的他和战场上判若两人——安静、专注、手指沾墨。但你看他记笔记的握笔姿势,和握刀一模一样。

### 5.4 近身格斗(体术/冷兵器)

> 身份侧重:格斗家 + 冷兵器大师

- **外层**:全部脱掉,只留**底装**(里衣+软甲+下装+缠手带)。打之前他会把斗篷/长袍一扯扔给旁边人——这个动作本身就是威慑:我要认真了。
- **武器**:见第七节武器谱。「逸」+ 暗藏的投掷匕 + 近身短刃。
- **发带**:开打前用一条赭红布带把碎发束起——平时挡额是为了帅,打的时候必须露全视野。
- **气场**:一上擂,所有"狂傲"的松散瞬间收成一种**弹簧压紧的紧绷**。笑还在,但笑成了猎手的笑。

## 六、沙漠大君信物:臂环「九沙」

除了弯刀「逸」,作为大君他还有一件**王权信物**(只在5.2议事场合戴),与刀的信物分工不同:

| 维度 | 设计 |
|------|------|
| **形制** | 左上臂一枚开口式锻铁臂环,粗犷厚重。 |
| **纹样** | 环面铸九道平行凹槽,代表统一的九大部落;每道槽内嵌一粒该部落的**特色砂石**(每部落一种颜色)。这是"协议"的物质化——他把协议戴在手臂上。 |
| **材质** | 锻铁(沙漠王的铁,非金非银)+ 九色砂石。 |
| **狂傲 ↔ 警惕** | 狂傲:戴着它就是"我统一了你们"。警惕:开口式设计,一拧即脱——议事时若遇刺,臂环不会成为累赘。 |
| **象征** | 刀「逸」是他个人的武力,臂环「九沙」是他建国的法理。一刀一环,武与法。 |

## 七、武器谱(冷兵器大师的装备)

杰是冷兵器大师,不可能只有一把刀。他的武器配置同样遵循"明暗相济":

| 武器 | 位置 | 性质 | 用途 |
|------|------|------|------|
| **弯刀「逸」** | 腰侧明挂 | 明 / 主武器 | 沙漠弯刀,魔法导流+科技卡扣。明面上的招牌。 |
| **投掷短匕** | 左靴外侧暗袋 | 暗 / 远程 | 投掷用,平衡性极佳,可断十步外烛火。格斗时先手投出制造破绽。 |
| **贴身短刃** | 后腰脊椎处,贴软甲暗藏 | 暗 / 近身杀招 | 直刃,无护手,极短。这是「逸」作为诱饵时,他真正的近身杀招——别人盯着他的弯刀,他另一只手已经摸到了你肋下。 |
| **长柄戈**(战争用) | 行军时由侍从背负,战时取用 | 明 / 战场兵器 | 沙漠长柄戈,统一战争时的主兵器。非单兵装备,是统帅兵器。 |

> **冷兵器大师的哲学:别人一把刀用一生,他用三把刀演一场戏。**

明处的「逸」吸引你的眼睛,靴里的匕逼你躲,而贴着脊椎的短刃——你根本没看见——已经决定了结局。这套配置本身就是他"狂傲表象 vs 警惕内核"的物化。

## 九、上身顺序(以"议事场合"为例)

1. **软甲**:喉口、前胸、肋侧贴身上锁,魔法符文朝内。
2. **里衣**:灼白交叉襟,敞至胸骨,盖住软甲但不系扣。
3. **下装**:赭红收腿裤 + 深棕绑腿。
4. **缠手带**:双手指节至腕缠好。
5. **靴**:深棕高帮,左靴暗袋插入投掷匕。
6. **贴身短刃**:后腰脊椎处,贴软甲藏好。
7. **弯刀「逸」**:腰侧卡扣锁好(此场合为议事,可挂可不挂,依威慑需要)。
8. **外层**:沙金立领长袍,领口敞一颗,露出灼白领口层叠。
9. **臂环「九沙」**:左上臂戴上。
10. **国印**:窄皮带挂腰。
11. **发带**:平时碎发挡额;若气场收紧,赭红布带束发。
