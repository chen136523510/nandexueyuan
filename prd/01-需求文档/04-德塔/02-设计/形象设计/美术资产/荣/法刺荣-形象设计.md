# 形象设计文档：法刺·荣

## 1. 角色档案

- **姓名**：荣（法刺代号·荣）
- **性别**：女
- **年龄**：约35岁（比幸年长、位阶更高）
- **出身**：某被虚空裂隙摧毁的村庄孤儿 → 被睿帝捡到 → 睿帝亲手培养 → 帝国禁卫队队长 → 法刺头号人物
- **履历**：帝国禁卫队队长（公开身份），统帅禁卫队。实际为法刺头号战力。睿帝从废墟中捡到的孩子，被铸成帝国最锋利的刀。
- **性格关键词**：**领导气质**、军事统帅、冷厉、寡言、精准、对睿帝绝对忠诚（报恩+信仰）、短发干练
- **核心矛盾**：她是帝国最锋利的刀，但刀用久了也会有裂纹。她开始对自己执行的任务产生零星质疑——不是质疑睿帝，而是质疑「为什么总是杀掉而非拯救」。

## 2. 设计理念

**一句话主轴**：帝国之刃——不是优雅的花式剑术，是精准、无声、出鞘必中的杀戮器械。

**与幸的视觉区分**：
| 维度 | 幸（文·外交） | 荣（武·暗杀） |
|------|-------------|-------------|
| 气质 | 精致优雅 | 凌厉干练 |
| 体态 | 修长、有曲线、站姿从容 | 精瘦、肌肉线条清晰、站姿低位重心（随时拔刀） |
| 服装 | 收腰西装+衬衫 | 半甲+软甲+束袖战斗服 |
| 配色 | 深蓝/珍珠白/低调金 | 黑/银灰/暗红（血） |
| 剪影 | 细长、利落、窄肩线 | 中短、肩线略宽（甲片）、收腰但不突出曲线 |
| 发型 | 半束发，优雅盘起 | 短发（bob cut），干练利落，领导气质 |

## 3. 命名哲学

「荣」在帝国语中意为「尖刺」——不是花，是刺。法刺的命名体系：核心成员以「刺的形态」命名。幸意为「钩」（卷曲、试探、钩出情报），荣意为「刺」（直、锐、一击毙命）。

视觉转化：所有服装线条以「锐角、直线、锥形」为主，没有圆润弧线。

## 4. 贯穿信物

**武器·刺刃**（专属双头短刃）

| 属性 | 设计 |
|------|------|
| **形制** | 两柄拼接可成闭环刃的短刃，双持或单持。刃长约25cm，背厚脊薄，尖端极度尖锐。柄尾可弹出第二段——形成**短矛/刺穿形态** |
| **材质** | 刃身：哑黑钢（表面经发黑处理，不反光——夜袭用）+ 暗红酸蚀纹路（横向三道，如血经）<br>柄：黑檀木裹银线防滑，末端法刺暗记浮雕 |
| **使用** | 荣从不拔刀威吓。刀出鞘=目标已判死刑。她的握法很特殊——反手握（刀尖朝下，从下往上挑刺，无声高效） |
| **意义** | 这对刃是睿帝亲手赐予的。每一道暗红纹代表她完成的一次「不可能任务」。三道的含义：①刺杀叛教教主 ②颠覆大草原前政权 ③清除内鬼 |

**法刺共同识别元素**：所有法刺核心成员在制服内侧有**帝国鹰爪纹银线绣**（爪握三芒星——象征捕获、穿刺、灭迹）。幸的绣在胸针衬底内侧（隐蔽），荣的绣在**甲片内衬肩带**（同样隐蔽但更战斗化——任务中脱甲时才会露出，是身份的最终认证）。

## 5. 基础造型

### 上身 / 外甲 - 战术半甲
- **形制**：左肩全覆盖甲片（三层哑黑钢片叠压），右肩无甲（便于挥刃+行动习惯）。半甲从肩到上腹，腰部无甲（保持灵活）。甲片边缘是锐角V形切割，不是圆润弧形
- **颜色**：哑黑（反光率最低的含矿物漆涂装）
- **质感**：甲片表面有轻微锤纹（手工打造，战损感）+ 磨砂黑牛皮绑带固定
- **细节**：左胸位有帝国禁卫队徽记（银灰色线绣鹰徽，可撕下——出任务时撕掉后露出下方法刺暗记）

### 上身 / 内层 - 高领锁子软甲衣
- **形制**：全高领，从脖子到腰腹的极细锁子甲（孔径仅2mm）+ 内衬密织玄黑丝
- **颜色**：铁灰（非亮银，有磨损感）
- **质感**：微有金属光泽，但整体偏哑；颈部领子的锁子甲织成小菱形花纹（唯一装饰）
- **功能**：防割喉、防刺穿，轻便无声

### 下身 - 战术长裤 + 小腿束带
- **形制**：利落的直筒黑色长裤，裤脚收口入靴，裤缝外侧有一条**暗红细线**（从左胯到鞋口，一条直线——呼应刺刃的暗红纹）
- **颜色**：哑黑（同半甲配色）
- **质感**：厚棉斜纹布 + 膝部加厚层（深灰磨砂皮革内嵌软铁片）
- **腿部细节**：大腿外侧绑有**投掷匕首袋**（四柄小型飞刀，柄尾露在外面）

### 足部 - 全黑软底作战靴
- **形制**：靴筒到小腿中段，靴口V形剪裁，走步无声，靴底暗纹减噪
- **颜色**：全黑（无金属扣、无反光件）
- **质感**：磨砂牛皮 + 靴口内衬一层薄铁皮（防割踝）
- **功能**：鞋底嵌入小型消音垫片

### 头部 - 短发 + 干练
- **发型**：**黑色短发（bob cut）**，齐耳长度，不遮挡视线。无刘海，露出额头和锐利的眉眼。短发是她领导气质的体现--不需要装饰，干净利落就是态度
- **颜色**：**纯黑**（raven black，用raven black修正--novaAnimeXL中纯黑会偏蓝）
- **质感**：发丝整齐服帖，不蓬乱。偶尔有几缕被风吹起，但不影响整体干练感

### 面部特征
- **眼形**：细长丹凤眼，不怒自威，眼尾微微上挑（非媚态，是猎食者的聚焦）
- **眉形**：弯弓眉，眉峰利落，与眼尾角度呈现「锐角三角」
- **唇形**：薄唇，无唇彩，自然血色偏苍白
- **肤质**：冷白皮（比幸偏冷，因长期夜间行动很少见日晒）
- **表情**：大多数时候面无表情，不是冷傲，是**没有必要浪费表情**

### 配饰（极少）
- **颈饰**：无项链、无丝巾——任何可能被抓住的东西都在禁制清单里
- **耳饰**：左耳有一个极小的**黑铁环**（无装饰，尺寸1cm，就是单环）
- **腰带**：哑黑牛皮宽腰带，银灰色铁扣头（扣头形状=帝国鹰徽简化版，不带翅膀——只有禁卫队才用无翼鹰）
- **手套**：不戴手套（握刃时需要直接接触手感），但左手腕绑有一条**黑色窄皮革护腕**（藏有一枚细针——最后一手自杀/灭口用）

## 6. 色彩与材质总表

| 部位 | 颜色 | 材质 | 质感关键词 |
|------|------|------|-----------|
| **头发** | 纯黑 (raven black) | 丝质细发 | 短发bob cut、干练利落 |
| **皮肤** | 冷白 | 平滑、无瑕疵 | 冷调、苍白 |
| **眼睛** | 铁灰 | 虹膜带细微金属光泽 | 瞳孔如针、聚焦、冷酷 |
| **内衫（软甲）** | 铁灰 | 锁子甲 + 玄黑丝内衬 | 细密织纹、磨损感 |
| **外甲（左肩半甲）** | 哑黑 (#1C1C1C) | 三层叠压黑钢 + 锤纹 | 战损、非反光、锐角切割 |
| **长裤** | 哑黑 | 厚斜纹棉布 + 膝部皮革 | 利落直筒、外侧暗红线 |
| **靴子** | 全黑 | 磨砂牛皮 | 软底无声、V形靴口 |
| **护腕** | 哑黑皮革 | 窄皮革绑带 | 无装饰、内含针 |
| **刃（刺刃）** | 哑黑钢 + 暗红纹 | 发黑钢、酸蚀纹 | 不反光、三道血经 |
| **耳环** | 铁灰黑铁 | 单环 | 极简 |
| **暗红线（裤缝）** | 暗红 (#4A0E0E) | 直线刺绣 | 唯一色彩点缀 |

## 7. 上身顺序

1. **内层**：高领锁子软甲衣（护颈、护躯干）
2. **下装**：战术长裤 + 绑匕首袋
3. **足部**：作战靴（V形靴口扎住裤脚）
4. **护腕**：左手腕绑黑皮革护腕（含针）
5. **外甲**：战术半甲（左肩覆盖，右肩无甲。绑带交叉固定，鹰徽在左胸可撕）
6. **武器**：双持刺刃，反手握，交叉插在腰后鞘（鞘口斜向45°，拔刀轨迹最短）
7. **头部**：整理短发，挂左耳黑铁环

## 8. 一句话总结

**帝国铸就的刀：不是暗处的刺客，是阳光下统帅禁卫队的军事领袖--短发干练，军装笔挺，被睿帝从废墟中捡来，铸成帝国最锋利的刀。**
