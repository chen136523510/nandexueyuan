## 二、设计理念

**一句话主轴**：「白天起哄架秧子，晚上磨刀不眨眼。」

班是学院里最会活跃气氛的人，也是关键时刻下手最狠的人。他对内是兄弟们的开心果，对外是不留活口的狠角色。这两面同源--他太在乎这群人了。

**与其他角色的差异**：
- ≠ **添**（魁梧厚重/西装/接地气大哥）-> 班是精干利落，动作快，不是壮汉型
- ≠ **见**（旧黑袍/沉稳/院长气度）-> 班穿黑夹克，气质更锐利更街头
- ≠ **杰**（金发/部落领袖/狂傲）-> 班是黑发黑瞳，不发亮，不发声，不张扬
- ≠ **丘**（游侠/嫉恶如仇）-> 班的狠是沉默的，不是义愤型的

**辨识度策略**：在一群"有标志色"的角色里（金/蓝/银/白），班是全黑系--黑发黑瞳黑衣，像一道影子。他的辨识度不靠颜色，靠**气质的突然切换**：上一秒在起哄，下一秒眼神就冷了。

## 三、命名哲学

**「班」**--取"班师回朝"的班，也取"班底"的班。

他是学院的班底，是最早跟着院长扎根的那批人。名字听着像绰号，叫着叫着就只剩一个字了，没人记得本名。他自己也不提。

**视觉转化**：无显性刻字（区别于添的皮带刻"添"），他的存在感靠行为而非物件。

## 四、贯穿信物

**信物名称**：磨牙石吊坠

**形制**：一块拇指大小的粗糙磨刀石碎片，用旧皮绳穿成项链挂在脖子上。石头表面被磨出一道道细痕，边缘包了铜丝防止割断皮绳。

**来历**：伤疤那场战斗中救下的队友，后来在一次裂隙行动中失踪（推定阵亡）。这块磨牙石是那个队友留下的唯一遗物--他生前习惯战斗前磨刀，班接过了这个习惯。

**使用方式**：
- **对内**：闲时取下来在指尖转着玩，或无意识地磨指甲边缘（松弛感信物）
- **对外**：战斗/出行前取下来快速磨一遍匕首刃口（准备态信物）

**意义**：
- 对内调皮的一面：把玩件，像转笔一样转石头，是他"没正形"的视觉符号
- 对外狠辣的一面：磨刀石，杀人前的最后一步仪式
- 伤疤的锚点：每次磨刀时背上的旧伤会隐隐发痛--提醒他这块石头是谁留下的

## 五、基础造型

### 整体轮廓（剪影）
- **精干利落型**（lean muscular / athletic build），线条紧实，不臃肿不厚重
- 肩宽腰窄，倒三角但不过分夸张，是"能扑出去救人"的爆发型体格
- 站姿随意，重心常偏一条腿，手习惯插夹克口袋或搭在腰间（靠近匕首位置）
- 动作快、步幅大，走路带风

### 体型细节
| 部位 | 描述 |
|------|------|
| 身高 | 中等偏高（175-178cm），不靠身高压人，靠速度和气场 |
| 体格 | lean muscular，精壮不臃肿，肌肉线条紧实可见但不夸张 |
| 肩颈 | 肩宽，脖子修长（区别于添的"没脖子"壮汉型），肩线利落 |
| 四肢 | 四肢修长，手指骨节分明，手背可见青筋--是"快"的体型 |

### 头部

| 部位 | 描述 |
|------|------|
| 发型 | **中分黑色短发**。头发顺直，中分线清晰，两侧自然垂下盖住部分耳朵，后颈处收短。不油不亮，自然的哑光黑。干净但有型，比添的寸头"长"一点，比见的微卷"直"一点。 |
| 眼色 | **黑瞳**（纯黑/极深褐）。不与任何角色做眼色区分--班不需要靠眼色辨识，靠气质切换。 |
| 眉骨 | 略高，自然状态下显压迫感（对外冷酷的来源）；笑起来眉尾下压，变成玩世不恭 |
| 眼型 | 略狭长，眼尾微挑。不笑时眼神锐利如刀，笑起来眯成缝（调皮感的来源） |
| 鼻梁 | 高且直，侧面轮廓锋利 |
| 嘴角 | **嘴角天生带一点上扬弧度**（玩世不恭的视觉信号），不笑也像在憋笑 |
| 下颌 | 锐利下颌线，线条干净 |
| 皮肤 | 偏白但不病态，有户外痕迹但不深（比添白，比见深一点） |

### 伤疤（剧情锚点）
- **位置**：左肩胛骨延伸至腰际，三道平行爪痕（兽型虚空生物所伤）
- **状态**：愈合后呈浅粉色凸起疤痕，平时被衣服完全遮住
- **触发**：天气变化/裂隙靠近时隐隐作痛（学院人感知裂隙的具体化表现）
- **立绘处理**：基准立绘不露伤疤（服装遮挡）。暂不出负伤态差分。

> 出图顺序：先脸模 -> 再基于脸模出两套立绘。第一章只用「日常装」。

### 套装 A：日常装「送葬人」（第一章基准立绘）

## 九、表情差分规划

> 第一章基准立绘 = 日常装「送葬人」。表情差分按剧情情绪拆分。

| 表情键 | 触发场景 | 情绪 | 第一章是否需要 |
|--------|---------|------|:---:|
| `normal` | 默认/日常起哄 | 嘴角上扬、玩世不恭、眉尾下压 | ✅ 基准 |
| `grin` | 幕间起哄挤兑添 | 坏笑、眯眼、嘴角上扬加大 | ✅ P1 |
| `serious` | 归途报信（帝桥调兵） | 笑意收尽、眉骨抬起、眼神沉 | ✅ P1 |
| `cold` | 对外冷酷态（后续章节） | 眼神如刀、嘴角平直、面部无表情 | 后续 |
| `pain` | 伤疤发作（后续章节） | 微皱眉、咬牙、手触后背 | 后续（暂不出） |

> 连幕防疲劳原则：班在第一章只在幕间和归途出场，两套表情（grin/serious）足够。normal 作为基准。
