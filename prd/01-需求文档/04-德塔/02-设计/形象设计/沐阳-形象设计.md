# 沐阳 · 形象设计

> 他在研究院里照了三十年的灯,照得越亮,越觉得看不清。
> 六十岁那年他离开,去了草原,把自己浸进阳光里。
> 世人都说他疯了,谣言叫他牧羊人。
> 他不辩解--牧羊人怎么了?牧,本来就是最高明的学问。

---

## 院长修订（2026-07-29）

> 以下为院长口述修订，覆盖原始设计部分方向：

- **不是消瘦老头**：沐阳是**帅老头**，有魅力。常年的草原劳作让他的身材**结实**，不是干瘦虚弱的形象。
- **戴眼镜**：作为前首席院士，眼镜是必备元素。圆框眼镜，透着学者的气质。
- **出图反馈**：v3方向正确（白发+眼镜+结实），但需注意不要出白胡须（保持干净的面部）。

## 一、角色档案

| 字段 | 内容 |
|------|------|
| 姓名 | 沐阳 |
| 性别 | 男 |
| 年龄 | 80 |
| 出身 | 研究院(曾任首席院士) |
| 履历 | 首席院士 -> 因科研理念不同隐居 -> 大草原牧羊人 |
| 现状 | 草原隐士,谣言称其为"牧羊人" |
| 能力标签 | 科研 · 观察 · 草药 · 天象 · 牧养 |
| 性格关键词 | 沉静 · 洗练 · 通透 · 不辩 · 仍热 |
| 核心矛盾 | 首席院士的学识 vs 牧羊人的粗砺;退出者的姿态 vs 仍在观察的头脑 |

### 形象设计理念

沐阳的设计主轴只有一句话:

> **他不是放下了学识,而是把学识放牧在了草原上。**

世人都以为"隐居"是"放下"--放下研究,放下身份,放下头脑。但沐阳没有放下任何东西,他**翻译**了。研究院里的一切,他都翻译成了草原语言:实验台翻译成山坡,论文翻译成牧羊笔记,学生翻译成羊群,灯翻译成太阳。

他离开研究院,不是因为才华尽废,是因为**理念不同**。他不再相信"照"的学问,他要做"沐"的学问。这个"照与沐"的分野,就是他全部设计的题眼。

### 这个角色与前几位的不同

沐阳不是战士,不是王者,不是自封的神。他是一个**主动退出**的人。所以他的设计里:

- **没有武器谱**--他不杀人,他养羊。
- **没有场合切换**--他只有一个场合:草原。日出而作,日落而息。
- **没有状态对照表**--他不演,他只是他自己。
- 岁月本身就是他最大的设计元素。80 岁,是他的廓形,他的质感,他的权威。

## 二、「沐阳」命名哲学(题眼)

这是沐阳所有设计的根。名字不是取的,是他离开研究院时给自己改的--原名已无人记得,他自己也不提。

### 「照」与「沐」:两种学问

研究院的学者做的是**「照」**的学问:

- 用灯照亮,用实验剖析,用仪器测量。
- 主动地、从外部地、干预地去"看"清楚。
- 越照越亮,越亮越觉得自己掌控了一切。

沐阳做的变成了**「沐」**的学问:

- 不照,而是浸进去。让自己被阳光、被风、被草、被四季裹住。
- 不剖析,而是感受、等待、长在其中。
- 被动地、从内部地、不干预地去"活"明白。

> **「照」是站在光外,把光打在东西上;「沐」是站进光里,让光打在自己身上。**
> 他不再相信"照"能照出真相,他相信"沐"才能长出真知。

### 「阳」:他选择的光

- 研究院的灯是人造的、可控的、狭窄的--照亮一块台面。
- 草原的阳是天赐的、不可控的、无边的--滋养万物。
- 他选「阳」不选「灯」,就是选"不可控的真实"不选"可控的虚假"。

### 名字即宣言

> **沐阳 = 沐浴于阳 = 把自己浸进真实的光里。**
> 这不是退隐,这是换了一种更难的研究方法。

## 三、贯穿信物:牧羊杖(无名)

沐阳有一根牧羊杖,是他到草原第三年自己削的,用了二十多年。**没有名字。**

> 杰会给刀取名「逸」,汪神会给自己造印刻字。沐阳不会。八十岁的人,不再给东西命名--东西就是东西,用久了它自己会长出意义来。

| 维度 | 设计 |
|------|------|
| **形制** | 传统牧羊杖,顶端弯钩,全长约齐肩。 |
| **材质** | 草原老榆木,手感沉实。木色被掌汗和岁月养得发红发亮,像琥珀。 |
| **杖身** | 刻满了**刻痕**--这是关键。刻痕分两类,外人分不出: |
| | 一类是**牧羊账**:竖线记羊数,横线记季节,圈记出生/死亡。这是牧羊人的杖。 |
| | 一类是**观察笔记**:草穗形状、云层走向、虫蛀规律、草药花期--用极简符号刻下,只有他自己读得懂。这是院士的杖。 |
| **弯钩处** | 嵌着一枚**旧透镜**--他从研究院带出来的唯一物件,从一台报废观测仪上拆下的镜片,磨圆了嵌进弯钩根部。 |
| **透镜的用法** | 他举起杖远眺时,会不自觉地透过弯钩处的透镜看远处--这个姿势,和当年在实验室举观测仪一模一样。**工具换了,动作没换。** |
| **杖尖** | 包铁,磨损严重。既是拄杖(80岁的腿),也是防狼防蛇的实用件。 |
| **无名的意义** | 不命名,是他八十岁的态度:东西用久了自己会变成你的一部分,不需要额外赋予意义。 |

### 透镜与杖身的关系(信物的核心)

杖身是木,是草原,是牧羊人;透镜是玻璃,是研究院,是首席院士。

> **木包着玻璃,草原包着院士。他没丢掉任何一样,只是把旧的嵌进了新的里。**

## 四、基础造型:草原学者的"翻译"

沐阳的造型不复杂,但每一件都有"双层"--表面是牧羊人的粗砺,里子是院士的精细。这就是"翻译"在设计上的体现。

### 4.1 外袍:日光色长袍

| 维度 | 设计 |
|------|------|
| **款式** | 宽身、直筒、交领、长至小腿。极简,没有多余结构。 |
| **颜色** | **日光色**--不是白,不是黄,是那种被阳光晒了很多年、褪了很多次的浅金麦色。像草原正午的干草垛。 |
| **材质** | 粗羊毛织物,草原自纺自织。有结节、有粗细不均--手织的痕迹。但**洗得很干净**,没有污渍。粗砺但不邋遢,这是院士的洁癖翻译成了牧羊人的习惯。 |
| **领口** | 交领,松松系一根布带。不紧--他要透风、要活动、要随时能蹲下查草。 |
| **袖** | 宽袖,但袖口可以收紧(有暗绳)。平时敞着,查草药时收紧--这是实验服袖口的翻译。 |
| **下摆** | 小腿中段,不拖地。草原风大,长摆绊脚。 |
| **岁月痕迹** | 肩头和后背有日晒褪色,比前胸浅一号--这是常年面朝太阳走路晒出来的。补丁有两块,针脚极密极匀,是院士的手艺,不是牧羊人的粗糙。 |

### 4.2 内衬:贴身细麻衣

- 贴身穿一件**本色细麻衣**,领口贴肉。
- 这件比外袍精细得多--**草原上不该有这么细的布**。这是他从研究院带来的旧物,穿了二十年,洗得发薄但不破。
- 院士的"底"贴着皮肤,外面套着牧羊人的袍。顺序也是意思:**粗砺在外,精细在里。**

### 4.3 下装与足部

| 部位 | 设计 |
|------|------|
| **裤** | 宽腿棉裤,草黄色,收口于靴筒。草原实用款,不讲究。 |
| **靴** | 及踝软皮靴,本色,毛朝内(冬暖)。鞋底磨得极薄--他走太多路了。 |
| **裹腿** | 粗布绑腿,防草刮防虫咬。绑法是草原式,但绑得**出奇地匀称**--又是院士的习惯:做什么都讲究规整。 |

### 4.4 头部:银发与草帽

- **发**:全白,稀疏但未秃。不束不冠,自然垂至肩,风一吹就散。他不管。八十岁了,头发爱怎样怎样。
- **草帽**:宽檐,麦秸编,旧得发黄。檐边有毛茬。他戴帽不是为了遮阳好看,是真的怕晒--但脸还是晒得极黑,因为帽檐挡不住草原的风把脸迎向太阳。
- **不戴冠,不留髻**:研究院的首席院士或许有院士冠,他早就不知道扔哪了。草帽就是他的冠。

## 五、岁月之痕:80 岁的设计

沐阳是这几个角色里唯一由"年龄"定义廓形的人。80 岁不是数字,是质感和姿态。

### 5.1 身体

| 部位 | 状态 |
|------|------|
| **背** | 微弓,但不佝偻。草原风大,长期迎风行走,背自然前倾。但脊梁还在,站直时仍比多数年轻人挺。 |
| **手** | 关节粗大,皮肤粗砺,有老茧。但**指甲修得很短很齐**--院士的习惯没丢。这双手拧过精密仪器旋钮,现在拧羊圈门闩。 |
| **脸** | 沟壑纵横,晒得深褐。法令纹极深,但不是苦相,是**笑纹**--他常笑,笑得很淡。眉骨高,眼窝深,眼珠依然清亮(不浑浊,这是他和普通老人的区别--头脑还在转,眼睛就还亮)。 |
| **颈** | 瘦,筋络分明,皮肤松弛但不干瘪。喉结突出。 |
| **步态** | 慢,但稳。不拖沓,每一步都踩实。用杖,但杖是辅助不是依赖--他不用杖也能走,只是80岁了,懒得逞强。 |

### 5.2 岁月的"不衰退"

他老,但不衰。这是关键区别:

- **眼不花**:透过那枚旧透镜,他还能看清草叶上的虫卵。
- **耳不聋**:草原上他能听出三里外羊群的异动。
- **手不抖**:记牧羊账时刻痕极稳,草药分类时手指精准。
- **脑不钝**:他仍在观察、记录、思考--只是不再写论文,而是刻在杖上。

> **研究院失去了一个首席院士,草原多了一个不写论文却仍在研究的老头。**

## 六、「牧羊人」:双层解读

谣言称他为牧羊人。这个词有两层,一层是世人的,一层是他自己的。

### 第一层:世人所见(字面)

- 一个老人,在草原上放羊。
- 传闻他以前是研究院的人,后来"疯了""废了""隐了"。
- 没人确切知道他是谁,只知道他养羊、懂草、偶尔给牧民看个小病。
- "牧羊人"是世人给他贴的标签,带着一点轻慢:不过是个放羊的老头。

### 第二层:他自己所知(隐喻)

"牧"这个字,沐阳有自己的理解:

- 研究院的首席院士,本质也是"牧"--牧学生,牧学问,牧一个领域向前走。
- 现在牧羊,是一样的:你**不能逼羊懂你,你只能懂羊**。这和做研究一模一样。
- "牧"的最高境界不是控制,是**跟随**--跟着羊群找到最好的草场,跟着问题找到最真的答案。

> **「照」的学问要掌控万物,「沐」的学问要跟随万物。「牧」就是跟随。**
> 他从"牧学问"翻译成了"牧羊",手段没变,只是对象换了。

### 牧羊人的工作 = 院士的工作

| 院士做的事 | 牧羊人做的事 | 本质 |
|------------|--------------|------|
| 观察实验对象 | 观察羊群和草场 | 观察 |
| 记录数据 | 刻牧羊账于杖上 | 记录 |
| 发现规律预测结果 | 看云知雨,看草知季 | 推演 |
| 指导学生避错 | 引羊群避狼避崖 | 引导 |
| 发表论文 | 无--但牧民来问他都答 | 传播 |
| 申请课题经费 | 无--天地就是经费 | 资源 |

> 他还在做院士,只是研究院不知道。

## 七、院士残痕:藏在粗砺下的精细

这是沐阳造型最有趣的部分:他一身牧羊人打扮,但总有一些细节"露馅"--只有懂行的人凑近了才看得出,这不是个普通老头。

### 7.1 衣物上的残痕

- **针脚**:外袍的补丁针脚极密极匀,是受过训练的手艺。草原牧民补衣服是粗针大线,他的针脚像缝过实验滤纸。
- **布料**:内衬细麻衣的质地,草原上没有。懂行的一摸就知道:这是研究院专供的高级细麻。
- **系带**:腰间布带的打结方式,不是草原的结,是一种**极标准的活扣**--实验台系围裙的结。他系了三十年,改不掉。

### 7.2 随身物件的残痕

- **牧羊杖上的符号**:刻痕里有一部分是观察笔记,用的是研究院的速记符号系。如果有另一个院士路过,能读出"这是在记录草穗变异"。
- **透镜**:弯钩处那枚玻璃,不是普通玻璃,是光学玻璃。珠宝商或仪器匠人一眼就认得出。
- **草药袋**:腰间挂一个小布袋,装他采的草药。袋口的系法是实验室样品袋的标准系法。
- **笔记本**:对,他还有一本。极薄,牛皮面,内页发黄。不是牧羊人的账本,是**真正的观察笔记**--有图、有数据、有推演。他没停过研究,只是不再给任何人看。

### 7.3 习惯上的残痕

- **蹲下观察**:他看草时,会单膝跪地,凑近,一动不动看很久。这个姿势不是牧民看草,是院士看实验样本。
- **洗手**:吃饭前他会仔细洗手,用沙子搓--草原上没有更好的办法,但他绝不将就。这习惯在牧民里很少见。
- **说话方式**:他说话慢,用词准,偶尔冒出一个很"书面的"词。牧民觉得他"有文化",但不知道有多深。

> **院士是藏不住的。哪怕他穿了二十年粗羊毛,骨子里的精细会从每一个针脚、每一个符号、每一个习惯里渗出来。**

## 八、色彩与材质总表

| 部位 | 颜色 | 材质 | 质感 |
|------|------|------|------|
| 外袍 | 日光浅金麦色(褪色) | 粗羊毛织物,手织 | 有结节、干净、补丁针脚密 |
| 内衬 | 本色白(发薄) | 细麻(研究院旧物) | 贴身、精细 |
| 裤 | 草黄 | 棉 | 宽腿收口 |
| 靴 | 本色皮,毛朝内 | 软羊皮 | 鞋底磨薄 |
| 裹腿 | 本色 | 粗布 | 绑得匀称 |
| 草帽 | 麦秸黄(旧) | 麦秸编 | 檐边毛茬 |
| 牧羊杖 | 老榆木红褐(包浆) | 老榆木+铁尖+光学玻璃透镜 | 沉实、光滑如琥珀 |
| 草药袋 | 本色 | 粗布 | 实验室系法 |
| 笔记本 | 牛皮面(旧棕) | 牛皮+发黄纸 | 薄、有图有数据 |
| 发 | 全白 | - | 稀疏、垂肩 |
| 皮肤 | 深褐 | - | 沟壑、晒痕、笑纹 |

### 色彩逻辑

- **日光浅金 + 草黄 + 麦秸黄** = 阳光的色系,温暖、褪色、被时间养过。
- **本色白 + 本色皮** = 未染的质朴,草原的诚实。
- **老榆木红褐 + 牛皮棕** = 岁月的沉淀,器物被用老了的颜色。
- **没有冷色,没有亮色** -- 他整个人是暖的、旧的、柔的,像草原下午四点的阳光。

## 九、日常场合(他只有一个场合:草原的一天)

沐阳不切换场合,他的生活是循环的。但一天之内,姿态随日光变化:

| 时辰 | 光 | 他在做什么 | 姿态 |
|------|----|-----------|------|
| **晨** | 朝阳斜照 | 出圈放羊,查夜里有无异动 | 拄杖,慢行,弯腰看蹄印 |
| **午** | 顶天烈日 | 羊群卧荫,他蹲在坡上记观察 | 单膝跪地,凑近草丛,一动不动 |
| **午后** | 光渐柔 | 靠着杖远眺,透镜看云 | 举杖齐眉,透过弯钩透镜望天 |
| **昏** | 暮金满身 | 赶羊回圈,给病羊敷草药 | 蹲在羊边,手势极稳极轻 |
| **夜** | 星光 | 坐帐篷前,翻笔记本,刻杖 | 借星光和余温,慢慢刻,慢慢写 |

> 他的一天,就是一篇论文的田野调查。只是没人看,他也不在乎有没有人看。

## 十、上身顺序

1. **内衬**:本色细麻衣,贴身(研究院旧物)。
2. **裤**:草黄宽腿棉裤,收口。
3. **裹腿**:粗布绑腿,绑匀。
4. **靴**:本色软羊皮靴,毛朝内。
5. **外袍**:日光色粗羊毛长袍,交领,松系布带(实验台活扣)。
6. **草药袋**:挂腰间,实验室系法。

## 一句话总结

> **他不是放下了学识,是把学识放牧在了草原上。**
> **研究院的灯照了三十年,越照越远;草原的阳沐了二十年,越沐越近。**
> **谣言叫他牧羊人,他笑。他确实在牧--只不过从前牧的是学问,现在牧的是羊。手段一样:不照,而沐;不逼,而牧。**

## 附录A：背景故事与虚空研究（院长补充 · A.V.118主线前史）

> 以下为院长于 7/28 口述补充的剧情设定，补全了文档"待补充"项中的"科研理念分歧的具体内容"。

### A.1 帝国研究院首席时期

沐阳曾是帝国研究院**首席院士**、大魔法师，研究虚空大半生。

其核心主张：**控制虚空生物**，而非杀死虚空生物再提取力量。这一主张与当时的执政官理念冲突--执政官倾向于更直接、更可控的"杀死提取"路线，沐阳则认为活体控制才能触及虚空的真正运作机制。

### A.2 实验事故与自我放逐

在一次控制虚空生物的实验中，实验出现意外，虚空生物暴走，造成**数名市民无辜身亡**。

沐阳深感惭愧，**引咎辞职**，并选择**自我放逐至大草原**。临行前封存所有相关研究资料，列入**绝密档案**。帝国极少数人知道这位前首席的存在。

> 这解释了他从"首席院士"到"草原隐士"的转变：不是理念不同而和平离开，是带着愧疚和责任的放逐。

### A.3 蜂巢思维：草原上的秘密研究

在大草原，沐阳并未真正放下研究，而是以"沐"的方式继续。

他初步了解并掌握了**控制部分虚空生物**的能力，即**蜂巢思维**：
- 似乎存在一个**更高级的虚空生物**，它可以直接遥感若干个低级虚空生物作为触手。
- 沐阳通过足够精细的魔法操控，**切断了这种遥感并取代**之--即把自己插入蜂巢链路，成为低级虚空生物的新"指挥节点"。
- 但这种手段**极其消耗体力和蓝量**。随着沐阳年岁渐高，几乎**足不出户**。

> 这解释了世界观设定集中"他所在区域的裂隙活动呈现规律性（像被引导而非自然渗出）"--那不是虚空自然渗出，是沐阳在控制。

### A.4 睿帝与沐阳的渊源

- **年少接触**：睿帝年少时曾与沐阳短暂接触，知道这是一位**高尚且博学**的院士。
- **称帝解封**：睿帝称帝后，私自解封了绝密档案，了解了当年的事情。
- **出山契机**：当前研究院的首席**"迅"染病**，疑似是虚空生物引起的某种症状。睿帝的研究也进入瓶颈期。于是睿帝选择**亲赴草原**，请沐阳出山主持研究院，并寻求治愈迅的办法，顺便敲打一下大草原的城邦。

> 睿帝对沐阳的态度是"敬重 + 务实"：敬重其人品学识，务实地需要其虚空研究能力。这条线连接了帝国主线与草原主线。

### A.5 "牧羊人"称呼的真正来源

草原上偶然间见过沐阳的人，会认为他真的可以跟虚空生物对话。询问姓名时，沐阳如实回答"沐阳"，但草原人将其误听为**"牧羊"**，遂以"牧羊人"称之。

这其实是一种**误解和谣传**，但几乎没人知道真相。

> 世人的"牧羊人"标签来自谐音误解；沐阳自己对"牧"的理解（见第六章「牧羊人」双层解读）则是另一层。世人所见与沐阳所知，恰好构成了这个词的双重含义。
