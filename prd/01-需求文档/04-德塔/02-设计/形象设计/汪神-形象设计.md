# 汪神 · 形象设计

> 他从水里来,把四方海盗按在一张桌前,建了一个国。
> 加冕那天没人给他戴冠,他自己取了"水"与"王"二字,合为"汪",自封为神。
> 从此他敞着胸,唱着歌,胸肌上是盐,腹肌上是风。
>
> **【主线状态警示】**：游戏主线 A.V.118 时，汪神已**失踪5年**（A.V.113南极远征确认失踪）。本文档主体描述的是**「传奇形态」**（A.V.80加冕~A.V.108远征前，鲜活在场的历史形象）。主线中汪神更多以**画像/回忆/可能重现的剪影**形式出现，详见第十一节「谜团形态」。

| 履历 | 水手 -> 舰队统帅 -> 群岛建序者 -> 联合王国建立者 -> 加冕为汪神 -> **A.V.108南极远征 -> A.V.113确认失踪** |

### 形象设计理念

汪神的设计主轴是一句话:

> **他是水做的王,也是藏着秘密的学者。**

不是"穿得像水手"的王,也不是"装得像神"的水手。他的全部设计都服务于"水"与"王"这两个字的融合--水的流动、亲民、浩荡,遇上王的威仪、秩序、不可逆。但他还有**第三面**——一个派人在故纸堆里翻找虚空真相、最终找到"阿瓦隆"线索的学者。这个学者面藏在他豪放的外表下,是他南极远征(也是他失踪)的根本动因。

他和前几个角色最大的不同:**他是自封的神**。这意味着他的所有"神性符号"都带着一种"我说是就是"的豪横--他不需要教会认证,不需要血统背书,他自己取两个字合在一起,就是神。这种自信本身,就是他最大的气场。而他追追寻虚空真相的执念,又让这种神性多了一层"明知不可为而为之"的悲剧底色——神也想知道自己面对的是什么。

### 「水+王=汪」的命名哲学(贯穿全设计)

这是汪神所有设计的题眼,必须先讲清楚:

| 字 | 含义 | 视觉转化 |
|----|------|----------|
| **水** | 他的来处、他的根、他的力量之源。水手出身,航海起家,水是命。流动、亲民、浩荡、无定形。 | 蓝绿色系、流动的衣摆、波浪纹、敞开的领口(水流不设防) |
| **王** | 他建立的秩序、他的自封。四方海盗臣服,联合王国成立。威仪、铁腕、不可逆。 | 王权信物、肩饰、印玺、收紧的腰封(秩序的骨架) |
| **汪** | 水与王合一。水之大者为汪--汪洋。他不是一滴水的王,是一片汪洋的王。既浩荡又有主。 | 整体廓形:上敞下收,既有水的流动又有王的份量 |

> **水让他能走到任何人面前,王让任何人到他面前都得跪。**

## 二、贯穿信物:汪印

汪神的信物不是武器,是一枚印。因为他建国的核心动作不是征服,是**让四方海盗坐下来签协议**。

| 维度 | 设计 |
|------|------|
| **形制** | 圆形大印,直径约一掌,厚实,可手持可佩戴。 |
| **材质** | 深海沉木(海难沉船的船骨,在海底沉了百年,捞起阴干)--木色近黑,有海水的盐霜沁入纹路,自带一种"从水里捞出来的"的厚重感。 |
| **印面** | 刻一个**「汪」**字,但不是普通的汪--左三点水作**三道浪纹**,右"王"字三横一竖作**三道横纹叠一锚形竖线**(锚即王的竖)。水浪与王权合在一个字里。 |
| **印背** | 浅浮雕一只**张开双臂的人形**(他自己敞胸的剪影),脚下踏浪。这是他"以身为印"的意思--这枚印的权威,来自他这个人,不来自任何神授。 |
| **佩戴** | 不挂腰,用一根编绳**挂颈悬于胸前**,垂在敞开的胸肌之间。印是沉木的,贴着皮肤,随体温发暖。这是他唯一"贴身"的信物--王权贴着心跳。 |
| **使用** | 不盖蜡封,按**湿泥印**(取群岛红泥,和海水成泥,按压成印,风干即成令牌)。四方海盗认这块泥印为令,见泥印如见汪神。 |
| **狂放 ↔ 秩序** | 狂放:沉木粗砺、编绳简陋、泥印土气,一点也不像王玺。秩序:四方海盗见了它就认令,这是铁打的秩序。 |

## 二点五、学者信物:阿瓦隆古卷(第三信物)

汪神除了汪印(王权信物),还有一件**学者信物**——这是他"追寻虚空真相"这一面的物化,也是他南极远征(失踪)的根本动因来源。

| 维度 | 设计 |
|------|------|
| **形制** | 一卷**防水海象皮包裹的古卷残页**,卷轴状,约手掌长,用鲨鱼皮绳捆扎。 |
| **内容** | 残页上是他从各岛收集的古代文献抄本,夹杂他自己的批注(墨迹是海岛深蓝植物染料)。最关键的一页画着一条**通往南极的航线**,尽头标着"阿瓦隆"二字。 |
| **材质** | 海象皮(防水,长期航海不腐)+ 古旧羊皮纸(发黄、有盐渍)。卷边磨损严重,被他翻阅过无数次。 |
| **佩戴** | **挂在与汪印相反的一侧**(汪印胸前正中,古卷挂右腰侧,与四方令牌并列)。一前一后,一王一学。 |
| **使用** | 他常在深夜独自展开,借着船灯研读。旁人以为他在看海图,其实他在算阿瓦隆的坐标。 |
| **狂放 ↔ 学者** | 狂放:这卷破纸和他豪放的形象格格不入,看着像捡来的破烂。学者:这正是他全部远征决策的依据,一个王为了一卷残纸带着舰队去南极。 |
| **失踪后的下落** | A.V.108远征时他随身带走原本。王都岛留存有**他手抄的副本**(残缺),现由摄政议会保管——三方势力都在暗中想要这卷副本,因为它指向阿瓦隆的无尽宝藏/能源。 |

> **汪印让他能命令四方,古卷让他走向未知。前者是权力的总和,后者是权力的尽头。**

## 三、基础造型:敞胸的水王

汪神的造型最显眼的一点是**敞衣露胸肌腹肌**。这不是为了卖弄,这是他的"政治宣言":

> **我敞着胸站在你面前,因为我没东西要藏。我的水手出身、我的肉身、我的命,都在这儿。**

同时,敞胸也呼应"水"的意象--水不设防,水不闭壳。但他的下半身和配饰是收束的、有秩序的,对应"王"。这就是"上敞下收"的廓形逻辑。

### 3.1 上衣:水手敞襟短衣

| 维度 | 设计 |
|------|------|
| **款式** | 立领、对襟、**全程不系扣**的短上衣,下摆齐腰。 |
| **颜色** | 海雾蓝灰(清晨海面的颜色),偏冷,但洗得发白有盐渍感。 |
| **材质** | 粗帆布--就是船帆的料子。他穿的就是他航过海的帆。有骨感、有盐霜、海风一吹会微微发硬。 |
| **领口** | 立领但敞着,从喉口一路敞到下摆,胸肌、腹肌、汪印全露在外面。 |
| **袖** | 七分袖,卷至肘上,露出前臂的肌肉和晒痕(水手长期操帆的晒痕)。 |
| **下摆** | 齐腰,不盖过腰带,便于活动、便于下水。 |
| **内衬** | 无。直接贴肉。冬天冷就在外面加披风,不系紧。 |

### 3.2 下装:收束的王

| 维度 | 设计 |
|------|------|
| **裤** | 深海蓝长裤,收腿,面料是精纺棉(比上衣精细一档--下半身代表"王",材质要规矩些)。 |
| **腰带** | 宽皮带,深棕,做旧。带扣是一枚**横置的锚形铜扣**(锚即王字的竖)。这是他下半身唯一的金属件,沉稳、不闪。 |
| **绑腿/靴** | 及膝绑带皮靴,深棕,软底(船甲板行走无声)。绑带是盐渍皮绳。 |

### 3.3 肩饰:王的份量

他虽敞胸,但双肩有**王权肩饰**,这是"上敞下收"中"王"在身上的体现:

- **形制**:双肩各一片半圆硬甲,从肩头覆到肩峰,不连体。
- **材质**:锻铁,但表面包一层**鲨皮**(粗糙、深灰、有磨砂感--海洋的质感)。
- **纹样**:左肩刻**三道浪纹**(水),右肩刻**三横一竖锚纹**(王)。两肩合起来就是"汪"字的拆解。
- **作用**:肩饰压住双肩,让敞胸的造型不至于轻飘--上半身有"份量",下半身有"秩序",中间敞着的是水。

### 3.4 披风(可选,常备)

- **形制**:及膝短披风,单侧右肩搭扣(左肩自由)。
- **颜色**:深海蓝,近黑。
- **材质**:厚羊毛,防海风、御夜寒。
- **细节**:内衬浅蓝,翻过来像海浪的白沫。
- **穿戴**:平时不穿,搭在右肩或由侍从拿着;海风大或正式场合才披。披的时候也是敞着的,**从不系紧**。

## 四、胸膛:他最重要的"配饰"

汪神敞衣露出的胸肌腹肌,本身就是设计的一部分,不能含糊带过:

### 4.1 身材

- 健硕但不夸张,是**功能性**的肌肉--拉帆、攀桅、搏风浪练出来的,不是健身房雕出来的。线条流畅,不僵硬。
- 胸肌饱满,腹肌明显但不分块过深--是"有力量但不刻意"的程度。
- 皮肤是海风和烈日晒出的**深麦色**,胸膛正中有一条**晒痕分界线**(长期敞襟晒出来的),这本身就是他标志的一部分。

### 4.2 胸前的痕迹

- **盐霜**:长期航海,胸口常有海风干透的盐渍,阳光下会微微泛白。他不擦,这是水手的勋章。
- **旧伤**:左肋下有一道陈年刀伤疤(平定海盗时留的),他不遮,敞着胸正好让人看见--"我挨过刀,所以我配让你们坐下签协议"。
- **纹身**(可选):右胸上方或肩臂处,一个**汪字纹身**,墨色用的是海岛特有的深蓝植物染料。这是他自封为神时刺的,刻进肉里,洗不掉。

### 4.3 汪印的位置

汪印(见第二节)用编绳挂颈,垂在胸肌之间的凹槽处。沉木贴着胸骨,随呼吸起伏。这是他身上离心脏最近的物件--**王权贴着心跳**。

## 五、歌唱:穿在身上的声音

汪神爱唱歌,这是他设计里最特别的一环--**声音也是他的"穿搭"**。

### 5.1 歌声特质

- 低沉、浑厚,带海风沙哑感。不是歌剧院的嗓,是甲板上船工号子的嗓。
- 唱的是**海谣**(群岛民间的航海歌谣),内容多为风浪、归港、母亲、战友。
- 唱歌时声音能传很远,在海上是号令,在港口是安抚。

### 5.2 歌声的功能(政治性)

| 场景 | 唱歌的作用 |
|------|------------|
| 舰队航行 | 统一划桨节奏,提振士气(水手号子功能) |
| 接见海盗首领 | 边唱边走入场,歌声比威吓更让人腿软--他不是来谈判的,他是来收编的 |
| 巡视民情 | 在码头酒馆唱一曲,渔民就知道王来了,而且王是"自己人" |
| 处决邪教徒 | 行刑前他唱一首安魂谣,既是给死者的最后尊重,也是给活人的警告 |

> 他唱歌不是才艺,是**权力的另一种声学形态**。

### 5.3 歌唱时的姿态

- 多数时候**单手扶着腰带的锚扣**,仰头,喉结暴露,胸膛挺起。
- 有时**坐在船舷或码头边**,双腿悬空,边唱边晃--这一刻他不是王,是水手坤。
- 唱到高潮处会**拍自己的胸膛**当鼓点--胸肌就是他的乐器。

## 六、厌恶邪教徒:视觉上的"反衬"

汪神体恤民众,但厌恶邪教徒。这个"厌恶"要在造型上有体现,但**不是通过戴什么**,而是通过**对比**:

- 他自己的"神性"是**自封的、敞亮的、贴着肉身的**(汪印挂胸口、纹身刻肉里)。他最看不起的,就是那些**装神弄鬼、藏头缩尾、用神权恐吓平民**的邪教徒。
- 所以他敞胸,本身就是对邪教徒的无声嘲弄:**"真正的神不需要面具,我把命敞在这里。"**
- 处决邪教徒时,他会特意**扯开对方的兜帽/面具**,说一句:"让神看看你的脸。"然后才动手。

> 他的敞胸,在邪教徒面前就成了一种**审判姿态**--你藏,我露;你骗,我真。

## 七、四方臣服:协议的视觉化

汪神建国的核心是"让四方海盗臣服",不是单纯征服。这件事要在造型上留下痕迹:

### 7.1 腰带上的四方令牌

宽皮带上,锚扣两侧,缀四枚**小型令牌**(每枚代表一个被收服的海盗势力):

- 每枚令牌材质不同(铜、铁、骨、珊瑚),代表不同海盗头子的"信物"上缴。
- 令牌形状各异(有的是断刀头、有的是海兽牙、有的是旧金币),是各方臣服时交出的"旧主权的象征"。
- 汪神把它们缀在自己腰上,意思是:"你们过去的主人,现在都在我腰上。"

### 7.2 肩饰的钉痕

鲨皮肩甲边缘,有几枚**旧钉孔**--那是各方臣服时,海盗头子亲手把自己的徽记钉上去又被汪神拆掉留下的痕迹。他留着这些孔不补,意思是:"你们曾经扎过根,现在是我让你们拔的。"

## 八、色彩与材质总表

| 部位 | 颜色 | 材质 | 质感 |
|------|------|------|------|
| 上衣 | 海雾蓝灰(盐渍发白) | 粗帆布 | 有骨感、盐霜 |
| 裤 | 深海蓝 | 精纺棉 | 收腿、规矩 |
| 腰带 | 深棕 | 做旧皮 | 宽、有份量 |
| 腰带扣 | 古铜 | 锚形铜扣 | 沉稳不闪 |
| 绑腿靴 | 深棕 | 盐渍皮绳+软底皮 | 无声 |
| 肩饰 | 深灰(鲨皮)+锻铁 | 鲨皮包铁 | 粗糙磨砂 |
| 披风 | 深海蓝近黑 | 厚羊毛 | 御风、内衬浅蓝 |
| 汪印 | 近黑(沉木) | 深海沉木+编绳 | 盐霜沁纹 |
| 阿瓦隆古卷 | 发黄+深蓝批注 | 海象皮+羊皮纸+植物染料墨 | 磨损、盐渍、卷边 |
| 四方令牌 | 铜/铁/骨/珊瑚各异 | 各异 | 旧主权的痕迹 |
| 皮肤 | 深麦色 | - | 晒痕、盐渍、旧伤 |
| 胸前纹身 | 深蓝 | 植物染料 | 汪字刺青 |

### 色彩逻辑

- **海雾蓝灰 + 深海蓝** = 水的色系,主视觉,亲民与浩荡。
- **深棕 + 古铜** = 王的色系,秩序与份量。
- **鲨皮灰 + 沉木黑** = 海洋的粗砺,他的水手底色。
- **深蓝纹身** = 自封神性的唯一显性符号,刻在肉里。

## 十、上身顺序

1. **裤**:深海蓝收腿裤。
2. **靴**:深棕及膝绑带靴。

## 十一、谜团形态(A.V.118 主线状态)

> 主线时间点,汪神已失踪5年。他在场时是上述「传奇形态」,主线中他以**符号、传说、谜团**的形式存在。生图用途以此节为准。

### 11.1 主线中的存在形式

| 形式 | 出现场景 | 生图要点 |
|------|----------|----------|
| **王都岛巨幅肖像** | 王都岛议事厅、港口广场 | 传奇形态的标准像,庄重,常被三股势力借用宣誓合法性 |
| **回忆/闪回** | 汪神旧部叙述往事时 | 传奇形态,但画面偏旧、偏暖(褪色记忆感) |
| **可能重现的剪影** | 阿瓦隆航线、南极迷雾中(伏笔) | **只露背影或侧影**,看不清脸,身份存疑——是汪神?是冒充者?还是别的什么? |
| **遗物** | 摄政议会保管的古卷副本、空荡荡的王座 | 不出现人,用物件暗示他的缺席 |

### 11.2 "重现剪影"的设计变体

若主线后期汪神(或冒充者)重现,设计需保留**辨识度锚点**但制造**不确定性**:

| 锚点(必须保留) | 不确定性(制造悬念) |
|----------------|-------------------|
| 敞胸 + 汪印剪影 | 脸始终在阴影/逆光中 |
| 海雾蓝灰帆布衣 | 衣服明显更破旧,像是穿了5年没换 |
| 汪字纹身 | 只露一角,无法确认是不是原来的那个 |
| 歌声(听觉锚点) | 声音沙哑,像不像由听者判断 |

> 这个形态的核心是:**让玩家/读者自己猜"他到底是不是汪神"**。配合设定集伏笔"虚空有理智生物",重现者可能是汪神、可能是虚空伪装、可能是完全不同的人。

### 11.3 主线生图优先级

主线中汪神相关的生图需求,**80%是肖像/回忆**,20%是重现剪影。建议:
- 优先固定一张「传奇标准像」(传奇形态),用于所有肖像/回忆场景
- 重现剪影少量、克制使用,保持悬念

## 一句话总结

> **水让他能走到任何人面前,王让任何人到他面前都得跪。**
> **他敞着胸,是因为没东西要藏;他唱着歌,是因为这片汪洋已经是他唱出来的。**
