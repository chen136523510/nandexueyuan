## 0. 背景与决策依据

### 0.1 院长决策（2026-07-29）

- **方向**：废弃 2D 动作/俯视游戏（Phaser/Colyseus 全停），改为 视觉小说（叙事驱动 + 立绘 + 背景 + 对话 + 分支世界线）
- **引擎**：Vue 3 Web 自研（网站 `/nde` 路由直接进入，无需联机）
- **玩法**：叙事 + 好感度/势力关系（设定集已有 0-100 好感度锚点）
- **UI 参考**：《永恒世界》（Eternum）--底部全宽对话框 + 立绘 dim/高亮 + 快捷栏 + 手机消息系统 + 地图移动
- **视觉风格**：独立深色主题（深蓝灰底 + 暖金/青色点缀，与莫兰迪风社区页面区分）
- **存档**：服务端持久化（遵从 ADR-005）
- **剧本创作**：黑机连酒馆 AI 生成大纲/草稿，白机整理为 JSON 剧本数据

### 0.2 调研参考

| 参考对象 | 参考维度 | 结论 |
|---------|---------|------|
| 《哀鸿：城破十日记》 | 剧本体量/双线叙事/多结局 | 45万字 + 双线（记/忆）+ 几十个死亡结局。我们的世界观 v1.3 足够支撑大体量叙事 |
| 《永恒世界》(Eternum) | UI 交互/视觉风格 | Ren'Py 引擎标准交互范式：底部全宽对话框 + 打字机 + 立绘 dim + 快捷栏 + 手机消息系统 + 地图移动 |

## 1. 技术架构

### 1.1 前端架构

```
src/视觉小说/                           # 视觉小说 引擎（独立模块）
  engine/
    engine.js                          # 剧本引擎核心（节点解析/跳转/条件判断）
    types.js                           # 节点类型定义 + 角色色彩配置
  components/
    DialogueBox.vue                    # 对话框（底部全宽 + 打字机 + 角色名标签）
    CharacterLayer.vue                 # 立绘层（多立绘同框 + 说话者高亮/非说话者 dim）
    ChoiceMenu.vue                     # 选项菜单（居中垂直按钮 + hover + 已选标灰）
    QuickMenu.vue                      # 快捷栏（存档/读档/设置/历史/跳过/自动）
    SaveLoadPanel.vue                  # 存档/读档界面（缩略图网格 + 时间戳）
    HistoryPanel.vue                   # 文本回看
    SettingsPanel.vue                  # 设置（文字速度/音量/自动播放）
    BackgroundLayer.vue                # 背景层（场景切换 + dissolve 转场）
  stores/
    视觉小说Store.js                    # Pinia store（当前节点/好感度/存档/全局状态）
  data/
    prologue.js                        # 序章剧本（学院降临）
    chapters/                          # 后续章节
```

### 1.2 后端架构

**数据库新增两张表**：

- `GameSave`：存档槽（每用户最多 10 手动 + 1 自动），存储节点/章节/好感度快照/变量快照/缩略图
- `GameProgress`：全局进度（每用户一条），存储解锁章节/解锁CG/好感度/剧情变量

**新增 API**：

```
GET    /api/视觉小说/progress           # 获取全局进度
POST   /api/视觉小说/progress           # 更新全局进度
GET    /api/视觉小说/saves              # 获取存档列表
GET    /api/视觉小说/saves/:slot        # 读取指定槽位
POST   /api/视觉小说/saves/:slot        # 写入指定槽位
DELETE /api/视觉小说/saves/:slot        # 删除指定槽位
```

### 1.3 剧本数据结构

JSON 格式节点系统，4 种节点类型：
- `dialogue`：对话/旁白（背景 + 立绘 + 说话者 + 文本 + 好感度效果）
- `choice`：选项分支（多个选项，每个选项有好感度效果和跳转目标）
- `condition`：条件分支（基于好感度/变量自动跳转）
- `event`：事件节点（解锁CG/修改变量，无UI自动跳转）
- `end`：章节/结局结束

## 2. UI/UX 设计

### 2.1 主界面布局

```
┌─────────────────────────────────────────────┐
│                                    [快捷栏]  │
│           [背景图]                          │
│     [立绘A-dim]  [立绘B-高亮]  [立绘C-dim]   │
├─────────────────────────────────────────────┤
│ [角色名] 对话文本...                    ▼    │
└─────────────────────────────────────────────┘
```

### 2.2 视觉风格

- 背景：`radial-gradient(ellipse at center, #1a2332 0%, #0d1117 100%)`
- 对话框：`rgba(13,17,23,0.88)` 半透明深底 + 暖金微光边框
- 角色名标签：每角色独有色彩（睿帝=银灰/丘=林绿/杰=金沙/汪神=淡蓝/牧羊人=纯白/法刺=暗红）
- 选项按钮：左侧暖金竖条 + hover 高亮 + 已选标灰

### 2.3 快捷键

| 键 | 功能 |
|----|------|
| Space/Enter/点击 | 推进文本 |
| H | 隐藏界面 |
| S / L | 存档 / 读档 |
| Esc / 右键 | 设置 |

### 2.4 后续特色系统

- **手机/消息系统**（M-G2）：剧情中角色发消息，气泡聊天界面。适配世界观--六大势力间通过"通讯符文/传讯术"推进剧情
- **地图移动系统**（M-G3）：节点式地图，以云顶山脉为中心，点击势力据点触发场景
- **CG鉴赏**（M-G3）：网格布局，未解锁锁定，解锁可全屏+重播
