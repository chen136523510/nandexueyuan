### [design] 德塔世界观承载方式决策 — CG/漫画演出层 + 联机状态同步 + 否决切 3D

- **时间**：2026-07-27
- **决策人**：陈梓键（院长）
- **文档**：[ADR-005](../../00-调研/decisions/ADR-005-德塔世界观承载方式.md)
- **背景**：设定集 v1.3 庞大世界观资产（118年历史/六大势力/四大伏笔）与泰拉瑞亚式 2D 横版 sandbox 叙事承载力存在结构性落差。70% 设定内容是叙事性的，纯打怪探索无法承载；黑机世界观产出面临沉没风险。
- **核心决策**：
  1. **剧情承载 = CG/漫画演出层**（P0 纯漫画，P1 可选视频增强）：JRPG 式"战斗 sandbox + 独立剧情演出层"分离架构。触发时机=击杀BOSS/首达新地图/关键NPC初遇/主线里程碑。首次自动弹出，可在 HUD 或男德通聊天界面回顾。
  2. **漫画工作流 = ComfyUI + IP-Adapter**（黑机已有，零 API 成本，复用 R-003 美术流水线，像素风优先与现有美术统一）
  3. **所有进度类状态联机同步**（剧情解锁/好感度/净化进度）：禁止仅用 localStorage，必须服务端持久化
  4. **否决切 Unity 做 3D 大型游戏**：单人开发 3D 动作成功率极低、AI 美工解决不了动画/关卡/手感、现有 Phaser+Vue 投入打水漂、背离"小集体抽象娱乐"初衷
- **AI 视频产品调研**（受限，部分待院长浏览器手核）：
  - ✅ 已确认：Vidu（生数科技）多主体一致性 7张参考图+主体库+图生视频+首尾帧+1080P+动漫风强（首选）
  - ✅ 已确认：腾讯混元生视频 图生视频+动漫/3D+按QPS计费（次选）
  - ❓ 待核：即梦Seedance/可灵/通义万相 参数与定价（官网SPA本环境抓不到）
- **对战斗系统阶段1影响**：无直接影响，CG/漫画演出层是独立后续工作。本决策仅提前锁定承载方式，避免战斗做完才发现剧情无处安放。
- **待办**：①院长手核可灵/即梦/万相定价 ②PoC 验证 ComfyUI+IP-Adapter 漫画一致性 ③战斗系统完成后预留 story-trigger 消息通道
