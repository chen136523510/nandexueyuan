## 一、双线品牌架构（本轮确立）

| 线 | 载体 | 视觉气质 | 配色基调 |
|---|---|---|---|
| **网站线（男德学院社区站）** | TopBar/首页 Hero/favicon | 松弛、手作感、莫兰迪、不像 AI | 米白底 + 鼠尾草绿 + 暖赭（design-system 原色） |
| **德塔线（NDO 视觉小说）** | 游戏内标识/加载页/游戏内纹章 | 西方奇幻油画厚涂、黑深残、暖光反差 | 深墨绿 + 赭金微光 + 虚空色（美术设计规范 V2.1） |

两线共用「学院」血缘（暖赭金点缀互相呼应），但**不共用图形**：网站是「家的门面」，德塔是「异世界的堡垒」。

## 二、德塔线：Δ 形变五方案

> 主题锁定：Δ 形变 + 厚涂画风 + 滤镜（SVG 草案已用手绘滤镜模拟，定版可换 Seedream 精绘）

### NDO-1 厚涂岩塔Δ（主推）
- **形变**：Δ 变成一块厚重的等腰岩体塔，底边微微内凹成塔基弧
- **画风**：左亮右暗的厚涂块面（3 层色阶）+ feTurbulence 置换滤镜做笔触不平整边缘 + 全画幅 6% 噪点颗粒去数码感
- **点睛**：塔身一扇暖光小窗（德塔加护微光——总有一盏灯）
- **文件**：`ndo-1-rock.svg`

### NDO-2 月护Δ
- **形变**：近黑深绿 Δ 剪影正挡在满月前，右缘被月光勾出冷银轮廓光
- **叙事**：班走廊月亮 CG 的符号化——塔与月，德塔世界观前二意象同框
- **画风**：月晕柔光（高斯模糊）+ 月面两笔环形山厚涂手感 + 冷色世界里唯一暖点（塔底小窗）
- **文件**：`ndo-2-moon.svg`

### NDO-3 阶梯塔Δ
- **形变**：Δ 笔画拆解成 5 层退台叠起的金字塔式高塔（据点本体），层层内收
- **点睛**：塔尖嵌赭金宝石（加护微光符号化）+ 底层拱门透暖光
- **气质**：最像「学院建筑」的一个，层线即年代地层
- **文件**：`ndo-3-ziggurat.svg`

### NDO-4 虚空裂Δ
- **形变**：负空间玩法——完整岩体底边正中被撕掉一个小 Δ，裂缝深处透出微光，光尘飘出
- **叙事**：虚空纪元的「裂」——世界破碎，但裂缝里有光（黑深残基调的正向反转）
- **滤镜**：虚空蓝紫渐变底（#3E4C63 系，六大势力外唯一允许的体系外色，仅此方案）+ 岩体碎裂边缘置换
- **文件**：`ndo-4-rift.svg`

### NDO-5 基准Δ（多场景骨架）
- **形变**：最小形变——纯 Δ 塔面 + 底层门洞 + 顶心赭金菱形
- **用途**：16px favicon / 传送阵符文 / 简报抬头的单焦点简化版（调研 2.5 节交付清单要求）
- **文件**：`ndo-5-base.svg`

**德塔线滤镜系统（定版后统一调）**：暗角 / 颗粒噪点 / 轮廓光 / 暖窗辉光——四参数做成 CSS filter 或 SVG filter 复用，保证游戏内各处 logo 质感一致。

## 三、网站线·第一批：四方案（V3 作废，摸鱼梗方向不再延续）

> 方向修正：院长要求重出。本轮回归「学院门面」的松弛正经感，不再玩藏鱼梗（V3 的 A/C 藏鱼、B/D 咸鱼全部归档）
> ⚠️ 技术注意：第一批四案全部含 `<text>` 文字，依赖霞鹜文楷 webfont，CDN 失败/字体缺失场景不可控。定版必须矢量固化（V2 已有 opentype.js + de-path.txt 成熟管线）。第二批五案已规避此问题（全纯图形）。

### WEB-1 门匾
- **形态**：深墨绿横匾 + 暖赭双线描边 + 文楷「男德学院」+ 两端如意云头角饰
- **逻辑**：TopBar 就是门楣，LOGO 就是挂上去的匾——语义严丝合缝；加载动画可做「挂牌落定」
- **文件**：`web-1-plaque.svg`（横版 560×120）

### WEB-2 四训环徽
- **形态**：外环一条鼠尾草绿圆线在四个方位各断开一段，断口嵌暖赭小圆点，四训「修身/齐家/摸鱼/开摆」嵌断弧旁，中心文楷「德」+ 落款点
- **逻辑**：中国校徽的圆结构（北大范式）× 社区四训内核；四点像四个成员围坐
- **风险**：四训小字 16px 下不可读，favicon 需用无字简化版
- **文件**：`web-2-motto-ring.svg`

### WEB-3 手绘松弛圈
- **形态**：一笔画完的不闭合手绘圆圈（起笔轻/中段重/收笔飘，三段粗细变化），圈内文楷「男德」微倾斜，右下暖赭小落款
- **逻辑**：最贴合 design-system「松弛、手作感、不像 AI」的品牌关键词；不闭合的圈 = 不装正经的学院
- **文件**：`web-3-loose-circle.svg`

### WEB-4 德字 app 图标
- **形态**：暖赭渐变圆角方块 + 米白大「德」字 + 字底一条躺平弧线（接住整个字的横躺短线）
- **逻辑**：favicon/app 图标形态的单焦点方案；躺平线是最轻的一笔摸鱼，外人只见装饰
- **文件**：`web-4-de-icon.svg`

## 四、网站线·第二批：发散五方案（2026-08-23 黑机，不绑院名）

> 院长指示：网站 LOGO 不局限于「男德学院」名称，发散发散。
> 五案全部脱离院名文字，从「社区本质（53万条消息/围坐/家）+ 生活锚点（搬板凳/躺平/长明灯）+ 已有资产（岁月史书年轮/德塔塔窗暖光）」发散。
> 全纯图形无 `<text>`，天然抗字体环境与缩小，favicon/小尺寸可靠性优于第一批。

### WEB-5 长明灯·书院灯笼（黑机主推）
- **意象**：晚间群聊最活跃——「总有一盏灯亮着的地方」。灯笼透光竖窗与德塔塔窗暖光形成屋外灯/屋内窗暗对仗，社区 = 亮灯处
- **气质**：书院感 + 等候感 + 归属感。与德塔线共用「暖窗/暖光」视觉母题
- **文件**：`web-5-lantern.svg`

### WEB-6 小板凳
- **意象**：「搬好小板凳」= 围观点评的入场券。把群聊吃瓜日常画进家具
- **气质**：歪凳面 + 绿坐垫 + 外八凳腿，最松弛的一张凳子
- **文件**：`web-6-stool.svg`

### WEB-7 年轮
- **意象**：2022 至今 53 万条消息，一圈一圈聊出来的年轮。与岁月史书模块直接呼应
- **气质**：偏心不完美同心弧 + 中心暖赭年髓 + 缺口处一颗正在长的新芽（年轮还在长，社区还在聊）
- **文件**：`web-7-rings.svg`

### WEB-8 躺平的人
- **意象**：不写「人」字——直接画一个翘着二郎腿躺平的人。开摆的行为符号化
- **气质**：凡夫 + 弄臣原型，Zzz 三点渐小克制不卡通。头暖赭（血缘色），身体深墨绿，极简色块
- **文件**：`web-8-lying.svg`

### WEB-9 冒泡小屋
- **意象**：烟囱冒的不是烟，是聊天气泡——「这个家的烟囱在冒话」。家屋与德塔堡垒对仗（网站是家 / 德塔是异世界）
- **气质**：暖窗屋里有人 + 屋顶冒泡，家的温度 + 群聊的闹
- **文件**：`web-9-home-bubble.svg`

## 五、组合建议（白机 + 黑机）

### 白机推荐（V4 第一批）
- **网站主标**：WEB-3 手绘松弛圈（组合标，TopBar 左侧圈 + 文楷「男德学院」横排）
- **网站 favicon**：WEB-4 德字图标（16px 单焦点最可靠）
- **德塔主标**：NDO-1 厚涂岩塔Δ（游戏加载页/关于页）
- **德塔 favicon/符文**：NDO-5 基准Δ
- 两线以「暖赭金」为血缘暗号（网站落款点/德塔塔窗同色）

### 黑机补充（V4.1 第二批后）
- 网站主标若走不绑院名方向：**WEB-5 长明灯**概念最顺（总有一盏灯亮着的地方），且与德塔暖窗母题血缘最自然；**WEB-7 年轮**最有岁月史书呼应，适合做社区「数据向」辅助图形
- **WEB-8 躺平的人**吉祥物潜力最大，可作辅助 IP（404 页/空状态/加载动画），类似 V3 咸鱼学士帽的定位但更抽象不具象
- 两批可组合使用：主标用 WEB-5/WEB-3，favicon 用 WEB-4 或 WEB-7（单焦点），辅助 IP 用 WEB-8
