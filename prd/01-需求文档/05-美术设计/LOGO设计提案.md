## 一、设计目标与约束

**目标**：给「男德学院」社区一个正式 LOGO，填补品牌空白（现状：全站零 LOGO、零 favicon，纯文字品牌）。

**约束（来自现有体系，不可违背）**：
1. 色彩必须服从 design-system 莫兰迪体系：鼠尾草绿 `#A8C5A0` 家族 / 暖赭 `#D4A574` / 米白 `#F5F2EC` / 墨灰 `#4A4A4A`
2. 字体沿用霞鹜文楷（Display 层），不引入新字体
3. 气质 =「一本正经地胡说八道」：外表庄重（学院徽章仪式感）× 内核戏谑（男德/摸鱼/开摆），符合编剧世界书铁律「对外不明觉厉，喜剧只在学院内部」
4. 必须可缩至 16px favicon（调研核心原则）

## 二、方案A：塔月徽章 Emblem（主推）

### 2.1 结构拆解（外圆内盾 = 中国校徽传统 × 西方纹章）

```
外环双圈（暖赭金） -- 大学校徽 seal 公式
├─ 上弧环排「男德学院」（霞鹜文楷）
├─ 下弧环排「修身 · 齐家 · 摸鱼 · 开摆」（院训入徽，早稻田式内部梗）
├─ 3/9 点菱形饰（纹章学分隔符）
└─ 中央盾徽（深墨绿底 #35483A = 鼠尾草绿深色变体）
   ├─ 塔（米白，垛口+拱门+三窗 -- 德塔本体，砖石建筑非魔法塔）
   ├─ 月（暖赭新月 -- 班走廊月亮 CG，已落地的剧情意象）
   ├─ 三粒微光星（德塔加护，淡金色微光）
   └─ 地平线+传送阵弧线（一楼大厅传送阵）
```

### 2.2 元素寓意表

| 元素 | 世界观出处 | 徽章语义 |
|---|---|---|
| 塔 | 据点「德塔」本体 | 学院根据地，品牌第一识别物 |
| 月 | 班走廊月亮 CG（第二章） | 温柔与守护，平衡塔的硬朗 |
| 微光三星 | 德塔加护（成员身上的淡金微光） | 成员身份认同 |
| 传送阵弧线 | 一楼大厅传送阵（连地球与异世界） | 「现实社区 ⇄ 德塔游戏」的元设定双关 |
| 院训环排 | 首页 Hero 院训 | 仪式感 × 戏谑反差的落点 |

### 2.3 调研依据对照

- 徽章式 = 学校/组织首选类型，象征荣誉与成员身份，一稿两用（社区 LOGO 即游戏内学院纹章）
- 塔+单一语境符号 = 埃菲尔官方品牌解法（塔形已泛化，靠语境符号翻新）
- 院训入徽 = 早稻田稻穗式数字彩蛋传统；下弧格言 = 普林斯顿书+盾+缎带三件套同构
- 配色全部来自现有体系色系家族，不引入体系外颜色

### 2.4 色板

| 用途 | 色值 | 来源 |
|---|---|---|
| 盾底/简化版圆底 | `#35483A` | 新增：鼠尾草绿 `#A8C5A0` 深色变体（待并入 design-system 时登记） |
| 塔身/高光 | `#F5F2EC` | 现有 `--md-bg` |
| 金色描边/月/星 | `#B8905E` / `#D4A574` | 现有 `--md-accent` 及其深化 |

## 三、方案B：组合标 Combination（备选）

简化塔月图形（圆形，同方案A-2）+ 横排「男德学院」大字标 + 院训副标。导航栏/页头日常使用，小尺寸可读性最稳，成长性好（未来可拆出图形独立使用）。

**双轨制建议（调研结论直接套用）**：大学「seal 限官方 + 日常简化标」的成熟模式--**方案A 完整徽章用于仪式/周边/游戏内，方案B 或 A-2 用于网页导航栏，A-2 单焦点版做 favicon**。两案并非互斥，是一套体系的两个层级。

## 四、变体体系（本次已产出）

| 文件 | 用途 | 说明 |
|---|---|---|
| `badge-full.svg` | 完整徽章：周边物料/游戏内/关于页/宣言 | 外圆内盾+环排文字 |
| `mark-simple.svg` | favicon / 头像 | 16px 单焦点：深绿底+米白塔+暖赭月 |
| `mark-mono.svg` | 印刷/单色/水印 | currentColor 继承，任意单色场景 |
| `combo-horizontal.svg` | 导航栏/页头横排 | 组合标备选 |
| `preview.html` | 草案预览页 | 含浅底/深底/16px/单色四组验证 |

已实测验证（2026-08-16，Playwright）：256/64/32/16px 四档尺寸均可辨、深浅底均成立、单色三色版正常、环排文字渲染方向正确（上弧顺时针/下弧逆时针均为可读方向，实测渲染宽度 171px/331px）。

## 五、待院长裁决

1. **方案选择**：A 徽章式（主推）还是 B 组合标？或双轨制（A 为主 + B/A-2 日常）？
2. **元素取舍**：盾内现含 塔+月+三星+传送阵弧线 四元素，是否嫌多（调研戒律：忌元素堆砌，单一记忆点最佳）？可砍至「塔+月」双元素极简版。
3. **是否 Seedream 精绘**：SVG 为手写矢量草案（未消耗任何生成 API）。若院长想要带羊皮纸/金属质感的精绘版（调研结论：新品牌第一版宜有质感），按红线须先确认提示词再调用。
4. **落地排期**：裁决后接入 index.html（favicon 矩阵 ico+svg+180+512）+ TopBar/HomeView，属小改动，可插空做。
