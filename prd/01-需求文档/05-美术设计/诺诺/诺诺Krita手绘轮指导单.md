## 2. Krita 操作规程（每张贴图同套路）

1. **建稿**：打开 src_v5 源 PNG → 另存 `.kra` 到 `krita_round/`（源稿留存纪律，等同立绘"带背景原图必须留存"）
2. **图层结构**：底层=原贴图（锁定）→ 调整层（色相/曲线，可选）→ 手绘层 → 顶层标注层（交付前隐藏）
3. **硬约束**：**不得改变画布尺寸与 UV 布局**——换回 VRM 靠 UV 对位，位移=贴图错位
4. **交付**：导出同名 `handpaint_iris.png` / `handpaint_brow.png` / `handpaint_face_skin.png` 放 `krita_round/` 根目录（注意命名是"材质语义"不是原贴图编号）
5. **上屏**：Blender headless 跑 `build_v7_texture.py` → main.js 缓存参数 ?v=8→**?v=9** → PoC 验收
6. 分工模式（⚖️ 院长选）：AI 全驱动（Computer Use）/ AI 备料+院长手绘 / 混合（推荐：Krita Python 脚本器做精确操作，艺术笔触人手）
