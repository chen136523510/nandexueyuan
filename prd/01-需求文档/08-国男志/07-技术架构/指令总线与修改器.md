# 指令总线与修改器

> 状态：✅ 已定（R3 立项/R6 入口定案），一期必做

## 指令总线（command bus）

引擎从第一天采用指令总线模式：**所有状态变更必须经过统一 command 入口**。

```
UI / 算法AI / 修改器 /（二期）LLM 采纳后的命令
        → command（加资源/改忠诚/改城归属/跳时间/解锁科技/瞬建/出兵…）
        → 规则校验 → 状态变更 → 事件记录
```

- 严禁任何调用方直改状态对象（否则存档一致性无法保证）；
- 修改器因此天然可做，且不污染引擎逻辑；
- 指令日志可支撑撤销/回放/调试（后续可选）。

## 修改器（调试工具 + 玩家金手指）

定位：开发期调试 + 上线后内部娱乐金手指（单机不影响他人）。

**入口（R6 拍板）**：**设置界面内功能区**——Esc 键或点击齿轮 UI 打开设置面板，修改器作为其中一区。

### 一期功能清单

| 类别 | 可改项 |
|---|---|
| 资源 | 金/粮/军力/生产力/科技值自由增减 |
| 城市 | 民生/忠诚、城防、归属阵营、空虚/废弃/起义状态切换 |
| 武将 | 四维点数、特技/技能解锁、驻守位置、阵营、个人忠诚 |
| 科技 | 一键解锁全部/指定节点（科技树上线后） |
| 时间 | 快进/暂停/跳到指定月；事件强制触发（测起义/自立） |
| 设施 | 区域瞬建、城墙满级 |
| 外交 | 关系值任意设定 |

### 二期扩展

战时无敌/采配无限/一击破城。

> 可选趣味：开修改器的存档不给"统一成就"（待定，非必须）。
