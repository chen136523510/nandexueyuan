# 部署与服务器承载评估

> 状态：✅ 已实测（2026-10-22 R4 白机 SSH 只读查询，未改任何状态）

## 生产机实测

| 项 | 实测值 |
|---|---|
| 机型 | 阿里云 ECS `47.96.158.104`（IP/账号/密钥以 `docs/account-passwords.md` 为准） |
| CPU | 2 核 Intel Xeon Platinum |
| 内存 | 1.6 GiB 总量，实测可用约 949 MB |
| 磁盘 | 40 GB，已用 15 GB，剩 23 GB（39%） |
| 负载 | load average 0.13 / 0.03 / 0.01（基本空闲） |
| 在跑 | Express API（约 71MB）、Colyseus game-server（约 41MB）、PM2、宝塔面板 |

## 结论：支持，前提是浏览器权威

游戏运算全部在玩家浏览器本地执行，服务器不参与任何对局模拟：

| 负载 | 放哪里 | 服务器承担 |
|---|---|---|
| 大地图 tick / 内政产出 | 浏览器 TS 引擎 | ❌ |
| 二期实时战斗（6~10 部队、碰撞、寻路、弹道） | 浏览器 Canvas | ❌ |
| 算法 AI（三阵营内政军事） | 浏览器 | ❌ |
| 存档 | LocalStorage/IndexedDB + JSON 导出 | ❌ |
| 静态资源（JS/立绘，gzip 后数 MB 级） | Nginx 托管 | ✅ 极轻，20 人量级无压力 |
| 账号鉴权（可选复用主站登录） | 现有 Express，加 `/api/guonanzhi/*` 路由 | ✅ 几个 API 请求 |
| 军师/外交 LLM（二期） | 服务器仅作 API 代理（藏 key）+ 火山方舟 GLM 出站 | ✅ 无状态转发，零新增订阅 |

## 红线

- **绝不在服务器跑对局模拟**：1.6G 内存已用近半，每多一个常驻对局进程都是硬挤，单机游戏无此必要；
- Nginx 不新开端口，对局纯前端；
- 未来若做"群友异步对战/排行榜"（需服务端权威对局），当前机型不够，届时另行评估——首版单机明确不做。

**一句话**：这台 2 核 2G 的机器对国男志只是"静态站 + 登录 + LLM 转发器"，真正干活的是院长和群友自己的电脑。
