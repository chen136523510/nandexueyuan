# UI 雏形规划（界面先行）

> 状态：⛰️ 立项（R15 院长定调「先做雏形、界面 UI 先行」），九屏清单为建议稿待院长圈选优先级 · 更新：2026-10-24 R15
> 原则：**界面先行、逻辑假数据**——雏形只定布局/交互/信息密度，不接任何游戏逻辑（不接指令总线/存档）。目的：把前 14 轮设计文档落到可见界面上，暴露机制矛盾，并倒逼悬而未决项（L2 网格基点等）拍板。

## 为什么 UI 雏形先行（R15 白机理由，院长认可方向）

1. 设计文档已经够厚，纯文字讨论边际递减；界面落地是最快的矛盾检测器；
2. R14 内容目录 v1（产业 14+娱乐 10+居民楼四型）刚好当假数据，界面有货可摆不空转；
3. 院长意愿=先把界面设计好；UI 定型后数据结构呈现方式确定，后续模块（兵种/科技树）有了挂载点。

## 假数据原则

- 全部占位数值，写死在组件里，不接指令总线/存档/真实结算；
- 可点击跳转模拟真实动线（L1 点城进 L2、点地块弹建造面板）；
- 雏形定型后按 07 架构拆正式组件，不推倒重来。

## 双机分工（按 AGENTS 分工口径）

- **黑机**：UI 风格小样（配色/面板质感/字体气质 2~3 版，Krita/ComfyUI 管线，遵守美术纪律）——UI 风格与地图风格小样（黑机协作清单 #6）可同批出；
- **白机**：Vue 可点击雏形代码（纯代码线，白天窗口主活）；
- 黑机窗口可先行出轻量线框 HTML（轻代码，不占重工具链窗口）。

## 技术基线

- Vue3+TS 已定（R1）；雏形怎么快怎么来（DOM 网格即可），正式版 L1/L2 用 Canvas；
- 雏形产物放 `poc/` 或 `01-地图与城市/原型预览/` 同级的独立原型目录（建目录时定），不进正式 `src/`。
