## 〇、背景（执行 AI 1 分钟读完）

《国男志》是仿三国志 12 的现代架空策略经营游戏（Web 单机）。界面分三层：L1 战略大地图 / **L2 城市内景（本施工单目标：玩家处理内政时看到的界面）** / L3 战斗场景（不在本单范围）。L2 采用**网格地块制**（红警式）：建筑占不同格数、网格内自由摆放；**网格线可隐藏**（右上角开关）。首城试点=深圳（玩家老家，CN 阵营，红色主题点缀）。

深圳初始已放置 4 件建筑（市政府+高新园+学院+小区），其余靠玩家建造。可建目录 38 条（本单 §三全量给出）。

深圳还有**地形层**（v1.2 具名版）：伶仃洋+深圳湾在南缘、深圳河在东界、梧桐山/阳台山在北缘、塘朗山/莲花山/大南山丘陵进城——全部按深圳现实地理命名，地形格不可建，是「每城独一无二」的第一抓手（规格 §2.2/§3.3；设计文档 01-地图与城市/地形设计.md，执行 AI 不需要读它）。

## 一、产物形态与文件结构

纯静态、无构建、file:// 双击可开（与既有 L1 地图原型同惯例）：

```

  css/style.css     # 全部样式

  验收图/            # 各里程碑截图
```

- Vue 用 UMD 版 CDN：`https://cdn.jsdelivr.net/npm/vue@3.4.38/dist/vue.global.prod.js`（全局 `Vue`，模板写在 JS 字符串里，不用 SFC/JSX/ESM）。
- 打开原型需联网（CDN），README 里写明。
- 页面按 1440×900 桌面设计，最小可用宽度 1200；不做移动端适配。

## 二、界面规格

整体布局：**顶栏 HUD（64px）+ 左侧城市画布（自适应居中）+ 右侧建造面板（320px，可收起）+ 底部消息条（28px）**。

### 2.1 主 HUD（顶栏）

从左到右：

1. 阵营徽标：红底圆角方块内白字 `CN`（#e63946）；旁列两行：城市名「深圳」、小字「商业/工业 · 玩家老家」。
2. 城市切换下拉：只有「深圳」可选，其余 12 城列出但禁用、后缀「未开发（试点首城）」。
3. 资源条（7 枚 chip，图标+数值）：金 5000 · 粮 3000 · 军力 500 · 能源 0 · 生产资料 1000 · 生产力 +20/回 · 科技值 +5/回。前五为存量（变动即时刷新），后两为每回合流量（由基础值+已建成建筑产出累加，实时重算显示）。
4. 回合数「回合 1」+ 主按钮「下一回合 ▶」。
5. 「👁 网格」开关（切换网格线显隐，默认显示）。
6. 「返回大地图」按钮 → 点击弹 toast：「L1 大地图不在本雏形范围」。

- 顶部 4 个 tab：**基础（5）/ 产业（15）/ 娱乐（10）/ 居民楼（8）**；产业 tab 内按 重工业/高新技术/能源/轻工 四组小标题分段。

### 2.4 放置模式与建造预览弹窗（R13 核心交互）

流程（必须完整实现）：

1. 选中目录卡 → 面板卡高亮，底部消息条提示「放置模式：点击开发区内空地放置，右键/Esc 取消」。
2. 鼠标悬停画布：以悬停格为左上角显示 **w×h 幽灵建筑**——合法=绿色半透明、非法（出界/重叠/边界外）=红色半透明；点击非法格 → toast「此处不可放置」。
3. 点击合法格 → 弹出**建造预览弹窗**（画布上同步渲染该建筑的覆盖圈预览）：
   - 标题：图标+名称；
   - 信息行：占地 / 造价（金 X · 生产资料 Y）/ 建造回合数；
   - **建成后数值变化**：逐条列出该建筑 yields（如「生产力 +8/回」「科技值 +6/回」「宜居度 +2（覆盖圈内居民楼受益）」），并在资源条对应 chip 上做 +N 高亮闪烁一次；
   - 有 cover 的显示「生效范围：半径 N 格」；
   - 底部按钮：**确认建造** / 取消；
   - 资源不足时确认按钮禁用，差额红字「金不足 320」。
4. 确认 → 扣金+生产资料 → 建筑以「建造中（0/Y）」状态落格 → toast「已开始建造」→ 预览弹窗关闭、退出放置模式。

### 2.5 建筑详情弹窗与拆除三分法（R13）

点击已放置建筑（非放置模式下）→ 详情弹窗：

- 通用区：图标+名称、状态（已建成 / 建造中 X/Y / 停工）、产出列表、覆盖圈（有则显示，hover 画布亦可见）。
- 操作按钮按状态分（拆除三分法）：

| 状态 | 按钮 | 效果 |
|---|---|---|
| 建造中 | [拆除] [停工] | 拆除=返还 9 成生产资料（金全返），建筑移除；停工=保留进度、灰显占格 |
| 停工 | [复工] [拆除] | 复工=继续倒计时；拆除=同上返 9 成 |
| 已建成（本回合完工） | [拆除] | **无损拆除**：金+生产资料全额返还 |
| 已建成（往回合完工） | [拆除] | 返还 9 成生产资料（雏形简化，正式规则数值期定） |

- 每个拆除按钮 hover 显示返还明细 tooltip；确认前用弹窗内二次确认行（点一次变「确认拆除？」再点执行）。

### 2.6 假逻辑（js/app.js）

- 状态：`{ turn, stocks:{gold,food,mil,energy,mat}, buildings:[{uid,catId,x,y,status:'done'|'building'|'paused',remaining,total,builtTurn}], placingCatId, activeModal }`。
- **下一回合**：turn++；每个 building 状态 building→remaining--，归零则 status=done、builtTurn=turn、toast「{name} 建成」；存量结算：stocks.food += Σfood、gold += Σgold、energy += Σenergy（仅 done 建筑）；流量重算（基础 prod 20/tech 5 + Σ）。
- 放置合法性：目标 w×h 全部落在开发区内（总坐标 x,y ∈ 2..9）且不与任何现有建筑格、任何地形格（海/河/山/丘）重叠。
- 网格开关只影响网格线 CSS 类，不动数据。

## 六、总验收清单（M5 自测 + 院长走查路径）

1. 双击 `poc/guonanzhi-ui/index.html` → 见深圳 HUD + 网格城市，资源数字正确；
2. 「👁 网格」开关切换网格线显隐，建筑不受影响；
3. 建造一座公园：选中卡 → 幽灵放置（绿/红反馈）→ 预览弹窗显示「宜居+2 · 半径 1 格」与资源变化 → 确认 → 金/生产资料扣减 → 建造中 1/1 → 下一回合 → 建成；
4. hover 公园显示圆形覆盖圈；
5. 当回合拆掉刚建成的公园 → 明细显示**全额无损返还**，资源回滚一致；
6. 建造中拆钢铁冶炼厂 → 返还 9 成生产资料；停工→复工链路可走通；
7. 点击市政府 → 血条 100% 弹窗，无拆除按钮；
8. 把金花到不足 400 → 选商业中心 → 确认按钮禁用并显示差额红字；
9. 点击边界外格子 → 「此处不可放置」；
10. 城市下拉其余城禁用；「返回大地图」弹提示 toast；
11. 放置模式下把幽灵建筑压到海/河/山/丘格上 → 红色非法、点击提示「此处不可放置」。
