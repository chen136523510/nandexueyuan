# 区域与建筑

> 状态：✅ 结构已定（R2/R3/R6/R11），数值待一期成型后微调

## 六类区域（参考文明 6，现代化命名）

| 区域 | 产出 | 备注 |
|---|---|---|
| 学院 | 科技值 | 推进科技线 |
| 商业中心 | 金 | 募兵/外交/俸禄/升级 |
| 军事基地 | 军力（兵力/城防） | 守军兵力上限；二期战场实体=补兵建筑 |
| 工业区 | 生产力 | "矿山"仅借代，可命名为算力中心/发电中心/**核电站**等效形态；核电站生产力高但天灾时有核污染变体（二期） |
| 娱乐中心 | 民生/忠诚 | **每城各有特色**（与城市地标特色呼应） |
| 农田 | 粮 | 养兵/出征消耗 |

另有 **城墙**（城防建筑，非六区域之一）。

## 建造规则

- **槽位不设数量上限**（R6 拍板）：六区域+城墙自由建造；
- 取舍来自：生产力/时间预算（同时只能建有限数量）、武将驻守能力、维护成本；
- 城市发育度决定城市范围→二期战场布防纵深（详见 [01-地图与城市/城市成长与城防.md](../01-地图与城市/城市成长与城防.md)）。

## 武将派驻建筑（R11 立项，数值待定）

城中角色可分配到具体建筑挂职，给该建筑对应效果加成：
- 派驻**军事基地** → 练兵速度、兵员质量提升；
- 派驻**商业中心**（院长口称"交易所"）→ 财政收入提升；
- 其余区域同理（学院/工业区/娱乐中心/农田的效果方向待细化）。

不同角色有不同侧重（挂勾武将属性体系，见 [02-武将/属性体系.md](../02-武将/属性体系.md)）——**谁驻哪个建筑是内政策略层**。数值与侧重维度后续专题讨论（R11 院长：数值后续慢慢讨论，先把机制记下）。

## 二期战场实体化（红警范式）

内政建筑在二期实时战场中实体存在：城墙=可拆墙体/城门、军事基地=补兵建筑、附属箭塔=防御塔、农田/商业中心=城外地表可掠夺建筑。详见 [04-军事/内政战场联动.md](../04-军事/内政战场联动.md)。
