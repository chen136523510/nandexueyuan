## 已拍板决策摘要（截至 2026-10-22）

- **形态**：Web 单机（Vue3+TS+Canvas），浏览器权威（服务器只做静态托管/鉴权/LLM 转发，实测 2 核 1.6G ECS 余量充足）
- **规模**：**13 城定档**——CN 6（北京/上海/深圳/西安/香港/台北）、JP 3（东京/长崎/名古屋）、KR 2（首尔/仁川）、AU 2（悉尼/墨尔本）；21 将驻守定档（深圳 4 人含院长；王乐添=台北低忠诚高自立风险）；**玩家开局自选 CN/JP/KR/AU**
- **规则**：每城须有人驻守空城废弃；1 太守+幕僚（无将才空虚）；**城市民生低→起义（城池中立只守不攻）；武将个人忠诚低+独领城→自立新阵营（国号=头目英文缩写如 WLT）**
- **人才**：破城可俘获太守（可逃跑），四处置=劝降/释放/拷打机密/处决，均引发外交变化；21 将不补员，处决永久减员
- **规则**：每城须有人驻守，空城废弃（产出忠诚大减）；太守出征=后方空虚；忠诚过低叛乱
- **内政**：六区域（学院/商业中心/军事基地/工业区/娱乐中心/农田）+城墙；**槽位不限**，发育越好城市范围越大、越难攻破；科技树近现代起点（AI/天网/星链/无人机），含环保民生方向，待专题
- **军事**：二期 2D 轻量 RTS（路径 C）——右键下令自动时停、移动实时遥控、暂停全军部署；带队武将各自技能；红警式建筑实体化；**一期全自动档**（数值结算+战报），一套判定模型两档共用
- **一期范围**：内政循环 + 忠诚叛乱 + 规则外交 + 全自动战斗；天灾/异族/军师 LLM 均二期
- **架构纪律**：指令总线（修改器同源，入口=设置界面 Esc/齿轮）；JSON 数据驱动；引擎与 UI 分离
- **内容**：内部消遣不商业化，当代元素允许；唯一底线=群友真人梗本人过目+可退出
