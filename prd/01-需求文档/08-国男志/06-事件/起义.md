# 起义

> 状态：✅ 结构已定（R8 改名+定机制），数值待一期成型后微调

## 两种"造反"，机制分开

| | 起义（城市） | 自立（武将） |
|---|---|---|
| 触发主体 | 城市/民众 | 武将个人 |
| 主因 | **民生**低到一定程度 | **个人忠诚**低 + 独领一城（通常也伴随民生低迷） |
| 结果 | 城池变**无主之地（中立）**，类似中立单位，**只守不攻** | 建立以头目名缩写命名的**新阵营**（如 WLT），城与驻军倒戈 |
| 文档 | 本文件 | [02-武将/忠诚度.md](../02-武将/忠诚度.md) |

院长原话："绝大多数情况下，只有民生低到一定程度，才会引发这种事件。"

## 起义城（中立）行为

- 不属于任何阵营，不主动进攻；
- 可被任何阵营攻取（平叛/收复）；
- 攻取后需派将驻守，否则仍走空虚→废弃流程；
- 一期：以状态+数值结算实现；二期：平叛可作为一种战斗类型（见 [04-军事/战斗类型.md](../04-军事/战斗类型.md)）。

## 抑制

资源足够即可稳住后方（院长原话）：娱乐中心/建设提升民生、驻军压制、太守能力；具体手段与数值待内政数值专题。

## 待数值

- 民生起义阈值；
- 起义概率与持续时间；
- 中立城守军强度（与原城防/兵力的关系）。
