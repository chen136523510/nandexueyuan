# 一期 / 二期范围切分

> 状态：✅ 已定 · 更新：2026-10-22 R8
> 原则：一期跑通"内政→出兵→占城→处置"完整战略循环；二期加战场表现力、事件与 AI。

| 系统 | 一期（战略循环可玩版） | 二期 |
|---|---|---|
| 内政 | 六区域+城墙+资源+驻守城态（无槽位上限，范围成长） | 同 |
| 科技 | 待专题，一期可能仅占位/简化（近现代起点） | 完整科技树（AI/天网/星链/无人机+环保民生） |
| 武将 | 21 将名册/驻守/个人忠诚/自立/俘虏四处置 | 技能在实时战场释放 |
| 战斗 | **全自动数值结算+文字战报**（唯一战斗模型） | 2D 轻量 RTS 手动档（与自动档共用同一判定模型） |
| 战斗类型 | 按攻守城市对自动判定（内陆/登陆等） | 同，登陆战滩头表现细化 |
| 内政-战场联动 | 设施等级折算进结算数值 | 城墙/基地/箭塔实体化（红警范式） |
| 外交 | 规则判定+模板话术；处置俘虏引发关系变化 | +LLM 谈判（JSON 闸门） |
| 事件 | **城市起义 + 武将自立** | + 天灾（沙尘暴/海啸/污染）、异族入侵（西北陆患/沿海海盗） |
| LLM | **不接**（系统雏形多，无可读现状） | 军师（只读 snapshot）先行，外交 LLM 随后 |
| 修改器 | **必做**：指令总线+设置界面内控制台 | +战时金手指 |
| 存档 | 浏览器本地存档（LocalStorage/IndexedDB+JSON 导出） | 同 |

## 关键架构约束

- **一套战斗判定模型两档共用**：一期自动结算就是二期自动档，二期手动档只加渲染与指令层，不写第二套规则。
- 一期数据结构即按二期战场实体建模（设施等级/位置战场可读），避免两套数据。
- 数值一期成型后统一微调，现阶段只定结构。
