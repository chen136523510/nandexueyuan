# 游戏定位与范围

> 状态：✅ 已定 · 更新：2026-10-22 R8

## 一句话定位

仿三国志 12 的实时策略经营游戏 × 文明 6 区域/科技内政 × 红警式"内政建筑即战场实体"联动；架空东亚微缩地图，男德学院 21 名群友分属 CN/JP/KR/AU 四阵营逐鹿 13 城。

## 基本盘

| 项 | 定案 |
|---|---|
| 模式 | **单机**（不做网络对战） |
| 技术形态 | Web：Vue 3 + TS + Canvas，JSON 数据驱动，纯 TS 引擎与 UI 分离 |
| 运算位置 | **浏览器权威**（服务器只做静态托管/鉴权/LLM 转发，见 [07-技术架构](../07-技术架构/部署与服务器.md)） |
| 城市 | **13 城**（上限 ≤21，留 8 格扩展） |
| 武将 | **学院 21 人群友，不加 NPC、不补员** |
| 阵营 | 4 个：CN/JP/KR/AU；玩家开局自选 |
| 单局时长 | **不设上限**（R13："可以一局打好几天"）；原 3~6 小时节奏指标作废 |
| 成本纪律 | 全自研/开源/免费，零订阅；LLM 走现有火山方舟通道 |
| 商业化 | 不商业化，内部群体消遣；内容尺度相应放宽（真人玩梗仍需本人过目） |

## 核心循环

```
内政（区域建设/科技/调将/资源）
  → 募兵编成（武将率军，太守出征则后方衰减、跌破临界才空虚）
  → 出征（仅邻接可攻；跨海=登陆战；需提前组织粮草定进攻时限）
  → 战斗（一期全自动结算 / 二期轻量 RTS 可手动）
  → 破城（占领市政府；俘获太守/城池起义中立化）
  → 处置俘虏（劝降/释放/拷打/处决，联动外交）
  → 扩张与镇守（无将空城持续衰减→易空虚起义，受 21 将总数硬约束）
  → 外交/科技破局 → 统一
```

## 设计原则

- **负反馈纪律（R13 院长定调）**：不给玩家设置过多负反馈——不轻易出现"设施破坏需要修复"类惩罚（战后重建从轻）；**不教玩家玩游戏**，只提供足够丰富的选择和路线；**前期不要有太多战事发生**（开局和平期设计 ⛏ 待专题）。
- **内容体量优先（R14 院长定调）**：整个游戏通过 AI 搭建，玩法不是核心竞争力（拼凑各家游戏精华即可），**游戏体量才是引人留存的关键**——设计工作按"一个模块一个模块拓展内容"推进（扩内容不扩玩法复杂度），白机依授权逐模块产出内容目录（03-内政目录 v1 已启，见 [03-内政/区域与建筑.md](../03-内政/区域与建筑.md)）。

## 胜利条件

统一 13 城（消灭/劝降其他阵营）为基本途径；**R13 要求增设其他获胜途径**（科技/文化/外交等方向 ⛏ 待专题设计）。
