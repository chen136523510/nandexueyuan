# 关系规则与 LLM

> 状态：🏗️ 结构已定，一期不接 LLM（R6 拍板推迟二期）

## 关系规则（一期）

- 势力间关系值受：外交行动、战争行为、**俘虏四处置**（劝降/释放/拷打/处决）、条约破弃等影响；
- 俘虏处置的外交震荡方向见 [02-武将/俘虏与处置.md](../02-武将/俘虏与处置.md)：处决=强烈震荡（忌惮/愤怒/死战不降）、释放=善意、拷打=被曝势力恶化、劝降=与原势力恶化；
- 声望机制（沿用蓝本：丢城/胜仗/释放俘虏/处决等影响声望，声望再影响外交态度与劝降）。

## LLM 的两个接缝（均二期）

```
确定性游戏引擎（唯一状态源）
   ├── 算法 AI（内政/军事）→ 命令
   ├── 外交系统
   │     ├── 规则层：关系值/利益/筹码 → 唯一判定
   │     └── LLM 层：谈判文本/提案措辞/人物语气（不判定）
   └── 军师 LLM：读 snapshot → 建议+理由+引用数字（只读，玩家采纳才执行）
         JSON Schema 校验 → 规则闸门 → 合法命令/纯文本建议
```

### 军师 LLM（二期先于外交 LLM）

- 输入只读 snapshot：城市/兵力/资源/外交/威胁/科技（参考诺诺 snapshot 思路，见 [../参考资料.md](../参考资料.md)）；
- 反幻觉：数字由引擎注入，LLM 只解释与排序；情报不足须明说；
- R6 拍板推迟原因：一期系统多为雏形/未定版，LLM 没有可靠现状可读，强上只会幻觉。

### 外交 LLM（二期）

- 输出 `{stance, terms, dialogue}` 经规则闸门校验（筹码存在/不超预算/不违约/人物红线），不合法回退模板话术；
- 不可见战争迷雾隐藏信息；超时不影响游戏；
- 成本：仅外交发生时调用，走火山方舟 GLM 现有通道，零新增订阅。
