# 城市特色与地标

> 状态：✅ 已定素材持续追加中（R14：台北+台积电、西安+秦长城、首尔+萨德建议待确认） · 效果数值待数值期 · 更新：2026-10-23 R14
> 机制：现实地标作为城市**特色词条**（每城 1~3 个），给对应区域产出加成或挂专属事件；是"每城各有特色"的落地方式。

## 备注

- 院长原意询问的是**富士山**（白机一度误答为富士康，已在 R7 更正），两者均保留：富士山挂东京、富士康挂台北。
- 一城可挂多个特色（东京=首都复合型 3 词条、台北=代工+半导体双词条）。
- 内容尺度：内部消遣不商业化，现实元素允许使用（见根 README 创作原则）。
- 待补词条（7 城）：上海/深圳/西安(产业向)/香港/悉尼/墨尔本——随内容拓展逐模块补齐。
