# ADR-005：德塔世界观承载方式（CG/漫画演出层 + 联机状态同步 + 不切 3D）

> 状态：Accepted | 决策人：陈梓键（院长） | 日期：2026-07-27
> 关联：设定集 v1.3、德塔战斗数值设计文档、R-009 德塔战斗系统、ADR-002 角色坐标系

---

## 背景

设定集 v1.3 已沉淀了**庞大的世界观资产**（118 年历史、六大势力、四大领袖 NPC、四线交汇、四大伏笔、好感度系统、学院颠覆性主题）。但当前德塔游戏形态是**泰拉瑞亚式 2D 横版 sandbox**，其叙事承载力与世界观资产之间存在结构性落差：

1. **70% 的世界观内容是叙事性的**（势力博弈、人物群像、历史时间线、伏笔），纯横版打怪探索无法承载
2. **2D 横版先天弱于剧情介入**：镜头语言弱、角色表现受限、节奏由玩家主导，难以做有导演感的剧情演出
3. **黑机投入巨大的世界观产出面临"沉没风险"**：男德通目前只会说一句"嘿！"，与厚重历史落差巨大
4. **院长核心诉求**：世界观取材致敬现实生活，**项目初衷是"小集体抽象娱乐"，不可背离**——不能为追求"完整呈现"过度工程化

院长同时提出两个待评估的方向：
- **方向 A**：是否切到 Unity 做 3D 大型游戏（刺客信条级别）？
- **方向 B**：用 AI 视频/漫画工具搭一套 CG 生成工作流

本 ADR 锁定方向 B 的技术选型，并**否决方向 A**。

---

## 决策

### 决策 1：剧情承载方式 = CG/漫画演出层（P0 漫画，P1 视频增强）

**采用"战斗 sandbox + 独立剧情演出层"分离架构**（JRPG/手游验证过的成熟模式），不追求"完整呈现"，按需承载关键节点。

**触发时机**（参考 JRPG 标配）：
- 击杀 BOSS 后（高潮叙事）
- 首次到达新地图（地理展开/世界观铺垫）
- 关键 NPC 初遇（人物登场）
- 主线里程碑（学院净化重大节点）

**首次自动弹出，可在 HUD 或男德通聊天界面回顾**（院长明确要求）。

**P0 主路径：纯漫画**（玩家一页一页翻，"玩游戏送漫画"）
- 工具链：**ComfyUI（黑机已有）+ IP-Adapter + Reference 节点**
- 角色一致性：IP-Adapter 是业界标准方案，成熟度 ⭐⭐⭐⭐⭐
- 美术风格：**像素风优先**（与现有精灵表/立绘/头像统一）
- 排版：ComfyUI 出单格 → 脚本/PS 拼页 → 脚本叠加中文对白气泡
- **优势**：零 API 成本、复用黑机现有美术流水线（R-003 精灵表同源）、黑机已有 mygo LoRA 经验

**P1 可选增强：视频片头/片尾**（仅用于重大节点，控制成本）
- 候选工具（按角色一致性能力排序，**未全部经手验证，落地前需 PoC**）：
  | 产品 | 关键能力（已确认） | 状态 |
  |---|---|---|
  | **Vidu（生数科技）** | 多主体一致性（7 张参考图+主体库）、图生视频+首尾帧、1080P、动漫风强 | **首选**，唯一明确支持角色复用 |
  | 腾讯混元生视频 | 图生视频、动漫/3D 风格、按 QPS 计费 | 次选，角色一致性待验证 |
  | 即梦 Seedance / 可灵 / 通义万相 | API 均开放，参数未手核 | 待院长浏览器核对官方定价页 |
- **不推荐全视频 CG**：单段成本高、一致性难、小集体项目过度工程化

### 决策 2：所有"进度类"状态必须联机同步（含剧情解锁）

**核心原则**：换机/多端不得丢失进度。

- ❌ **禁止**仅用 `localStorage`（单机，换机丢失）
- ✅ **必须**服务端持久化：
  - 剧情解锁状态：用户表 `unlockedStoryIds[]`
  - 好感度（设定集 v1.3 已锁定数值锚点 0-100）
  - 战斗系统相关进度（怪物击杀记录、净化进度等）
- 登录时下发，解锁/变化时 API 上报
- CG/漫画**资源本身**是静态资源（打包前端），无需同步，只同步"状态"

### 决策 3：否决"切 Unity 做 3D 大型游戏"

**明确否决方向 A**，理由：

1. **单人开发 3D 动作游戏成功率极低**（业界共识）：刺客信条级项目需数百人、3-5 年、上亿美金
2. **AI 美工解决不了核心难点**：AI 能生成贴图，但生成不了**动画衔接、关卡设计、动作手感**——而这三者是动作游戏灵魂
3. **沉没成本**：Vue 前端、Phaser 全部代码、所有 2D 精灵表/立绘/HUD 会打水漂
4. **背离初衷**：3D 大项目是"工业级"投入，与"小集体抽象娱乐"初衷冲突
5. **现有架构已验证可行**：2D 多人同步已跑通（R-003、多人同框）

**保留可能性**：若未来确有"更沉浸的探索"需求，优先在 2D 内升级（如 2D 俯视角，信息密度高于横版），而非切 3D。

## 替代方案对比

| 方案 | 剧情承载力 | 工程成本 | 与现有架构 | 是否采纳 |
|---|---|---|---|---|
| **A. 纯泰拉瑞亚，剧情碎片化叙事**（学魂系列） | 弱 | 低 | 完全兼容 | ❌ 否决（世界观沉没） |
| **B. 战斗 sandbox + CG/漫画演出层** | 强（关键节点） | 中 | 不推翻，加层 | ✅ **采纳** |
| C. 转 2D 俯视角 RPG（学星露谷） | 强 | 高（重做） | 推翻前端 | ⚠️ 备选，暂不动 |
| D. 切 Unity 做 3D 动作 | 极强 | 极高（2-3 年） | 全部打水漂 | ❌ **否决** |
| E. 切 Unity 做 2D VN 风格 RPG | 中 | 中（重做） | 推翻前端 | ❌ 否决（相对 Phaser 无明显优势） |

## 影响评估

### 对战斗系统阶段1的影响

**无直接影响**。战斗系统阶段1（R-009）按原计划推进，CG/漫画演出层是独立的后续工作。本 ADR 只是**提前锁定承载方式**，避免战斗做完才发现剧情无处安放。

### 对美术产能的影响

| 资产类型 | 估算规模 | 黑机产能 | 风险 |
|---|---|---|---|
| 漫画分镜 | 阶段1 约 20-40 格 | ComfyUI 本地，无 API 成本 | 低（产能可扩） |
| 全量剧情 CG | 150-250 张（六大势力全展开） | 约 2-4 周黑机全职 | **中**（需分批，按主线节点优先级） |

**应对**：不追求"完整呈现"，按主线优先级分批产出。阶段1 仅做"学院降临 → 第一只怪 → 净化首个裂隙"的最小剧情闭环。

### 对联机架构的影响

- 新增服务端 API：`GET /api/story/unlocked`、`POST /api/story/unlock`
- 用户表新增字段：`unlockedStoryIds`（JSON 数组）
- 客户端 Vue 层新增：剧情回顾组件（HUD 入口 + 男德通聊天界面入口）
- Phaser 层新增：剧情触发监听（接服务端 `broadcast('story-trigger')`）
