# ADR-006：德塔 视觉小说 引擎选型

> 状态：Accepted | 决策人：陈梓键（院长） | 日期：2026-07-29
> 关联：ADR-005（德塔世界观承载方式）、设定集 v1.4、技术设计/视觉小说重构规划.md

## 背景

2026-07-29 院长确认废弃原 2D 动作/俯视游戏方向（Phaser/Colyseus），改为 视觉小说（叙事驱动 + 立绘 + 背景 + 对话 + 分支世界线）。需要决定用什么引擎来实现。

### 约束条件

1. **网站点进去就能玩**：用户从 `nandexueyuan.top` 的 `/nde` 路由直接进入，不想搞独立应用
2. **不联机**：视觉小说 是单机体验，不需要多人同步
3. **白机黑机都能开发**：白机是便携本无显卡，但能写 Vue 代码；黑机有 RTX 4070 可跑 ComfyUI
4. **与社区功能联动**：同一个网站，与师德墙/男德通等模块无缝集成

## 决策

**采用 Vue 3 Web 自研方案**，在现有项目内新建 `src/视觉小说/` 模块，自建轻量 视觉小说 引擎。

## 替代方案

### 方案B：Unity WebGL 嵌入

- 优势：商业级引擎，生态成熟，跨平台（PC/手机/Switch）
- 劣势：① 白机无法参与开发（Unity 只有黑机有）② WebGL 包体大，加载慢 ③ 与社区功能割裂，需 iframe 嵌入 ④ 对一个20人朋友圈项目来说体量过重
- **否决理由**：浪费白机开发能力 + 与网站集成困难

### 方案C：Ren'Py Web 导出

- 优势：业界最成熟的视觉小说专用引擎，开箱即用（对话框/分支/存档/CG鉴赏全有）
- 劣势：① 脱离现有 Web 技术栈 ② Web 导出不成熟，集成困难 ③ 不支持联机扩展 ④ 独立应用，与社区功能割裂
- **否决理由**：与网站集成困难 + 技术栈不统一

## 决策依据

| 维度 | Vue 3 Web 自研 | Unity WebGL | Ren'Py |
|------|:---:|:---:|:---:|
| 网站集成 | ✅ 原生路由 | ⚠️ iframe | ❌ 困难 |
| 白机参与 | ✅ 全能 | ⚠️ 仅剧本 | ⚠️ 仅剧本 |
| 加载速度 | ✅ 快 | ❌ 慢 | ⚠️ 中 |
| 社区联动 | ✅ 无缝 | ❌ 割裂 | ❌ 割裂 |
| 引擎轮子 | ⚠️ 自建 | ✅ 成熟 | ✅ 开箱即用 |
| 联机扩展 | ✅ 可接 Colyseus | ⚠️ 需 Photon | ❌ 不支持 |

## 影响

- **新增**：`src/视觉小说/` 模块（引擎核心 + 组件 + store + 剧本数据）
- **新增**：后端 `GameSave` + `GameProgress` 数据库表 + `/api/视觉小说/*` API
- **路由变更**：`/nde` 从占位页 `NdeRebuildingView.vue` 切换到 `Nde视觉小说View.vue`
- **保留**：旧 `game/` / `game-server/` 代码废弃保留不删
- **剧本格式**：JSON 数据文件，白机/黑机都能编辑，不用碰代码
