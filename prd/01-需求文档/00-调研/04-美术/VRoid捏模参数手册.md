## 一、核心结论（先看这个）

1. **编辑器框架（官方一手）**：脸 / 发型 / 身体 / 服装 / 配件五大编辑器；每个编辑器内分 **Design（形状滑杆）/ Texture（贴图笔刷）/ 预设** 三层。
2. **脸部 17 类目**（官方原文）：Face Sets（整脸预设）、Eyes Sets（眼部套装）、Irises（虹膜）、Eye Highlights（眼高光）、Scleras（眼白）、Eyebrows（眉毛）、Eyelid（眼睑）、Eyeliner（眼线）、Eyelashes（睫毛）、Nose（鼻）、Mouth（嘴）、Mouth Inside（口腔）、Lips（唇）、Cheeks（脸颊）、Skin（皮肤）、Face Paint（脸绘）、Expression Editor（表情编辑器）。
3. **参数可超限**（官方一手）：Face/Body 编辑器数值可直接键入超过滑杆上限的值（官方演示 Shortness 拉到 4.0 模型直接翻转）——**诺诺捏模纪律：只在滑杆范围内调**，超限无官方支持、动画可能异常。
4. **蒂法官方设定（双源验证：Final Fantasy Wiki + 百度百科）**：身高 167cm、三围 92/60/88、血型 B；瓜子脸、柳叶眉、大眼睛、宽双眼皮、高鼻梁、薄唇、及腰乌黑长发（发尾扎起）。已逐项转译为下文参数方向。
5. **VRoid 的天花板**：预设骨架+参数化变形，**到不了 FF7R 蒂法级**（差距分析见第八节）——但把 VRoid 调到"写实向美少女上限"完全够 PoC，且与诺诺 MyGO/GBC 番剧卡通风定调方向一致。
6. **导出优化**（社区一手，mrxiaom.top 实测教程）：导出 VRM 时 Reduce Materials 材质合并拉满(12)、Texture Atlas 2048、多边形控制在 32000 左右（上限 65535）。

## 二、脸部参数全集与美学解读

### 2.1 脸型轮廓（Face Sets 类目下的形状滑杆）

| 参数（界面） | 人体学意义 | 美学解读与建议 |
|---|---|---|
| Face Width / Cheek（脸颊宽度） | 颧骨体+颊软组织水平宽 | 写实向收窄 -20~-40；宽颊=幼态Q版 |
| Chin Width（下巴宽度） | 下颌颏部宽度 | **写实向关键**，-30~-50；下巴宽=男性化/Q版 |
| Chin Length（下巴长度） | 颏点到唇下距离 | 蒂法下巴短而精致，0~-10 微收；过长显"马脸" |
| Chin Position（下巴前后） | 颏部前后突度（侧脸） | 0~+10 微前伸显立体；后缩="没下巴" |
| Jaw Angle（下颌角） | 下颌角位置与锐度 | 女性下颌角约 110°~120° 且位置高；调高调锐 |
| Cheekbones（颧骨） | 颧弓突度 | 微突 0~+15 增立体；过高显刻薄，过平显脸平 |
| Face Length（脸长） | 发际到颏点 | VRoid 默认脸偏短，写实向 +10~+20 |
| Temple（太阳穴宽） | 颞部宽度 | 与脸颊联动收窄，保持"上宽下窄"倒瓜子 |

**美学总纲**：写实向脸型=倒卵形（上圆下尖）。人类学上女性脸比男性短窄、下颌角弧度大、颏部尖细——蒂法"瓜子脸"= 脸颊收窄 + 下巴收窄收短。**操作顺序建议：先选一个偏成熟的整脸预设（Face Sets），再调轮廓滑杆，最后动五官**——预设给好基础拓扑，滑杆只做微调。

### 2.2 眼部（Eyes Sets / Irises / Eyelashes 等六类目）

眼部=二次元审美的 80%。VRoid 默认眼超大（占脸 1/3），所有"写实向"调整的第一刀都砍在这里。

| 参数 | 人体学意义 | 美学解读与建议 |
|---|---|---|
| Eye Size（眼睛大小） | 睑裂高宽 | **第一优先**：默认 -25~-35。真实人脸"五眼"=睑裂宽≈脸宽 1/5；二次元介于默认与真实之间 |
| Eye Position / Height（眼位） | 眼在面部垂直位置 | 成人解剖位=头高 1/2；二次元常下移显幼。写实向回正 |
| Eye Spacing（眼距） | 两内眦间距 | 三庭五眼：眼距≈1 眼宽。**宽眼距=天真幼态，窄眼距=成熟锐利**。诺诺可爱定位可保留微宽（+5~+10），蒂法基准为标准偏窄 |
| Eye Angle（眼轴角度） | 内外眦连线倾斜 | 外眦略高于内眦（10°~15°）=妩媚上挑；水平=清纯。蒂法微上挑 |
| Eye Depth / Socket（眼窝深度） | 眼球凹陷程度 | 写实向 +10~+20（二次元默认几乎无眼窝）；深眼窝=西式立体 |
| Eyelid（眼睑/双眼皮） | 单双睑与褶皱宽度 | 蒂法=宽双眼皮：选 double lid 预设+褶宽调大；VRoid 有单睑/双睑/吊睑预设 |
| Eyelashes（睫毛） | 睫毛密度长度卷翘 | 二次元睫毛=上睑线条加粗；写实向收细收短，避免"贴纸感" |
| Irises（虹膜/瞳色+纹理） | 虹膜直径与纹理 | 虹膜占睑裂比：真实~90%，二次元常溢出（大瞳效果）。写实向收小+选低调纹理 |
| Eye Highlights（眼高光） | 眼内反光点 | 二次元灵魂细节，位置统一（两眼光源方向一致）才不穿帮 |

### 2.3 眉毛（Eyebrows）

| 参数 | 美学解读 |
|---|---|
| Brow Shape（形状） | 柳叶眉=细长微弯；平眉=呆萌；剑眉=英气。**蒂法=柳叶眉** |
| Brow Thickness（粗细） | 写实向偏细；VRoid 默认偏粗显萌 |
| Brow Position（高低/间距） | 低眉位+近眼=成熟锐利；高眉位=惊讶幼态。蒂法眉眼距窄（英气来源） |
| Brow Angle（角度） | 眉尾微降=温柔，眉峰明显=强势 |

### 2.4 鼻子（Nose）

| 参数 | 人体学意义 | 建议 |
|---|---|---|
| Nose Height / Bridge（鼻梁高度） | 鼻骨突度（侧脸四高三低之一） | **VRoid 默认塌鼻（二次元惯例），写实向 +15~+30**。蒂法=高鼻梁。但 MyGO/GBC 风鼻梁适度即可，过高出戏 |
| Nose Length（鼻长） | 鼻根到鼻尖 | 三庭：鼻长≈脸长 1/3。默认偏短，写实向微拉 |
| Nose Width（鼻翼宽） | 鼻孔外缘间距 | 标准=内眦垂线之间（"五眼"纵向）。默认偏宽，收 -10~-20 |
| Nose Tip（鼻尖） | 鼻尖上翘/下垂 | 微翘=可爱，水平=成熟。蒂法鼻尖挺直 |

**3D 特有注意**：正脸视角二次元鼻子常简化成一个点或省略；但 3D 模型在 3/4 与侧面视角暴露真实结构——**捏鼻时以 3/4 视角验收**，不是正脸。

### 2.5 嘴与唇（Mouth / Lips / Mouth Inside）

| 参数 | 美学解读 |
|---|---|
| Mouth Size（嘴大小） | 标准=两瞳孔内侧垂线之间（正脸平视）。默认可不动 |
| Lip Thickness（唇厚） | **蒂法=薄唇**（官方百科明写）；厚唇=幼态性感。上唇略薄于下唇为自然 |
| Mouth Position（人中长度/嘴位） | 人中短=幼态。写实向鼻底-唇距微增 |
| Mouth Corner（嘴角） | 默认水平；微上扬=微笑脸常驻（慎用，会僵） |
| Lips Color（唇色） | 比肤色深一档的自然粉，避免艳色显假 |

### 2.6 脸颊 / 皮肤 / 脸绘（Cheeks / Skin / Face Paint）

- **腮红（Cheeks）**：VRoid 默认腮红很重（Q版惯例），写实向**减淡或关闭**——这是"一眼假"的最大来源之一。保留则选"脸侧阴影"型而非"圆形腮红"型。
- **肤色（Skin）**：中性偏白+脸颊微暖阴影；VRoid 肤色贴图可笔刷手绘，进阶项。
- **脸绘（Face Paint）**：泪痣、雀斑等点缀。泪痣是"氛围感"利器（右眼下 1 颗），诺诺可选。

### 2.7 表情编辑器（Expression Editor）

官方一手：从 Face 编辑器进入，按 NEUTRAL / FUN / JOY / ANGRY / SORROW 等 VRM 标准表情**逐表情**调整眉眼嘴参数，导出为 VRMBlendShapeProxy。**捏完脸后必须过一遍表情编辑器**——默认表情形状是按"大眼萌脸"设计的，脸型收窄后 smirk/angry 等表情可能穿模或怪异。

## 三、身体参数与人体比例学

### 3.1 头身比（美学第一定律）

| 头身比 | 语义 |
|---|---|
| 4 头身 | 幼儿 |
| 5.5~6 头身 | 少女漫 Q 版、VRoid 默认区间 |
| **6.5~7 头身** | **日系美少女标准区间（初音 6.5、Typical anime girl 6.5~7）** |
| 7~7.5 头身 | 成年写实女性 |
| 8 头身 | 模特/理想化 |

**诺诺定 6.5~7 头身**（VRoid 的 Head Size / Head Body Ratio 滑杆往小调头或往大调身体实现）——这是"可爱美少女"与"写实向"的平衡点。蒂法写实系约 7~7.5 头身，作参考上限。

### 3.2 身体滑杆（Body Editor · Design）

| 参数 | 人体学意义 | 诺诺建议 |
|---|---|---|
| Height（身高） | 整体身高 | 155~160cm 区间（少女感）；蒂法 167cm 为成熟向参照 |
| Head Size（头大小） | 头身比核心 | 配合身高实现 6.5~7 头身 |
| Neck（颈粗/长） | 天鹅颈=长细；短粗颈=壮 | 细颈微长，+5~+10 |
| Shoulder Width（肩宽） | 女性肩≈2 头宽；窄肩=娇小 | 偏窄 -10 |
| Chest（胸） | VRoid 有胸围大小+位置滑杆 | 诺诺=C 中杯量级（可爱向）；蒂法 92 为成熟向上限参照 |
| Waist（腰） | 腰臀比 WHR：0.7 被广泛认为最具女性美吸引力 | 蒂法 92/60/88→WHR 0.68（沙漏极端）。诺诺取 0.72~0.75（健康少女感），不过度 |
| Hip（臀） | 与腰联动构成沙漏 | 适中即可 |
| Arm / Wrist（手臂/手腕粗细） | 手腕粗细是"幼态vs成熟"敏感区 | 细 |
| Leg Length / Thickness（腿长/粗） | 腿身比：腿长（大转子至足底）≥身高一半为佳 | **腿长 +10~+15**（头身比靠腿撑），腿细但保留大腿线条 |
| Muscle / Fat（肌肉/体脂） | 全身胖瘦肌肉感 | 0 或微 -，保留少女柔感 |

**身材美学总纲**：二次元少女身材的秘密不在三围绝对值，在**比例**——头小、肩窄、腰细、腿长。VRoid 默认身体偏"微胖幼态"，要把调整量集中投给"腿长+腰细+头小"三处。

## 四、发型系统要点（官方 Hair Editor）

VRoid 发型是**笔刷画发+程序化发束**双体系，不是滑杆：

1. **预设/程序化发束**：前发/侧发/后发+extensions（发饰延伸）+ahoge（呆毛）分类；参数化调整发束数量形态。
2. **笔刷手绘**：在头模上直接刷发束；Retouch 工具（按住 R）修形；控制点调长度起伏。
3. **克隆/镜像**：右键 Clone/Flip——**双马尾=单侧马尾 Clone+Flip**，官方明确教程。
4. **摇曳骨骼（Sway Bones）**：为发束设物理摇曳（导出 VRM 后由渲染端物理接管，Web 端 three-vrm 默认读 springBone）。
5. **发色**：Texture 层笔刷上色，支持渐变（发根深发梢浅=高级感）。

蒂法基准：及腰乌黑长直发+低马尾（发尾扎起）、刘海中分微弧。诺诺建议：长发系预设起步，发色待定版轮与服装一起过目。

## 六、参数超限：官方规则与项目纪律

官方一手（Is there an upper limit to numerical parameters?）：数值参数可手动键入超出滑杆范围的值，动画照样生效；官方演示 Shortness 0→1→2→3→4：0 默认、1 滑杆极限、2 更小、3 "小仙女"、**4 模型翻转（破坏）**。官方声明超限操作不做支持保障。

**项目纪律**：诺诺捏模只在滑杆范围内调；确需超出（如极端头身比），先备份 `.vroid` 再试，验收通过才保留。

## 七、验收清单（捏完自检，院长过目前）

1. **正脸**：三庭五眼（发际-眉-鼻底-颏 ≈ 等分；眼距≈1 眼宽）
2. **3/4 侧**：鼻梁是否立体（3D 暴露区）、下颌线是否干净
3. **正侧**：四高三低（额-鼻尖-唇珠-下巴尖高；山根-人中沟-颏唇沟低）
4. **全身**：头身比 6.5~7、腿长≥身高一半、肩窄腰细
5. **表情编辑器**：NEUTRAL/FUN/JOY/ANGRY/SORROW 五表情不穿模
6. **VRM 导出试渲染**：MToon 效果下复查（VRoid 预览≠渲染端观感）

## 八、工具边界：VRoid 为什么到不了"FF7R 蒂法级"（院长问题解答）

> 结论先行：VRoid 是**参数化预设拼装**工具，蒂法（FF7R/Rebirth）是 **SE 专业 DCC 管线（ZBrush/Maya/Substance/UE4）+ 全职美术团队数月**的产物。差距不在"调得好不好"，在**工具物种不同**。但诺诺目标是 MyGO/GBC 番剧卡通渲染（NPR），VRoid+MToon 恰是对口工具链——"蒂法级"应理解为**审美结构参照**而非写实渲染目标。

**六项硬差距**（AI 3D 知识域，非本次联网调研）：

| 维度 | VRoid Studio | FF7R 蒂法 |
|---|---|---|
| 网格拓扑 | 固定基础网格+滑杆形变，**无法雕刻/重拓扑** | ZBrush 雕塑高模→手工重拓扑→法线烘焙 |
| 面数预算 | 导出 3~6.5 万三角面（VTuber 实时预算） | AAA 角色数十万面+多级 LOD |
| 材质 | MToon 卡通着色（色阶+描边+贴图手绘） | PBR+次表面散射皮肤+毛孔级法线细节 |
| 眼球 | 平面虹膜贴图 | 多层眼球（角膜折射/湿润高光/AO） |
| 头发 | 发束面片+贴图 | 发丝级 groom（XGen 类）+各向异性高光 |
| 表情 | VRM 标准 blendshape 数十个（二次元夸张化） | FACS 全套+定制修形+皱纹贴图 |

**对项目的意义**：①PoC 用 VRoid 完全成立（验证管线+占据"可爱美少女"定位）；②若未来要"蒂法级写实"或"GBC 级番剧质感"，路径是 **Blender 深加工**（AI 可脚本化操作，见黑机工作范式）或委托/混元 3D 辅助，而非在 VRoid 里死磕；③VRoid 上限≈商用 VTuber 模型水准，对 20 人朋友圈直播间产品已绰绰有余。
