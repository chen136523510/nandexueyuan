> 调研时间：2026-08-17
> 调研人：AI（白机）
> 背景：院长新点子--基于群聊记录（53 万条微信群聊）生成「抽象小剧情」剧本，参考阿牛小卖部类抽象短剧 + B 站亚文化（炫神/动物园/vtuber/电竞/MyGO）的叙事手法。本调研回答：①抽象小剧情的好笑机制是什么 ②各亚文化圈的叙事手法哪些可迁移 ③聊天记录改编成剧本怎么做、别人怎么做的 ④项目落地路径。

## 一、核心结论（先看这个）

1. **抽象感有公式**：`庄重形式 × 鸡毛蒜皮`（用圣经体/武侠体/纪录片体装外卖级内容）+ `预期违背` + `复读强化` + `黑话懂哥机制`（梗是社群身份通行证）。四路调研交叉印证，这是所有抽象作品的共同内核。
2. **素材筛选四象限**（vtuber 切片文化实证）：`事故 > 情绪峰值 > 反差 > 跨群联动`。改编不要平铺记录，专挑口误、刷屏、对线、破防时刻--「过于羞耻的内容传播力最强」。
3. **人设机制三层法**：表层身份 -> 背景执念 -> 自我解构梗，加「口头禅 + 标志物 + 追加设定带日期存档」。阿牛小卖部用「健力宝文喝武喝」这种物品即人设，20 人群天然适配（每人绑定一个游戏/零食/口头禅）。
4. **叙事结构铁律**：固定场景 + 3 秒入冲突 + 单线推进 + 金句反转收尾，体量 ≤3 分钟/300 字。MyGO 的进阶手法是「信息差结构」--A 说的话被 B 误解，比平铺冲突更高级。
5. **⚠️ 合规红线（重要）**：GitHub 9180★项目 chatlog（聊天记录导出工具）2025 年 10 月被微信官方发函下架。我们 20 人知情社区 + 数据已上线多年是护城河，但必须保留「删除我的记录」出口 + 化名开关。
6. **落地最短路径**：现有男德通管线（topicSearch/时间检索 + LLM + persona）已具备全部能力，不需要新基建。缺的只是：高能片段选题器 + 剧本体 prompt + 前端聊天界面演出层。

## 二、阿牛小卖部：素人群像抽象短剧的叙事解剖

### 2.1 基本盘

真人出演+后期配音的荒诞短剧，抖音原生、B 站发酵（B 站转载 UP「若炫棍」1.0 完结篇 221 万播放）。角色是**素人朋友群像，人设 = 真人性格极端化**--这一点与我们「群友本人出演改编剧」的场景完全同构。

### 2.2 单集叙事结构（可直接抄的骨架）

| 环节 | 做法 |
|------|------|
| 场景 | 固定场景（小卖部柜台），每期不改场地，只改冲突 |
| 开场 | 日常动作（吃零食/喝汽水），**3 秒内进入冲突** |
| 推进 | 单线荒诞冲突（赊账->报复->反转），多集串成「主线剧情」 |
| 收尾 | 金句收束或音乐催泪（「反方向的钟」刷屏 28 次） |
| 固定套路 | 赊账危机 / 村长威慑 / 零食对决 / 感情线 |

### 2.3 人设机制

- **核心角色标签化**：阿牛（老板/受气包）、胖哥（村霸/赊账王/哑巴）、愣子（吃面大师/武力值）、璐璐（感情线）、翠花（第一好看）
- **物品即人设**：健力宝（文喝/武喝）、三鲜伊面/牛羊配/周小玲合称「三巨头」
- **口头禅复用**：「这次不赊账了」（反向 flag）、「通知村长」（权力机制）

### 2.4 为什么好笑

- **审美悬置**：观众以「看傻子」的俯视快感解压（知乎一手观点）
- **反差荒诞**：日常场景 × 极端表演（舔遍手指吃辣条、摇匀汽水滋一脸）
- **音乐滥用**：同曲反复制造虚假史诗感
- **弹幕共创**：「鹿结局」「人物废稿」等剧情补全，观众参与写世界观

## 三、抽象文化（炫神/动物园）：语录体语言学与梗运作

### 3.1 背景一句话

电棍 otto（侯国玉，前 LOL 职业，猴）+ 炫神（许昊龙，狗）+ 山泥若（猪）=「动物园」；粉丝圈靠语录+二创形成有独特世界观的圈层（吉吉国）。**主播从未官方捆绑，动物园是纯粉丝命名**--自下而上的共同体命名法。

### 3.2 语录体语言学特征（给 prompt 工程的直接输入）

1. **方言根基**：抽象话源自四川话 6324（带哥/爬/gck）；电棍带东北味（这一块子/拉胯）
2. **转译即创作**：原话 -> 谐音 -> emoji -> 倒放 -> 空耳，每层转译产生新梗（「欧内的手好汉」=「大家好啊我是电棍」倒放）
3. **连环反问排比**：白银圣经「你告诉我，啊？」轰炸式复读
4. **甩锅因果链**：形式逻辑 × 荒谬内容（「开庭」式严谨取证）
5. **称号体系**：世界第一 xx、帅萌棍哥/收米棍哥造句
6. **生活琐事升格为圣经**：韭菜盒子外卖维权直播成「圣经」

### 3.3 剧本化手法

- **庄重体裁 × 鸡毛蒜皮**：《电棍笑传之踩踩背》武侠体、《十六中往事》手书、90 分钟大电影《棍的名字》
- **活字印刷**：把语录拆字重组当台词配音（社群有成熟软件，AI 语音效果反而不如它）
- **形象家族化**：一张脸投影出爹/娘/儿子/女友，设定随作品灵活变
- **又烂又好美学**：故意摆烂的跑调调音、劣质 P 图，把观众气笑

### 3.4 抽象感底层逻辑（六条，有一手语料支撑）

错位 / 预期违背 / 复读强化 / 层层转译失真 / 黑话懂哥机制（断章玩梗 = ylg 被鄙视）/ 「唐」= 医学委婉词形容正常行为的冒犯性错位。

## 四、vtuber 切片 + 电竞赛事：包装与仪式感

### 4.1 切片文化（素材筛选标准）

选题四类：**事故**（忘关麦/口误）、**情绪峰值**（急哭/破防）、**反差**（智力巅峰/唐笑）、**跨次元联动**。
标题公式：`【主播名】+ 事件概括 + 定性词`（「塔菲玩锈湖达到智力巅峰，看力竭了【塔菲切片】」）或悬念钩子（「下播忘记关麦，直播间竟传来这种声音！」）。**速度本身是价值**（激光=连夜出片）。

### 4.2 vtuber 人设三层法

表层身份（侦探+发明家）-> 背景执念（1885 年穿越）-> 自我解构梗（三围 129.3 致敬哆啦A梦）。关键机制：**追加设定随直播滚动存档（每条标注日期场次）**；梗需本人认证（嘉然：「嘉门不是我的梗，笑死才是」）；营业红线=真实感是命门。

### 4.3 电竞赛事叙事（包装手法清单）

- 解说三类：报菜名连招播报、对仗金句（「你强任你强，老子能变羊」）、立场化情绪失控（管泽元「1000块！！！」->被淘汰后「我其实还好」）
- **圣经机制**：后台争执原话存档 -> 口语+具体细节+反问句式 -> 「#背诵圣经」弹幕仪式 -> **事件反转后自动生成「新约」全篇反义版**
- 赛事包装件：对阵表带编号、组名文学（登峰组/涅槃组）、每日 TOP5（对仗文言标题）、名人堂、口号仪式

### 4.4 弹幕旁白四件套（前端演出直接抄）

开场定性 / 前方高能 / 省流摘要 / 「死因：XX」结局标注。

## 五、MyGO：信息差结构与共同体叙事

### 5.1 错位驱动（比平铺冲突高级的手法）

CRYCHIC 解散为总根源，「解散场景重演五次」。每人掌握真相的一块碎片但从不互通--第 7 话《春日影》演出是信息错位总爆发：台上四人渐入佳境 vs 祥子台下崩溃 vs 爽世全程臭脸。**改编启示：找「群友 A 说的话被群友 B 误解」的天然错位片段**。

### 5.2 名台词的传播公式

短句 + 高情绪浓度 + 明确指向对象 + 可填空模板（「为什么要演奏______!!!」）。二创可脱离原作迁移（赛马娘版/Hanser 版/GB 游戏机版）。

### 5.3 迷子主题

MyGO = 谐音「迷子」（迷路的孩子），标语「迷子でもいい、迷子でも進め」。不给答案，只给「结伴迷路」的合法性。**收尾模板：「我们虽然______，但还在______」**--给群聊赋予共同体感的万能句式。

### 6.1 案例清单

| 案例 | 形态 |

### 6.2 改编手法

素材选「高能片段」（冲突/反转/笑点密集），时间线压缩；隐私=化名+头像打码；**消息间隔大的跳跃转译为旁白**（「三天后，群里死一般的寂静」）；表情包/图片转译为动作描写。

### 6.3 AI 技术路径（GitHub 已确认项目）

- `YJH-Lab/ai-comic-drama`：LLM 剧本 -> 资产创建 -> 图生视频 -> 剪辑全自动（视频向，我们暂不需要）
- `hergaiety/blabber-comic`：chat logs 转 comics
- `ChatLab`(7188★)/`echotrace`(3761★)/`WeFlow`(13765★)：聊天记录 AI 分析/年度报告（数据接入层参照）

**⚠️ 反面教材**：`sjzar/chatlog`（9180★）2025-10 被微信官方发函下架，作者删光代码。聊天记录导出工具在国内已被定性风险。

### 6.4 剧本格式适配

标准格式：`场景头（INT/EXT 地点-时间）-> 动作描写 -> 角色名：对白`。
聊天记录适配：**群名=场景头、发言人=角色名、原消息=对白、表情包=动作描写、时间跳跃=旁白**。

## 七、对项目的建议

### 7.0 现状盘点（本地实测 2026-08-17）

- **数据**：白机 dev.db 当前为空（0 消息/0 分块），53 万条 + 5372 分块在线上服务器 prod.db。**开发前需从服务器拉库或直接在线上验证**。
- **已有底座**：男德通 topicSearch/timeSearch（高能片段定位）+ LLM 管线（glm-5.2）+ persona 体系（角色卡）+ knowledge.js 成员映射（陈梓键/丘序明/饶志锐…21 人知识库）+ SSE 流式。**剧本生成不需要任何新基建**。

### 7.1 「男德剧场」功能形态建议（三方案对比）

| | 方案 A：每周自动剧场（推荐先做） | 方案 B：点播式小剧场 | 方案 C：视频/漫画剧场 |
|---|---|---|---|
| 玩法 | 每周从上周群聊挑一个高能片段，LLM 改编成一集剧本，聊天界面演出（旁白+弹幕） | 用户选日期/话题，即时生成剧本 | 剧本->AI 配图/视频（接 Seedream/Seedance） |
| 成本 | 每周一跑一次选题+生成，约几千 token | 按需，每人每次 | 图 0.2 元/张、视频 45 元/条起 |
| 趣味性 | 「追剧感」+ 全员共同话题，最高 | 个性化强但散 | 最强但贵且慢 |
| 依赖 | 现有管线即可 | 现有管线即可 | 黑机 + 院长确认提示词（红线） |

**推荐 A 起步，B 作为入口补充，C 远期**。理由：周更制造期待感（阿牛小卖部/切片文化的「速度即价值」），全员同看一集才有弹幕共创；点播版同一 prompt 直接复用。

### 7.2 剧本体 prompt 设计要点（调研直接转译）

1. **选题器**：跑男德通检索找「高能日」（消息密度峰值日 + 冲突关键词 + 刷屏复读），四象限标注（事故/情绪/反差/联动）
2. **角色卡**：从 knowledge.js 出发，每人补「口头禅 + 标志物 + 称号」（阿牛小卖部物品即人设法）；人设固化后跨集复用，**追加设定带日期存档**（vtuber 滚动设定法）
3. **体裁轮换**：每周随机/投票选体裁--武侠体/圣经体/纪录片体/往事回忆录体/赛事解说体/MyGO 正剧体（庄重形式 × 鸡毛蒜皮）
4. **结构铁律**：≤300 字/集、固定场景开场 3 句内入冲突、结尾必带金句反转 + 「死因：XX」标注；时间跳跃用旁白（「三天后，群里死一般的寂静」）
5. **梗纪律**：只做**一层转译**（谐音/首字母/emoji 三选一），多层=假抽象；圈内梗限量使用（防 ylg 化）；保留原文金句，LLM 只补动作和旁白（活字印刷思路）
6. **演出层**：聊天界面 + 弹幕旁白四件套（开场定性/前方高能/省流/死因）+ 体裁专属 BGM 文案（不接真音频也行，写「♪ 反方向的钟 ♪」这种字幕梗）
7. **互动共创**：剧本结尾留「剧情空白」（如某角色动机未解释），群友评论区补全；事件反转后支持「出新约」（反义版）

### 7.3 合规三件套（必须做）

① 化名开关（默认化名+抽象头像，成员可切真名）② 「删除我的记录」出口（当事人可要求该集下线/重生成）③ 内容底线：不改编涉第三方隐私/敏感话题的片段（选题器加黑名单关键词）。

### 7.4 PoC 建议（⚠️ uphill，呈院长裁决后再动手）

最小 PoC = **手工跑通一集**：从线上库挑一个公认高能日（如 2026-01-01 广州游玩当灯泡）-> 手写 prompt 按上述规范生成剧本 -> 静态页展示 -> 院长过目定调（好笑阈值/梗密度/隐私尺度）-> 通过后再做选题器自动化 + 前端演出层。**不写正式代码，先出剧本样品**。
