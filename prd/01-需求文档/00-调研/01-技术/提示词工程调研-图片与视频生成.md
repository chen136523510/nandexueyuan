# 提示词工程调研：图片与视频生成（2025-2026）

> 调研时间：2026-08-09
> 调研人：AI（白机）
> 背景：项目已从英文 tag 堆叠（`1male, solo, short black hair`）转向 Seedream/MiniMax 语义模型，需系统了解新一代模型的提示词工程最佳实践
> 结论：**自然语言语义描述已全面取代 tag 堆叠，所有主流模型的文本编码器都升级为 T5-XXL / 大语言模型**

---

## 一、为什么 tag 堆叠失效了

新一代模型的文本编码器从 CLIP（只懂短词，序列长度 75-150 token）升级为 T5-XXL / 大语言模型（理解完整句子和复杂语法，序列长度 256-512+ token），训练数据也从 Danbooru 标签变成了自然语言图片描述。

| 根因 | 说明 |
|------|------|
| 文本编码器变了 | SD3/Flux/MJ v7/Seedream 都用 T5-XXL 或 LLM，训练数据是自然语言描述 |
| 质量修饰词是噪声 | `masterpiece, best quality, 8k` 在语义模型看来是无意义噪声，MJ v7 官方明确说会降低质量 |
| tag 无语法关系 | `black hair, military uniform, palace` 无法表达"谁穿、在哪里、什么姿态" |

SD3 论文（arXiv:2403.03206）消融实验证实：移除 T5-XXL 后，提示词遵循能力下降，文字生成能力影响较大。

## 二、图片生成提示词

### 2.1 通用分层结构（权重：越靠前越重要）

```
【主体】谁/什么，几个，什么姿态/表情
【空间关系】主体在画面中的位置，人物间关系
【环境场景】地点、时间、天气、氛围
【服饰外观】服装颜色/材质/款式/配饰
【光影效果】光源类型、色温、阴影特征
【风格指定】油画/水彩/写实等
```

### 2.2 各模型要点

| 模型 | 语言 | 权重控制 | 关键特性 |
|------|------|---------|---------|
| **Seedream**（项目在用） | **中文最优** | 词序 + 重复关键词 | 中文原生模型，中文语义最精确，支持十余种语言 |
| Midjourney v7 | 英文 | 词序 + `word::2` + `--no` | "像给电影摄影师描述画面"，Token 30-80 最佳 |
| Flux | 英文 | 提高 guidance_scale 8.0+ | 精准还原每个语义元素 |
| SD3 | 英文 | 词序 + T5 长序列 | 论文证实 T5-XXL 对复杂提示词至关重要 |

### 2.3 Seedream 专项（项目直接相关）

- **用中文写**——中文语义理解最强，避免翻译损失（尤其服饰细节、情感氛围）
- **指令式编辑**：`保持XX不变，将XX改为YY`
- **长度控制**：不超过 300 汉字，信息太分散模型会忽略细节
- 旧式英文 tag（`1male, solo` 等）应完全废弃

### 2.4 案例对比：描述"黑发女性穿军装站在宫殿走廊"

**旧范式 Tag 堆叠（已过时）：**
```
1girl, solo, black hair, long straight hair, military uniform, dark blue,
double-breasted, gold buttons, white shirt, ruby brooch, palace corridor,
stone pillars, marble floor, oil painting style, masterpiece, best quality, 8k
```

**新范式 自然语言（当前主流）：**
```
一位黑发长直发的女性站在宫殿走廊中央，面朝观众。
她身穿深蓝色双排扣军装，金色肩章和纽扣，内搭白衬衫，胸前佩戴红宝石胸针，
双手交叉于胸前，表情严肃自信。
背景是两侧矗立石柱的宫殿走廊，地面为大理石材质，暖色光线从侧面照入。
油画风格，奇幻插画。
```

差异：自然语言版本表达了空间关系（"站在走廊中央"）、服饰层次（"内搭/外穿/佩戴位置"）、光线方向（"侧面照入"），去掉了无用质量修饰词。

## 三、视频生成提示词

### 3.1 通用结构公式

```
[景别/镜头] of [主体 + 外观细节] [动作] in [环境/场景].
[镜头运动：推拉摇移跟升降弧].
[光影氛围].
[风格].
```

### 3.2 视频 vs 图片的本质区别

| 维度 | 图片 | 视频 |
|------|------|------|
| **运动描述** | 无 | **核心新增**——主体动作、环境运动、相机运动、节奏速度 |
| 时间线 | 无 | 需描述"先什么、后什么" |
| 镜头语言 | 仅构图 | 新增相机运动（推拉摇移跟升降弧） |
| 音频 | 无 | Veo/Kling 3.0 支持原生音频 |
| 物理一致性 | 无 | 新难点：复杂物理、方向、因果（Sora 官方承认弱点） |

### 3.3 图生视频（Image-to-Video）关键原则

> **输入图已决定构图、主体、光照、风格，提示词应几乎完全专注于运动描述。** —— Runway 官方

```
图生视频公式：The camera [运动] as the subject [动作]. [补充描述]
```

只有需要引入图中不存在的元素时，才写视觉描述。

### 3.4 各模型要点

| 模型 | 关键特性 |
|------|---------|
| **MiniMax Hailuo H3**（项目在用） | 动态运镜响应精准、微表情自然、对动漫/游戏CG画风支持好。官方建议要素：场景+色调+运镜+音乐 |
| Sora | 纯自然语言长句，30+ 官方示例全是完整句子，无一个 tag 格式 |
| Runway Gen-3/4 | 官方分"视觉描述"+"运动描述"两类，不支持负面提示词，三条铁律：正面表述/避免模糊/避免冲突 |
| Kling 3.0 | 六要素框架（主体/动作/场景/镜头/光影/风格），支持多镜头分镜 `[Shot 1]...[Shot 2]...` |
| Google Veo 3 | 最系统的要素分类（10 维度：主体/动作/场景/镜头角度/镜头运动/光学/风格/时间/音频/电影术语），支持原生音频 |

### 3.5 视频提示词要素完整清单（综合 Veo/Kling/Runway）

| 要素 | 细分 | 示例 |
|------|------|------|
| 主体 | 人物/物体/抽象 | 黑发男人、飞行器、石质穹顶 |
| 动作 | 基本/互动/情绪/微动作/转变 | 走/交谈/皱眉/微风吹发/花绽放 |
| 场景 | 地点/时间/天气/大气 | 室内/黄昏/雨天/尘埃漂浮 |
| 镜头角度 | 12 种 | 平视/低角度/高角度/鸟瞰/虫眼/倾斜/特写/极近/中景/全身/广角/过肩/主观 |
| 镜头运动 | 11 种 | 静止/平移/俯仰/推拉/横移/升降/变焦/摇臂/航拍/手持/弧形 |
| 光学效果 | — | 广角/长焦/浅景深/镜头光晕/跟焦/鱼眼/眩晕效果 |
| 风格 | 照明/情绪/艺术/氛围 | 伦勃朗光/悬疑/梵高/雾中魔法粒子 |
| 时间 | 节奏/演变/韵律 | 慢动作/延时/蜡烛燃尽/闪烁 |
| 音频 | 音效/环境/对话 | 脚步声/雨声/"他说：……" |

## 四、对项目的具体建议

### 4.1 图片生成（Seedream）

当前 image-gen SKILL 里的提示词写法**已基本符合新趋势**（中文自然语言），但有几处可优化：

1. **负面提示词**：项目现在用中文 tag 式负面词（`画面模糊、低分辨率`）。新趋势建议改为自然语言排除，但 Seedream API 仍支持 negative_prompt 字段，保留无妨
2. **去掉质量修饰词**：如果有 `masterpiece, best quality` 类词应删除（当前 SKILL 提示词模板中已无此类词，符合规范）
3. **服饰一致性描述放靠前**：词序即权重，重要的约束放前面
4. **负面词用自然语言**：当前负面词是 tag 式（`多人、路人`），可优化为自然语句（`画面中只有一个人，没有其他人物`）

### 4.2 视频生成（MiniMax H3）

国会事变 CG 视频的提示词应该按这个结构写：

```
[景别] 丘站在国会大厦废墟上，身穿皮甲和林绿色斗篷，手持长弓。
[动作] 他搭箭拉弓，瞄准天空中的飞行器，箭羽在风中微微颤动。
[环境] 背景是半塌的穹顶石质建筑，碎石和烟尘弥漫。
[运镜] 镜头从丘的背后缓慢推进，然后弧形转到侧面特写他的表情。
[光影] 黄昏的逆光，暖橙色光线穿透烟尘。
[风格] 西方奇幻电影感，厚重油画质感。
```

而不是：`1male, bow, arrow, ruins, sunset, cinematic, 4k`

**图生视频模式下**（用 `qiu/rogue.webp` 做参考图）：提示词专注于运动描述——相机怎么动、人物怎么动、光影怎么变化，不重复描述图里已有的服饰/外貌。

### 4.3 长度控制

| 类型 | 建议长度 | 原因 |
|------|---------|------|
| Seedream 图片 | ≤ 300 汉字 | 超长信息分散，模型忽略细节 |
| Hailuo 视频 | ≤ 300 汉字 | 同上 |
| Midjourney | 30-80 token（约 60-150 词） | 超过 150 token 收益递减 |
