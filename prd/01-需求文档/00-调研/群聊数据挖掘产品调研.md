## 二、可挖掘议题提案（六类 12 项）

> 标注说明：数据来源 = 纯 SQL（零 AI 失真，可信度最高）/ 男德通 Agent（AI 参与总结，需人工审稿）

### A 类：群史编年（脉络发展叙事）

**A1《群聊编年史》** ⭐旗舰选题
- 内容：按季度还原四年主题变迁——2022 疫情+家长群时代 → 2023（待考）→ 2024（待考）→ 2025 中考回忆+辩论元年 → 2026 考研决战+世界杯+求职季
- 为什么有意思：这是 21 个人从高中到大学毕业/工作的完整青春编年史，时间线滚动叙事天然有「原来那年我们在聊这个」的回忆杀效果
- 数据来源：time_search 按季度聚合 + LLM 归纳主题 + **人工审稿**
- 男德通跑法：`timeSearchAgent` 逐季度取块摘要 → `fullAnalysisAgent` 分年总结 → 人工定稿

**A2《史上最热闹的一天》TOP10 考古**
- 内容：每个峰值日做事件还原卡（本文 §1.3 已验证 5 个），配当天金句截图式引用
- 为什么有意思：峰值日全是事件日（瓜/决赛/出分/辩论），一天一故事，卡片式浏览零门槛
- 数据来源：SQL 峰值日排行 + `topicSearchAgent` 还原当日事件 + `sampleChunkMessages` 抽当日金句
- 男德通跑法：批量脚本对 TOP10 日期各跑一次日级检索，产出 JSON

### B 类：人物志（个人趋势与总结）

**B3《群友图鉴》人物卡** ⭐社交货币选题
- 内容：每人一卡——发言量段位/深夜党指数/高频话题域/口头禅/活跃时段热力图/代表话题块（如丘序明"挑战全网最快卸载"、饶志锐"辩论永动机"）
- 为什么有意思：网易云人格测试的群聊版，群友会主动对号入座 + 转发自己的卡，自带传播性
- 数据来源：`personStatAgent`（SQL 精确）+ 话题块人物字段聚合 + 口头禅词频（SQL）+ 深夜指数（SQL）
- 男德通跑法：21 人 × person_stat + 自定义 SQL 聚合脚本；人设描述 LLM 起草**院长逐人审稿**（20 人圈子，人设冒犯风险高）

**B4《夜猫子/早鸟排行榜》**
- 内容：深夜党指数排行 + 时段热力图（谁 0-5 点最活跃、谁 7 点准时上线）
- 为什么有意思：实测已出反直觉结果（张迅 46.7% 深夜占比），排序类内容消费成本最低
- 数据来源：纯 SQL，零 AI 失真
- 男德通跑法：一条 SQL 即可，男德通只做文案包装

### C 类：事件纵深（某件事的趋势曲线）

**C5《考研 Chronicle》** ⭐最有故事性的长线
- 内容：从 2025 择校讨论 → 2026-02 出分 → 03 国家线/复试/调剂 → 上岸/二战抉择的完整时间线，附「准研究生」昵称的诞生考据、情绪曲线（焦虑→崩溃→释然）
- 为什么有意思：这是群里最长最完整的故事线（跨 2 年），且有多人深度参与，有起承转合
- 数据来源：`topicSearchAgent`（考研/复试/调剂/二战多关键词）+ `timeSearchAgent`（2025-09~2026-04 逐月）+ `fullAnalysisAgent` 全量情绪归纳
- 男德通跑法：多关键词批量检索 + 时间聚合，人工串联叙事定稿

**C6《游戏兴衰史》**
- 内容：三角洲/博德3/LOL/金铲铲/死亡搁浅等各游戏按月热度曲线 + 「卸载三角洲」梗的完整生命周期（首卸→梗化→集体行为艺术）
- 为什么有意思：卸载梗是群内最有生命力的自创梗（黑机 8-16 调研时实测"谁卸载三角洲次数最多"有完整排行），热度曲线可视化直观
- 数据来源：SQL 按月 COUNT 游戏关键词 + `topicSearchAgent` 补事件
- 男德通跑法：关键词月度聚合脚本 + AI 写各游戏小传

**C7《国际局势观察室》**
- 内容：群友对大事件的反应史——巴以/股市/世界杯/AI 裁员，每次热点群友的观点光谱
- 为什么有意思：2026-03-23 单日 2,262 条的历史纪录就是巴以+股市贡献的，这个群对世界的关心程度超出想象
- 数据来源：`topicSearchAgent` 逐事件检索
- ⚠️ 风险：政治议题敏感度高，展示需措辞降级，建议只做「事件+热度+情绪」不做观点复原

### D 类：群文化考古

**D8《复读机殿堂》**
- 内容：金句总榜（§1.5 已有）+ 金句发明人考据（谁第一个说"哎哟我"）+ 复读机之王（同一短语重复发送次数最多的人）
- 为什么有意思：零理解成本、纯快乐，「哎哟我 3,148 次」这种数字本身就是梗
- 数据来源：SQL（重复短语聚合 + 首次出现时间 + 发送人分布）
- 男德通跑法：纯 SQL 脚本，AI 零参与，准确度 100%

**D9《梗百科》**
- 内容：群内自创梗词条化——每条含：出处日期/首创人/巅峰期/例句/现状（活跃/化石）
- 为什么有意思：新人（未来的新群友）看一遍梗百科就能融入，老人复习自己的文化遗产
- 数据来源：`topicSearchAgent` 逐梗溯源 + 人工考据定稿（梗的出处 AI 溯源不可靠，需老人回忆审校）
- 男德通跑法：候选梗清单（人工提名 20-30 个）→ AI 逐个检索最早出现 → 人工校对

### E 类：关系互动

**E10《互动网络图》**
- 内容：谁和谁对话最多（相邻发言/互相点名分析），21 人的关系网力导向图
- 为什么有意思：发现隐藏的「对话搭子」和意外的不熟组合，社交网络图视觉冲击力强
- 数据来源：SQL 相邻发言共现分析 + @ 解析（需新写小管线）
- 男德通跑法：批量共现计算脚本 + ECharts 力导向图
- ⚠️ 风险：CP 化解读需要分寸（恋爱话题群友真实隐私）

**E11《世纪对线名场面》**
- 内容：历史大辩论还原——共产主义辩论日/学历歧视日/巴以日，正反方阵容 + 核心论点 + 裁判（围观群众）反应
- 为什么有意思：辩论是这个群的核心娱乐方式（2025-03-10 全天辩论马拉松），名场面集锦=群友的高光时刻回放
- 数据来源：峰值日 + `topicSearchAgent`，人工撰写战报
- ⚠️ 风险最高：观点复原容易引战，建议做成「欢乐向战报」而非立场评判

### F 类：反直觉洞察榜（数据新闻向）

**F12《数据粉碎的 N 个错觉》**
- 内容：反直觉结论合集——「群快死了？（实际活跃度五年翻 3 倍）」「最话痨的人是谁？（11.4 万条=每人每天 76 条）」「这是个夜行群落（近半消息深夜发）」
- 为什么有意思：数据新闻体裁，每条都是"万万没想到"，适合做静态页的首页 hook
- 数据来源：纯 SQL + 男德通问答实录
- 男德通跑法：全部 SQL 可算，AI 零参与

## 四、生产管线设计（男德通怎么跑数据）

核心思路：**选题驱动批量脚本 + 人工策展双阶段**，不做实时查询。

```
选题定义（人工，本文 §二）
  ↓
批量执行脚本（本地跑，复用男德通 Agent）
  ├─ 纯 SQL 类（B4/D8/F12）→ 直接出精确数字
  ├─ 检索类（A2/C5/C6）→ topicSearch/timeSearch 批量跑出素材
  └─ 归纳类（A1/B3/D9）→ fullAnalysisAgent 产出叙事初稿
  ↓
人工审稿定稿（院长终审，AI 失真拦截闸）
  ↓
静态 JSON 落 public/museum/（版本化，数据代际与 R-052 对齐）
  ↓
前端渲染（纯静态，零 LLM 零查询运行时成本）
```

关键原则：
1. **准确度优先**：能 SQL 算的绝不 LLM（榜单类全 SQL）；LLM 产出必须人工审稿后才入静态页（静态=定稿，错字错数永久钉死）
2. **复用现成能力**：topicSearchAgent（R-053 后精度已升级）/timeSearchAgent/fullAnalysisAgent/personStatAgent 全部现成，本轮调研的 12 个选题无一个需要新 Agent
3. **数据代际**：静态 JSON 携带数据截止日期（当前 2026-08-10），群库更新后重跑刷新，与 R-052 缓存代际设计同思路

## 五、内容红线（20 人圈子特有约束）

静态展示与男德通私聊问答不同——**广播性质**，红线更严：

1. **群外真人不出现**：家长群风波涉及颜姐/dyy/李杨爸妈等群外人物，事件可讲（是群史），人名全脱敏（用「某家长A/B」）
2. **隐私类不出静态页**：恋爱咨询（2026-07-19 汪煜坤事件）/健康话题（心脏刺痛等）只可模糊化统计趋势，不做个人还原
3. **政治议题降级**：C7 只做热度与情绪统计，不复原具体立场言论
4. **人物卡人设**：院长逐人终审，冒犯性绰号（如有）不入正式卡
5. **可全量展示**：游戏/复读金句/深夜榜/活跃度趋势/辩论名场面（欢乐向）——这群内容占了金山的大头，足够撑起产品
