## 归档规则（新调研落档必读）

1. **先判类再落档**：新调研文档按上表四类放入对应子目录，不再直接放本目录根。跨类时选主要归属，其余在文档"关联文档"行交叉引用。
2. **文件名**：中文语义化，以「主题+调研」命名（如 `xxx调研.md`）；API 官方文档快照类 PDF 与其所属调研放同一子目录。
3. **判定口诀**：讲"怎么做"（方案/工程）→ 01-技术；讲"用什么"（选型/API/工具）→ 02-工具与AI服务；讲"做什么"（产品/玩法/叙事）→ 03-产品与游戏设计；讲"长什么样"（视觉/动作/镜头）→ 04-美术。
4. **引用纪律**：引用调研文档一律带完整相对路径（从引用方位置算起），禁止裸文件名互引——2026-09-20 归类移动时裸名引用全部修正过一次，别再制造。
5. 调研流程规范见技能 `.zcode/skills/research/SKILL.md`（纪律五已同步本归类规则）。
