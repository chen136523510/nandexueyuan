## 一、标准分镜脚本（Shot List）格式

分镜是导演与摄影指导沟通的「战略文档」。一次完整生成（generation）对应一个 shot。

### 核心字段（必备）

| 字段 | 含义 | 示例 |
|------|------|------|
| Scene Number | 场景编号 | 整场对战为 Scene 1 |
| Shot Number | 镜头编号 | S1-S8 |
| Description | 画面描述 | 丘拉弓瞄准/睿蓄力施法 |
| Shot Size（景别） | 主体在画面中的大小 | 远景/中景/特写 |
| Shot Type（机位角度） | 摄影机与主体的关系 | 平视/低角度/高角度/过肩 |
| Camera Movement（运镜） | 镜头运动方式 | 推/拉/追踪/环绕/手持 |

### 进阶字段（AI 视频场景重要）

- **Frame Rate（帧率）**：常速 / 慢动作 / 快动作——动作场景的灵魂
- **VFX**：特效需求（魔法光效、箭矢轨迹）
- **Subject（主体）**：谁在镜头里——对 AI 角色一致性关键
- **Lens（镜头焦段）**：广角强调运动，长焦压缩空间卖出打击感
- **Lighting（光照）**：光线方向、色温——AI 跨镜头一致性的核心变量

### 关键原则

> **一次生成 = 一个机位 + 一个动作 + 一个地点。** 复杂场景必须拆成多个独立镜头再拼接。

## 二、动作场景的分镜设计

### 2.1 权力动态（Power Dynamic）——动作场景的核心叙事

动作场景本质是双方力量的「拔河」（tug of war），用机位高度暗示权力：
- **低机位 = 弱势方**（被压制视角）
- **机位升高 = 获得力量**（反击视角）

典型权力翻转链：A 占优 → B 蓄力反击 → A 闪避 → B 爆发。这个翻转链就是分镜骨架。

### 2.2 远程 vs 近战的镜头语言差异

**远程攻击者（弓兵/枪手）适用技巧：**
- **长焦特写慢动作**建立角色 stakes：孤立关键人物让观众知道「该跟谁」
- **空间建立更重要**：用广角高/低角度对切创造运动感，即使角色相对静止
- **武器 insert shot（插入特写）**：在动作高潮处紧框武器，用横向运动「卖出」下一镜的打击

**施法者（魔法师）适用技巧：**
- **慢动作 = 仪式感与蓄力感**：角色「跨入战斗的门槛」时用慢动作，赋予进入战场的仪式性
- **变速剪辑（speed ramping）**：常速 → 慢动作 → 常速快速交替，产生动态冲击
- **施法蓄力 = 慢动作；法术释放 = 切回常速爆发**

### 2.3 打击感（Selling the Hit）的镜头技法

| 技法 | 作用 |
|------|------|
| 广角建立空间关系 | 中全景 + 广角交代双方位置与环境 |
| 长焦压缩空间卖出打击 | 过肩 + 长焦让武器即使没碰到也显得贴脸 |
| 侧面双人镜头 + 朝镜头方向挥击 | 广角强化横向速度 |
| insert shot + cut on action | 前一镜展示武器运动方向，下一镜长焦转角度，观众脑补打击完成 |

> 对 AI 场景的启示：AI 无法精确控制「差一厘米」，但可以用景别切换 + 运镜方向暗示力量传递，用 insert shot（箭矢/法球特写）作为转场锚点。

### 2.4 攻防节奏：Fast-cut vs Slow-motion 的时机

| 时机 | 技术 | 原因 |
|------|------|------|
| 开场建立对峙 | 慢动作长焦特写 | 孤立角色、建立 stakes、仪式感 |
| 空间/位置交代 | 广角常规速度 | 让观众理解「谁在哪」 |
| 蓄力/施法/瞄准 | 慢动作 | 放大张力、展示关键细节 |
| 打击瞬间 | 快切或变速 | 冲击力、混乱感 |
| 权力转换 | 留白镜头（稍长 1-2 秒） | 让观众「重新归位」 |
| 高潮爆发 | 快切密集 + 慢动作穿插 | 能量峰值 |
| 收束 | 回到稳定/静止 | 情绪落地 |

## 三、运镜技术在动作场景中的应用

### 3.1 追踪镜头（Tracking Shot）

- 摄影机移动跟随主体，**动作场景最常用**
- 作用：把观众「扔进动作中央」，创造沉浸感与高能量
- 适用：追踪角色横向移动闪避

### 3.2 环绕镜头（Arc Shot / 360 Shot）

- 摄影机绕固定主体轨道运动
- 核心用途：为对峙/重要时刻注入风格化视觉能量
- 速度决定能量：慢弧 = 压抑/顿悟；快弧 = 兴奋/眩晕
- 适用：对峙场景双人对视时用半弧强化「即将爆发」的张力

### 3.3 摇移甩镜（Whip Pan）

- 快速水平摇移产生模糊
- 用于角色被击飞后的急速转向，创造紧迫感
- **AI 场景特殊用途**：可作为两个动作镜头间的天然转场（whip pan blur 掩盖拼接接缝）

### 3.4 滑动变焦（Dolly Zoom / Vertigo Shot）

- 推拉 + 反向变焦产生空间扭曲眩晕感
- 用于角色接收改变命运的信息、或强烈心理冲击的瞬间
- 适用：终极蓄力完成、或意识到无法躲避时的压迫感

### 3.5 运镜使用原则

> 复杂运镜耗时，**克制使用**。30 秒视频建议选 2-3 种运镜反复出现形成视觉签名，而非每镜都换。

## 四、30 秒短视频的叙事节奏

### 4.1 三幕结构压缩

| 阶段 | 时间（30 秒版） | 内容 |
|------|----------------|------|
| **钩子 / Hook** | 0-3 秒 | 立即呈现视觉异常或对峙，不讲背景 |
| **升级 / Escalation** | 3-22 秒 | 冲突展开，力量此消彼长 |
| **高潮 / Climax** | 22-27 秒 | 能量峰值，最激烈的一击 |
| **收束 / Resolution** | 27-30 秒 | 情绪落地，角色已改变 |

### 4.2 关键节奏原则

- **前 3 秒定生死**：移动/破碎/变形的视觉异常，第一帧就要有张力
- **每个 beat 多功能**：短视频没有纯铺垫时间，每个节拍同时推进动作 + 情绪 + 信息
- **慢动作用于强调，快切用于冲击**：变速是节奏调控的核心工具
- **闭环潜力（Loop Potential）**：最好的结尾能接回开头——循环播放时结尾画面回到开场，观感更完整
- **静音友好**：关键信息用视觉承载，不依赖声音（AI 视频音效常缺失）

### 4.3 节奏密度参考

- 专业动作片：42 秒 31 镜 ≈ 1.35 秒/镜
- 30 秒 AI 视频建议：6-8 镜，平均 3-5 秒/镜，关键快切处可到 1-2 秒

## 五、AI 视频生成的分镜实践

### 5.1 各模型能力对比（2026 现状）

| 模型 | 多镜头能力 | 一致性方案 | 动作/运动 |
|------|-----------|-----------|----------|
| **Kling 3.0** | 原生 Multi-Shot，自动最多 6 镜，Custom 逐镜控制 | 角色锁定 + 环境锚定 + 全局风格 | 动作序列、高速运动最佳 |
| **Runway Gen-4** | 单镜为主，reference conditioning | 单图参考跨场景 | 精细相机控制 |
| **MiniMax Hailuo** | 风格一致性 | 风格一致 | 生成快，风格化好；面部一致性较弱 |
| **Veo 3** | 多提示词故事板 | 环境一致性强 | 与 Gemini 集成 |

### 5.2 单镜头 vs 多镜头：可行性结论

- **Kling 3.0 Multi-Shot**：原生支持一次生成内多镜头（最长 15 秒，最多 6 镜）
- **MiniMax H3**：单次最长 15 秒，**30 秒 = 2 段 × 15 秒拼接**
- **专业工作流**：8-12 个独立单镜生成 + 手动剪辑（控制力最强但耗时）

### 5.3 角色一致性的提示词策略

**弱提示词**（导致漂移）：
```
一个穿红裙的年轻女人
```

**强提示词**：
```
28岁东亚女性，齐肩黑色直发左分，心形脸，颧骨分明，淡妆自然唇色，
穿合身酒红色中长袖圆领连衣裙，身材纤细约168cm，戴小金耳环和细金链项链
```

> 每镜提示词必须重复：光线方向、色温、焦段、景深——这些是跨镜一致性的核心变量，比面部描述更容易出错。

### 5.4 提示词结构模板（多镜头）

Kling Custom Multi-Shot 推荐的逐镜头结构：

```
全局前置定义（保证一致性）：
GLOBAL STYLE: [整体风格/色彩/镜头质感/帧率]
CHARACTER A: [极详细外貌描述]
CHARACTER B: [极详细外貌描述]
ENVIRONMENT: [战场环境详细描述]
LIGHTING: [光源方向/色温/光质]

逐镜头：
SHOT 1:
- Duration: 时长
- Framing: 景别 + 机位角度 + 视点
- Content: 角色动作、剧情推进
- Camera Movement: push-in / pan / orbit / handheld / tracking

SHOT 2: ...
```

### 5.5 复杂动作序列的拆分与拼接工作流

1. **概念 → 故事板 → 提示词**（人类工作）：先定义每个镜头的主体、场景、机位、运动、情绪
2. **先做角色定版**：用 image-to-video（首帧控制主体外观/风格/构图），批准后再进入多镜生成
3. **按权力动态分镜**：每个镜头承载一个明确的视觉/叙事 beat，不重复信息
4. **用 element reference 锁定关键元素**：角色、武器、道具，跨镜保持可识别
5. **多次生成 → 剪辑拼接**：60 秒视频典型流程 = 脚本故事板 → 8-12 个 AI 片段 → 剪辑整合
6. **用运镜做转场缝合**：whip pan 的模糊天然掩盖镜头接缝；tracking shot 的运动延续性让拼接更顺滑

## 六、MiniMax H3 的具体约束（项目在用）

| 约束 | 说明 |
|------|------|
| 单次时长 | 4-15 秒，30 秒需 2 段拼接 |
| 首帧 | 只支持 1 张 `first_frame` 图片 |
| 角色一致性 | 面部一致性较弱，需靠提示词反复描述硬特征 |
| 分辨率 | 768P / 2K |
| 宽高比 | 图生视频恒为 adaptive（由输入图片决定） |
| 提示词语言 | 中文自然语言（同 Seedream） |
| 提示词上限 | 7000 字符 |

> 详见 [MiniMax视频生成API使用指南](./MiniMax视频生成API使用指南.md)
