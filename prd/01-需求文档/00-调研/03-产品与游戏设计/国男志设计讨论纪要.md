## 一、游戏定位（一句话）

**仿三国志 12 的实时策略经营游戏 × 文明 6 的区域/科技内政 × 红警式"内政建筑即战场实体"联动；架空东亚世界观，男德学院 21 名群友分属四大阵营（中/日/朝韩/澳）逐鹿 21 城以内的微缩地图。**

- 技术形态：Web 单机（Vue 3 + TS + Canvas），JSON 数据驱动，纯 TS 引擎与 UI 分离
- 节奏目标：单局 3~6 小时，朋友圈内部娱乐，零订阅成本（AGENTS 成本纪律）

### 2.2 第二轮（2026-10-22 院长七点原话整理）

**① 南扩**：地图南部延伸到澳大利亚，加入 **悉尼、墨尔本** 两城。

**② 四阵营 + 忠诚度 + 驻守规则**：
- 默认四大阵营：**中国、日本、朝韩（架空时间线中二者已统一为一国）、澳大利亚**
- 中国阵营 6 城（院长特供，原话"毕竟是我做的游戏，嘻嘻"）：**北京、上海、深圳、西安、香港、台北**
- **每个城市都有忠诚度**
- **每城必须有人驻守；无人的城市视为"废弃"状态，产出与忠诚度大减**
- 城市总数 ≤ 21，确保每城都能有人

**③ 架空世界观与事件系统**（架空以免争议）：
- 主动行为面（玩家行动三轴）：**内政、外交、军事**
- 被动事件：
  - **忠诚度过低 → 叛乱**
  - **随机天灾**：北京沙尘暴、日本海啸、环境污染等
  - **异族入侵**：西安方向陆上异族、沿海城市海盗；机制参考《三国志 12 威力加强版》异族势力

**④ 角色**：**暂定男德学院 21 名群友作为全部主力，不加 NPC**；21 人的阵营归属后续讨论。

**⑤ 内政城市规划（参考文明 6 区域）**，六类区域：

| 区域 | 产出/作用 |
|---|---|
| 学院 | 科技值 |
| 商业中心 | 财政（金） |
| 军事基地 | 军力（兵力/城防相关） |
| 矿山 | 生产力（建造速度） |
| 娱乐中心 | 每城各有特色（忠诚度相关） |
| 农田 | 粮食 |

**⑥ 科技线（参考文明 6）**：一条科技树，科技值驱动，各节点有明确效果。

**⑦ 内政-战斗联动（解决三国志 12 内外割裂，参考红警）**：
- 内政期建造的城墙、军事基地等设施，在战斗地图（二期）中**实体存在并发挥作用**
- 不再是内政归内政、战斗归战斗的两套皮

### 2.3 第三轮（2026-10-22 院长六点）

1. **太守出征**：21 将平时任太守驻守，也可率军出征；**出征期间后方为"空虚"态**。
2. **军事体系优化列入讨论**：院长提出两难——即时战斗如"开一局中盘红警"，加料恐主次不明（经营是主菜），不加料则与原版无差、无新意。白机提案见 §7.4（路径 C，待裁决）。
3. **科技树改以近代/现代为起点**：不做文明 6 式远古→现代长跑；开局即近代或现代，未来方向 = **人工智能、天网、星链、无人驾驶**（科技线重设见 §5.3）。
4. **内容红线放宽**：游戏不商业化、仅供学院内部群体消遣，当代元素允许使用（院长原话："有一些当代元素也会有点意思"）；世界观维持架空时间线。唯一保留底线 = 群友真人玩梗需本人过目（真人权益，非内容审查）。
5. **生产力来源泛化为工业区**："矿山"仅借代，可命名为算力中心 / 发电中心 / 核电站等等效工业区形态。
6. **预留修改器**：引擎预留数值/状态修改接口，开发期调试用 + 上线后作为玩家金手指（设计要求见 §5.4）。

### 2.4 第四轮（2026-10-22 院长六点，路径 C 拍板 + 交互定案）

1. **保留轻量 RTS**：战术不做牌组化，仍是 RTS 操控；**新意收敛为"带队角色有不同技能可发动"**（即每个领兵武将的招牌战法/技能）。
2. **伪回合制（决策自动时停）**：单机形态下，玩家做决策时游戏自动暂停（pause-and-command，全面战争/博德之门式主动暂停），免去即时微操压力。
3. **交互细则（院长原话设计）**：
   - **右键部队 → 自动暂停 → 弹出指令选项（如攻击）→ 指定目标 → 暂停解除**，给玩家"军队令行禁止"的指挥感；
   - **移动为实时遥控**：选中部队后持续点击地图地板下达行军点；
   - **提供暂停按钮**：暂停后可一次性部署所有部队的行进路线（多 waypoint 规划），点"继续"后统一执行。
4. **自动档**：可设置自动档；**一期全部是自动档**（数值结算+战报），二期在同一判定模型上加手动档（见 §7.4 拍板版）。
5. **路径 C 可行，正式拍板**。
6. **服务器承载评估**：已实测生产 ECS，结论见 §11——支持，前提是浏览器权威架构。

### 4.2 驻守/废弃规则的设计价值（白机分析）

"无人城 = 废弃，产出忠诚大减"是极好的**滚雪球迷你解药**：
- 三国志 12 攻城胜利即收编城内全部兵力，占地越快越强；
- 国男志占新城后若无将可派 → 城废弃、产出低、忠诚低、易叛乱，扩张速度受 21 将总数硬约束；
- 武将的调动（守哪个城、谁出征、谁当机动援军）天然成为核心策略层。

### 4.3 待澄清的设计张力（需院长后续裁决）

1. **太守出征规则（2026-10-22 院长拍板）**：太守本人率军出征 → 城市立即转**"空虚"态**（无主将驻守）；空虚期产出/忠诚惩罚按梯度生效（具体数值待设计），城完全无将且持续空虚 N 月 → 转"废弃"。远征军不能久拖，后院起火是硬约束。
2. **阵营归属**：21 人分到中日朝韩澳四阵营，院长玩中国阵营的话，中国阵营放几人？被分到日/澳阵营的群友由算法 AI 扮演——本人是否愿意"当日本人/澳大利亚人"需授权时一并确认（玩梗向）。
3. **武将属性体系**：沿用调研报告 §9.4 建议（四维 + 2~4 特技 + 1 招牌战法 + 1 句台词，总点数预算 260~320）；群友梗与数值分离（名字随便玩梗，效果统一模板）。

## 五、内政：六区域 + 城墙 + 科技线

### 5.1 资源轴（六条）

| 资源 | 来源 | 用途 |
|---|---|---|
| 金 | 商业中心 | 募兵/外交/俸禄/升级 |
| 粮 | 农田 | 养兵/出征消耗（断粮→士气崩） |
| 军力（兵力） | 军事基地 | 部队规模/守军 |
| 生产力 | 工业区（矿山/算力中心/发电中心/核电站等效形态） | 区域/城墙/单位的建造速度（文明 6 锤子） |
| 科技值 | 学院 | 推进科技线 |
| 忠诚度 | 娱乐中心/太守/事件 | 过低叛乱；废弃城大减 |

另保留：**城防值（城墙，默认上限参照三国志 12 的 800 百分比制）**。

### 5.2 城市槽位（待裁决）

- 【建议】文明 6 精髓是"取舍"：每城区域槽位有限（如 4~5 个槽 + 城墙固定位），六类区域不能全建满，逼玩家给城市定位（科技城/经济城/军事城），与城型（农业/商业/大都市/前线）乘法叠加。
- 备选：不做格子地块（文明 6 相邻加成首版可砍），区域只占"城内槽位"，降低地图编辑成本。
- "娱乐中心每城各有特色"的落地：每城娱乐中心带一个城籍专属效果/事件（北京沙尘暴抗性？东京海啸预警？——与天灾系统呼应）。

### 5.3 科技线（近现代起点，院长 2026-10-22 定）

不做文明 6 式"远古→现代"长跑；**开局即近代/现代军备水平**，科技树往**人工智能、天网、星链、无人驾驶**等近未来方向延伸。单条主干 10~12 节点【白机草案，待增删】：

| # | 节点 | 效果（内政/战斗联动） |
|---|---|---|
| 1 | 现代后勤学 | 农田/工业区 II；出征粮耗降低 |
| 2 | 混凝土永备工事 | 城墙 II；战场可建永备碉堡（二期实体） |
| 3 | 民兵动员体制 | 军事基地 II；兵力上限/募兵速度提升 |
| 4 | 卫星侦察（早期） | 可见邻接敌城兵力（战争迷雾揭开一层）；军师情报更准 |
| 5 | 网络战 | 可对敌方实施电子干扰（延迟其出兵/降低城防恢复） |
| 6 | 精确制导 | 攻城效率提升；远程单位伤害系数 |
| 7 | 无人机蜂群 | 解锁无人机单位（侦察+骚扰，采配消耗低） |
| 8 | 星链组网 | 全图视野加成；远程协同；秘策/战术牌冷却缩短 |
| 9 | 无人作战平台 | 无人装甲/无人舰艇（高战力低人力消耗，但受网络战克制） |
| 10 | AI 辅助决策 | 军师建议质量跃升；算法 AI 反应加快；战术牌+1 槽 |
| 11 | 全域指挥自动化 | 本阵指挥范围扩大；多部队协同战法 |
| 12 | **天网（终局节点）** | 全自动军力，数值碾压级；**风险事件：天网失控——可能对所有阵营反戈，全球性危机** |

- 天网梗可与"军师 LLM"形成元叙事（AI 给自己造了个 AI 上司然后它造反）。
- 后续可分叉为信息战 / 无人装备 / AI 三条支线，首版保持单线。
- 工业区形态（算力中心/发电中心/核电站）可与节点呼应：核电站=生产力高但天灾时可能核污染（环境污染事件变体）。

### 5.4 修改器（院长 2026-10-22 定，一期架构必须预留）

**定位**：开发期调试工具 + 上线后玩家金手指（彩蛋向，内部娱乐）。

架构纪律：
- 引擎从第一天采用**指令总线（command bus）模式**：所有状态变更必须经过统一入口（加资源/改忠诚/改城归属/跳时间/解锁科技/瞬建），UI、AI、修改器都走同一通道——修改器天然可做，且不污染引擎逻辑。
- 严禁修改器直改状态对象（否则存档一致性无法保证）。
- 一期功能清单（建议）：
  - 资源：金/粮/兵力/生产力/科技值自由增减
  - 城市：忠诚度、城防、归属阵营、废弃/空虚状态切换
  - 武将：四维点数、特技/战法解锁、位置（驻守城）、阵营
  - 科技：一键解锁全部/指定节点
  - 时间：快进/暂停/跳到指定月；事件强制触发（测试天灾/叛乱/异族用）
  - 设施：区域瞬建、城墙满级
  - 外交：关系值任意设定
- 呈现：隐藏入口（如标题界面连点 logo 或 `Ctrl+Shift+D`），开控制台面板；上线后作为"院长控制台"金手指保留，单机游戏不影响他人，可附成就标记（"开了修改器就没有统一成就"之类的小趣味，可选）。
- 二期扩展：战时无敌/采配无限/一击破城。

## 六、事件系统

### 6.1 主动行为面（玩家三轴）
内政（区域建造/科技/调将）、外交（同盟/停战/共同军/劝降/破弃，一期规则+模板）、军事（募兵/出征/驻守）。

### 6.2 被动事件

| 类型 | 触发 | 效果方向 | 备注 |
|---|---|---|---|
| 叛乱 | 城市忠诚低于阈值（废弃城加速） | 城倒戈/出叛军/内政停摆 | 娱乐中心、太守魅力、驻军压制 |
| 天灾 | 随机，城籍限定 | 北京沙尘暴（生产力/粮减）、日本海啸（沿海城防/兵力损）、环境污染（忠诚/人口减） | 环保类科技提供抗性 |
| 异族入侵 | 周期性/随机 | 西安方向陆路异族南下；沿海海盗袭扰劫掠 | 参考 PK 异族：有据点、可讨伐可怀柔 |

### 6.3 内容尺度（2026-10-22 院长裁决：放宽）

院长原话："内容红线其实没必要那么严格，因为这个游戏不商业化，只是供内部群体消遣。有一些当代元素也会有点意思。"

- **不按商业产品标准管控内容**：当代元素（现实国家/宗教/民族相关玩梗、现实事件化用如沙尘暴/海啸/污染/海盗/西北陆患）允许出现；异族势力可直白命名也可架空，均由院长创作时自定。
- 世界观仍为架空时间线（朝韩统一、四阵营并立即为架空设定），现实元素作为素材而非政治表达。
- **唯一保留底线**：群友真人相关的玩梗需本人过目 + 可随时退出（属真人权益，不是内容审查）。

## 七、内政-战斗联动（红警范式，二期核心卖点）

设计原则：**同一套设施数据，一期折算成结算数值，二期直接变成战场实体。**

| 内政建造 | 一期（数值结算）效果 | 二期（实时战场）实体形态（红警映射） |
|---|---|---|
| 城墙（等级） | 城防值上限、攻城回合数/减伤 | 环绕本阵的可破坏墙体 + 城门（突破点） |
| 军事基地 | 守军兵力上限、训练度加成 | 战场内"出兵建筑"：战损补充/援军刷出点；被拆=失去补兵能力 |
| 城防箭塔（基地附属） | 守方杀伤系数 | 自动射击的防御塔（红警哨戒炮逻辑） |
| 农田/商业中心 | 城内存粮/金（影响围城坚持时间） | 城外地表建筑，可被攻方掠夺（焦土压力，逼野战） |
| 娱乐中心 | 守军士气/忠诚 | 本阵附近士气光环 |
| 科技线节点 | 解锁兵种/结算系数 | 新兵种单位、建筑外观与攻击方式升级 |

- 攻方目标：拆城门 → 摧毁军事基地/本阵 = 占城（三国志 12 本阵攻防 + 红警拆家合体）
- 这要求一期引擎数据结构从第一天就把"设施等级/位置"建成战场可读的模型，不能写成两套数据。

### 7.4 军事体系方案（✅ 2026-10-22 院长拍板：路径 C + 轻量 RTS 交互定案）

**院长提出的矛盾**：原版即时战斗=开一局中盘红警。加料 → 战斗喧宾夺主，经营是主菜；不加料 → 与原版无差、无新意。

**破题原则**：主次之争的本质是"每场战斗强制投入多少操作"。料加在必经操作上（战中造兵、多线微操）必然抢戏；料加在**情境差异、角色技能、决策节奏**上则不增负担、有代差感。

**拍板方案（路径 C 修订版，战术牌层被院长否决，改为轻量 RTS 直感操控）：**

**① 战场情境层（差异来自经营，不来自操作量）**
- 每场仗的地形/可拆建筑/防御塔都由该城内政决定（§七映射表）：打军事基地满级的北京和打空城是两张图。
- 现代战争变量（呼应科技树，不加操作只加变量）：制信息权（卫星/星链/网络战影响视野）、无人装备（新单位类型而非新操作）、天网终局科技直接改战斗规则。
- 战斗类型分化：野战 / 攻城（拆墙破门）/ 平叛 / 异族海盗讨伐（特殊规则）/ 跨海登陆。

**② 轻量 RTS + 带队角色技能（新意收敛点，替代原"战术牌"提案）**
- 不做牌组化；保留 RTS 直感操控（选部队→下令）。
- 每支参战部队由一名武将率领，**武将各自拥有不同的可发动技能（招牌战法）**——这是与原版的核心差异点，也是群友玩梗的载体；技能消耗采配点数（原版费用机制，零新增系统）。
- 平 A/寻路/集火交给部队 AI，玩家只下移动/攻击/技能/撤退几类指令。

**③ 伪回合制（主动暂停，pause-and-command）**
- **右键部队 → 自动时停 → 弹指令选项（攻击/技能/撤退等）→ 指定目标 → 暂停解除**：军令下达的仪式感，"令行禁止"。
- **移动实时遥控**：选中部队后点击地板连续下达行军点，部队实时执行。
- **暂停按钮（全局部署模式）**：暂停中可一次性为全部部队规划行进路线（多 waypoint），点"继续"统一执行。
- 决策不赶时间，但画面与交火是实时的——兼顾策略从容感与 RTS 临场感。

**④ 自动/手动双档（一期全自动）**
- **一期全部自动档**：数值结算 + 文字战报，一套战斗判定模型跑通战略循环。
- 二期加手动档：同模型加渲染与指令层；不想手操的战斗仍可一键自动（院长原话"可以设置自动档"）。
- **一套战斗判定模型两档共用**，不写两遍。

**与红警的边界（防止滑向全面 RTS）**：只借"建筑实体化 + 防御塔 + 拆基地"三点；**不借战中造兵/造建筑**——兵力内政期编成、战场是定局对弈，单场 5~8 分钟结束。

**部队规模**：6~10 支部队/场（轻量上限，与暂停部署的操作量匹配）。

## 十、服务器承载评估（2026-10-22 白机实测）

### 10.1 生产机实测（SSH 只读查询，未改任何状态）

| 项 | 实测值 |
|---|---|
| 机型 | 阿里云 ECS `47.96.158.104` |
| CPU | 2 核 Intel Xeon Platinum |
| 内存 | 1.6 GiB 总量，**当前可用约 949 MB** |
| 磁盘 | 40 GB，已用 15 GB，剩 23 GB（39%） |
| 负载 | load average 0.13 / 0.03 / 0.01（基本空闲） |
| 在跑 | Express API（约 71 MB）、Colyseus game-server（约 41 MB）、PM2、宝塔面板 |

### 10.2 结论：支持，但必须坚持"浏览器权威"架构

**游戏运算全部在玩家浏览器本地执行，服务器不参与任何对局模拟**：

| 负载类型 | 放哪里 | 服务器是否承担 |
|---|---|---|
| 大地图实时 tick / 内政产出 | 浏览器 TS 引擎 | ❌ 不承担 |
| 二期实时战斗模拟（6~10 部队、碰撞、寻路、弹道） | 浏览器 Canvas | ❌ 不承担 |
| 算法 AI（三阵营内政军事决策） | 浏览器 | ❌ 不承担 |
| 存档 | 浏览器 LocalStorage/IndexedDB + JSON 导出 | ❌ 不承担 |
| 静态资源（JS/图片/立绘，gzip 后约数 MB） | Nginx 托管 | ✅ 极轻，20 人量级无压力 |
| 账号鉴权（可选，复用主站登录） | 现有 Express | ✅ 几个 API 请求 |
| 军师 LLM（一期可选） | **只转发**：服务器当 LLM API 代理（藏 key） | ✅ 每次军师提问 1 个出站请求，无状态，与男德通同类 |

- **为什么不能在服务器跑模拟**：1.6 GB 内存已用近半，每多一个常驻 Node 对局进程（哪怕 100~200 MB）都是硬挤；20 人同时在线理论上能挤，但完全没必要——单机游戏的计算天然属于客户端。
- **Nginx 配置注意**：对局纯前端不需要新端口；若复用主站登录，走现有 Express 加几条 `/api/guonanzhi/*` 路由即可。
- **LLM 代理成本**：军师只读 snapshot 生成建议，调用频率远低于男德通对话，沿用火山方舟 GLM，零新增订阅（符合成本纪律）。
- **磁盘**：23 GB 余量对静态资源绰绰有余；正式立绘走 `public/` 抠图资产管线，量可控。
- **未来验证点**：若院长以后想要"群友异步对战/排行榜"（需要服务端权威对局），当前机型不够，届时再评估——首版单机明确不做。

**一句话**：这台 2 核 2G 的机器对国男志而言只是"静态站 + 登录 + LLM 转发器"，余量充足；真正干活的是院长和群友自己的电脑。
