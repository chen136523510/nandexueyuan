## 一、核心结论（先看这个）

1. **三国志12 的骨架是"实时制+暂停"的轻量策略经营**：40 座都市、8 类内政设施、实时战斗（采配/战法/秘策）、外交与人才两条辅助线。系统结构清晰、数值公式可拆解，适合作为《国男志》的蓝本。
2. **内政的核心公式是"设施 × 武将 × 城型 × 都市技术"的乘法式产出**：市场收入、秘策点数消耗、战法系数等关键数值已拿到可复用的公式；但 40 城、数百武将、30+ 秘策的内容量对单人开发不可持续，必须大幅微缩。
3. **军事的核心是"兵种三角 + 采配资源 + 战法/秘策释放 + 本阵攻防"**：枪克骑克弓克枪；采配随时间积累；战法消耗 1~10 点；攻城器械与地形是主要变量；单挑是随机触发的卡牌小游戏。
4. **原版外交相对薄**：以钱/兵粮为筹码，声望、口才、心证（印象）影响成功率；折冲之策才解锁兵力/秘策/技法作为筹码。这个"薄"恰好是 LLM 的切入点——**LLM 负责对话与提案，规则引擎负责判定与边界**。
5. **人物系统是"四维 + 特技 + 战法 + 兵科适性 + 忠诚/相性 + 官爵/名品"**：群友武将化可以 1:1 映射；每人一个"招牌战法"比堆数值更有记忆点，也更适合社区梗。
6. **原版 AI 有明显短板，不要照抄**：内政自动分配低效、求人所不自动分配、出兵采用"约 2 倍兵力"的橡皮筋式补偿。人机内政/军事应自研启发式算法（边际收益分配、威胁图、机会评分），并把难度做成显式参数。
7. **推荐落地路径**：先做 Web 单机微缩版（12~16 城 / 30~50 将 / 6~10 支部队），保留实时+暂停；LLM 只接两个缝——外交谈判与军师建议，全部经 JSON Schema + 规则闸门校验，LLM 永远不直接改游戏状态。

## 二、总体框架与核心循环

### 2.1 基本盘（已确认）

| 项 | 内容 | 来源 |
|---|---|---|
| 发售 | 日本 2012-03-02；PC 中文版 2012-04-20；威力加强版（PK）2013 | 3DM 新闻 [39454]；游民星空 |
| 平台 | PC / PS3 / Wii U / PSV / PS4（各源表述略有差异） | 3DM；游民星空 |
| 模式 | 单机剧本 + 网络对战（对战版另发） | 游民星空《初玩上手指南》 |
| 剧本 | 7 个：184 黄巾之乱 / 190 反董卓联合 / 195 群雄割据 / 200 官渡之战 / 207 三顾之礼 / 214 益州平定 / 251 英雄集结（假想） | 快科技转译官网 |
| 都市 | 40 座 | 游民星空《全40个都市简易资料》+《全城市属性表》40 页城市列表 |
| 时间制 | 实时制 + 暂停；内政按时间推进，战斗实时进行 | 多篇攻略 |
| 胜利条件 | 消灭其他势力/统一天下；可劝降对方势力 | 多篇攻略 |

### 2.2 核心循环

```
内政生产（金/兵粮/兵力/技法/秘策）
  → 募兵与编成
  → 出征（仅邻接都市可进攻）
  → 野战/攻城（实时战斗）
  → 占城/俘虏/伤兵收编
  → 登用与培养武将
  → 扩大地盘 → 外交/秘策破局 → 统一
```

关键设计特征：

- **只有邻接都市才能进攻**（游民星空《原版种田心得》），因此地图连通性 = 战略纵深，"角落开局"是有效策略。
- **城池得失是兵力转移的主要方式**：攻城胜利后，城内兵力归胜方（游民星空《攻城和守城》），这使"以战养战"成为滚雪球机制。
- **实时+暂停**：玩家可以暂停下指令，AI 势力持续运行；这与"LLM 军师随时可问"天然契合。

## 三、内政系统

### 3.1 八类内政设施（已确认，来源：游民星空《全城市属性表》设施表头 + 高仍网《内政篇攻略》）

| 设施 | 主要作用 | 关键机制/数值 |
|---|---|---|
| 市场 | 产出金 | 收入改善 0~5 级；商才特技加成；商业都市 ×1.5 |
| 农园 | 产出兵粮 | 农业都市 ×1.5 |
| 兵舍 | 募兵、养兵 | 兵心特技加快伤兵恢复；兵舍等级影响募兵 |
| 制造所 | 生产兵器/攻城器械 | PK 有"量产技术"提升兵器生产率 |
| 计略府 | 防破坏 + 对邻接敌城搞破坏 | 军师特技每月降低邻城城防；鬼谋特技每月偷取邻城冲车/投石车；多个计略府效果可叠加 |
| 技法所 | 研究势力技法 | **同一城市必须建 2 个才能研究**；每次研究需 2 名满足条件的同城武将；研究者有几率提升智力/政治 |
| 求人所 | 探索、在野/俘虏登用、宝物搜寻 | **AI 不会自动分配求人所**（探索需要玩家判断） |
| 巡查局 | 声望、城防恢复、防俘虏逃脱 | 进驻任意武将立即 +40 声望（撤走即消失），此后每月 +1；补修/监视特技每月恢复城防、防俘虏逃 |

> 注：**外交不是设施**，是都市菜单里的行动（与三国志11不同），原版 8 类设施中没有外交府。

### 3.2 城型与产出倍率

来源：游民星空《全40个都市简易资料》城市解释 + 高仍网《内政篇攻略》+ 360 问答（低可信度项已标注）。

| 城型 | 效果 |
|---|---|
| 通常 | 基准 |
| 农业 | 兵粮产出 ×1.5 |
| 商业 | 市场收入 ×1.5 |
| 大都市 | 金收入 ×1.2；另有"募兵 +20%"说法（单一低可信来源，待验证） |
| 分断 | 士兵因不安而逃亡（负面城型） |

### 3.3 市场收入公式（单一来源，未交叉验证；来源：游民星空《市集收入介绍》，游侠论坛玩家实测）

```
单座市场月收入 =
  收入改善 + 民间支持
  + 将领进驻基本收入
  + 市场基本金收入 × 将领政治 × 系数
```

- 收入改善：0 级 50，每级 +50，5 级 300。
- 将领进驻基本收入：市场 1 级 75、2 级 100、3 级 125、4 级 150、5 级 175。
- 市场基本金收入：1 级 300、2 级 350、3 级 400、4 级 450、5 级 500。
- 系数：无商才 0.0116，有商才 0.01335。
- 商业都市：将领额外收入部分 ×1.5。
- 民间支持：与声望相关，但影响很小（声望 1000 时每级约 +28~30，9999 时约 +50）。
- 升级成本（文中口径）：市场 1→2 约 100，2→3 追加 500，3→4 追加 1000，4→5 追加 1800，满级累计约 5900。

**设计启示**：政治 70 无商才的武将，在 1 级市场月增收约 316；5 级约 581。但武将月薪约 300，回本要 2~3 年——所以原版最优解是"精英路线"：只登用政治 70+ 有商才/名士或政治 80+ 的武将，而不是人多就种田。这是"武将薪资 vs 单设施产出"的核心张力，值得在《国男志》保留。

### 3.4 募兵、兵力与伤兵

- **募兵**：兵舍产出；募兵量受总兵力、官爵、技法（义兵征集）、城型影响（360 问答摘要，低可信度，待验证）。
- **伤兵**：战斗损失不会全部死亡，一部分转为伤兵；恢复途径：
  - 兵舍 + 兵心特技（早期主力手段）；
  - 技法"伤兵复原"；
  - 战略秘策"用众之策"的兵心献策（瞬间恢复全部伤兵）；
  - 战役秘策"治愈之策"（战斗中大量回血）。
- **伤兵是滚雪球的关键**：攻城胜利后收编城内兵力/伤兵，连续作战能力取决于伤兵恢复速度。

### 3.5 城防、治安与声望

- **城防总量 800**，按百分比扣除；攻城方先把 800 打到 0 才能破城（游民星空《全40个都市简易资料》+《都市技术详解》）。
- 巡查局：补修/监视特技每月恢复城防、防俘虏逃脱；可抵消掠夺之策每月 -15% 城防的破坏（高仍网《内政篇攻略》）。
- 计略府 + 军师：每月削减邻接敌城城防（3 个月可把 100% 打到约 52%）。
- **声望**影响：官爵、俘虏忠诚下降率、外交态度、部分秘策效果；增加途径：巡查局、名士在市场/农田、胜仗、陈情、释放俘虏；**丢城 -50**。

### 3.6 都市技术（PK 新增，来源：游民星空《都市技术详解》1~4 页）

- 每城根据设施组合解锁"都市技术"，分 **5 大系统：特技 / 发展 / 兵种 / 防御 / 阻挠**。
- **每城最多 5 个都市技术**；全 40 城只有**成都**能点满全部技术。
- 解锁条件 = 指定设施种类 + 合计等级（例：虎豹骑育成 = 市场+兵舍合计等级 3 以上、制造所合计等级 2 以上；兵器技术 = 巡查局合计等级 2 以上）。
- 代表技术：
  - 兵种系：连弩研究（连弩兵）、虎豹骑育成；
  - 发展系：市场活性、军医育成、道路开发、防灾技术、强化保安；
  - 特技系：水练（全城武将获得水军适性）、远射技能；
  - 防御系：筑城术、筑城术极（建业，城门/阵耐久大幅提升）、保安强化、兵法阵看破；
  - 阻挠系：妨碍筑城（云南，敌城防 800→576）、妨碍出阵（削减敌方预备兵）。
- **城市图标大小反映发展度**：技术多的洛阳图标大，边境小城图标小。

### 3.7 技法与官爵

- **技法**是势力级科技：研究在技法所（同城 2 座 + 2 名武将），可提升收入、兵器生产、外交等；每个势力有独有技法（例：曹操"屯田制"增加兵粮）。
- **官爵**：需要拿到**州都**才能开始升官（游民星空《原版种田心得》）；官爵提升武将能力、带兵量，并一次性大幅提升忠诚——对新招降武将比加薪更划算。官爵表原页为图片，具体阶梯数值未取得文本（待补）。
- **名品**：宝物可提升能力/特技（全名品图鉴存在，具体清单未展开）。

### 3.8 内政节奏（原版玩家经验，可作为 AI 启发式参考）

来源：游民星空《原版种田心得》。

- 开局：求人/兵舍/计略各 1，其余全市场；优先把市场升到 3 级（性价比拐点）；农园前期靠初始即可。
- 前线：巡查 + 计略 + 求人；后方：普通/农业城全市场或兵营，商业城全市场，大都市全兵营。
- 战略：守住前线 → 停战/同盟 → 专心打一家 → 打到"角落"获得安稳后方。
- 破局：绝道之策 + 投石砸门 + 虚诱掩杀/挑发拉出守军 + 主力敲本阵。

## 四、军事系统

### 4.1 战斗流程

来源：多篇攻略综合（游民星空《攻城和守城》《种田心得》《秘策系统心得》等）。

1. **出征**：只能从邻接都市出兵；选择武将、兵力、兵种、攻城器械、军粮；可请求援军。
2. **战场**：一般为 3 条路线；双方各有**本阵**；有据点/城墙/城门；限时。
3. **采配**：战斗中随时间积累"采配"点数，用于释放战法（1~10 点）与战役秘策。
4. **胜负**：击破敌方本阵、全灭敌军、或时间到按剩余兵力判定；守方还可偷营（绕路打攻方本阵）。
5. **战后**：胜方收编城内兵力；败方武将可能被俘；伤兵进入恢复池。
6. **AI 出兵补偿**：玩家以 N 兵进攻时，守方会出动约 2N 兵（含其他城援军，不含盟友援军）——原版橡皮筋机制（游民星空《攻城和守城》，单一来源）。

### 4.2 兵种与相克

来源：游民星空《全兵种资料》+《暴击规律性》。

| 兵种 | 定位 | 相克 |
|---|---|---|
| 枪兵 | 抗骑、攻城破坏力尚可、可间接攻击（溅射） | 克骑兵 |
| 骑兵 | 高机动、野战之王、攻城破坏力低 | 克弓兵 |
| 弓兵 | 远程 DPS 主力、守城核心 | 克枪兵 |
| 冲车 | 攻城器械，破城门 | 被所有兵种克制；枪兵"破坏力"对其伤害较高 |
| 投石车 | 远程攻城器械 | 同上 |

- 三角关系：**枪 → 骑 → 弓 → 枪**。
- 特殊攻击：枪兵"奋迅"、骑兵"突击"、弓兵"强射"；对克制兵种或拥有"豪杰"特技时可发动。
- **攻击间隔 0.5 秒**；持续交战约 **15 秒**触发特殊暴击（枪兵约晚 1 秒）；中途脱离交战 3 秒以上会重置计时（玩家总结"十秒脱战原则"）。
- 暴击伤害随武力差放大：武力 10 与武力 90 伤害约差一倍。
- **勇猛**只影响单挑概率，不影响暴击率。
- 兵种数值表原页为图片，具体攻击/防御/机动数值未取得文本（待补）。
- PK 追加 13 个新兵种与"装备"概念（360 问答摘要，低可信度，待验证）。

### 4.4 秘策（战略/战役两层）

来源：游民星空《秘策系统使用心得》《战略秘策的特殊献策效果》《秘策消耗点数整理》《所有秘策献策效果汇总》。

**秘策分两类：**

- **战略秘策**（大地图层）：作用于邻接城市/全局，需要 3 名高政治武将开发，发动消耗"秘策点数"。
- **战役秘策**（战斗层）：由"参军"携带，战斗中释放。

**战略秘策（点数基准值 A，0 智力无军师）：**

| 秘策 | A | 主要效果 | 特殊献策 |
|---|---:|---|---|
| 求贤之策 | 700 | 全国范围登用在野武将 | 人脉：全国搜索并登用 1 名 |
| 求财之策 | 450 | 每回合获得金/兵粮/兵力，名声加成 | 名士：提升己方武将忠诚 |
| 占粮之策 | 300 | 不付俸禄，俸禄转为军粮 | 商才：一半金钱 1:1 转兵粮 |
| 折冲之策 | 450 | 外交可用兵力/秘策/技法作筹码 | 辩舌：所有势力心证变 100 |
| 缩地之策 | 600 | 输送/移动 1 回合到达 | 神速：输送不耗兵粮 |
| 用众之策 | 800 | 武将指挥兵力倍增 | 兵心：立即恢复全部伤兵 |
| 名工之策 | 500 | 设施升级省钱省时 | — |
| 离间之策 | 750 | 降低邻接敌城收入与武将忠诚 | 鬼谋：登用邻接势力 1 名武将 |
| 收夺之策 | 400 | 夺取邻接敌城金/兵粮/兵力 | 一骑：降低邻城防御 |
| 封印之策 | 450 | 停止邻接敌势力秘策开发/发动 | 鬼谋：中止对方正在开发的秘策 |
| 绝道之策 | 650 | 封锁邻接敌城出征与援军请求（援军上限 3000/队） | 监视：邻城兵力 -10% |
| 毒泉之策 | 400 | （未展开） | — |
| 乌合之策 | 600 | 弱化守军（AI 常用） | — |
| 忘技之策 | 0 | （未展开） | — |
| 封都之策 | 450 | （未展开） | — |

**战役秘策（A 值）：** 远望 200、鼓舞 280、禁出 200、禁归 200、伏兵 300、援兵 220、归阵 220、无策 280、连环 280、空城 280、伪报 250、穴攻 250、采配 300、治愈 280、捕掳 280。

**秘策点数消耗公式（单一来源，未交叉验证）：**

```
P = A - floor(智力/2) - 3 × (智力 - 80) - 50
```

- 其中 `智力 > 79` 时第三项生效；武将有"军师"特技时再 -50。
- 例：智力 84 的军师蒋琬发动求贤 = 700 - 42 - 12 - 50 = 596。

**献策机制**：秘策发动后出现"献策"按钮，随机武将（优选举荐高能力者），花费金钱延长持续时间或增强效果；成功率以圆圈数表示，能力越高/花费越多成功率越高。

### 4.5 攻城与守城

- 城防 800，按百分比扣除；冲车/投石车从城内库存取出使用（城市面板有"冲车、投石"数量）。
- 攻城：破城门 → 进城内打本阵；守方可在城头用弓兵输出。
- 守城：利用城墙（枪兵在城墙上攻击 -30%）、城门堵口、弓兵城头输出；也可主动出城野战。
- **以少胜多技巧**（玩家经验，单一来源）：带 6000 兵进攻，AI 只出约 1.3 万；用高智力火计/大打击连放清场；守城时用 1000 人诱敌 + 主力偷本阵。
- 本阵很脆弱：3000 人的弓兵名将也能在较短时间内射穿十万人的本阵——这是"偷营"战术的基础。

### 4.6 地形

来源：游民星空《地形对兵种影响》。

| 地形 | 效果 |
|---|---|
| 森林 | 除枪兵外行动力下降；弓兵/投石攻击力约 -30%，不能发动特殊攻击 |
| 浅滩 | 所有部队行动力下降（水练特技除外） |
| 栈道 | 所有部队攻击/防御减半、行动力下降（普通桥梁不算） |
| 城墙 | 枪兵攻击力约 -30%（因在城墙上属"间接攻击"） |

### 4.7 单挑

来源：游民星空《单挑详解》。

- 触发：两队交战时随机触发，不可主动发起；骑兵参与时概率更高；高级难度触发率低（每场最多约 1 次）。
- 规则：卡牌"天/地/人"，天克地、地克人、人克天；每回合可出同种类多张；5 回合后按 HP 槽判定。
- 卡牌点数：武力越高/武力差越大，单张点数越高，最大 9。
- 结果：HP 未打光 = 失败（部队混乱、攻防下降）；HP 打光 = 溃败（部队兵力消失、溃走）。
- 特技"一骑"提高必杀/反击入手率；"勇猛"影响单挑触发概率。

### 4.8 战斗操作要点（原版经验）

- 数字键 1~6 对应部队，实时微操；网战不能暂停。
- 采配攒到关键点再放战法；对方冲脸时用"采配之策"抢节奏。
- 伏兵、挑衅、虚诱掩杀是拉扯 AI 的核心手段；连环可防止敌军回防。

## 五、外交系统

来源：3DM 转译官网《外交系统中文介绍》、游民星空同源报道、52PK《劝降方法》、861 资源网《同盟解除》、360 问答摘要。

### 5.1 基本机制

- **派遣武将**提出外交；以**钱、兵粮**为条件交涉。
- **声望/名气**越高，交涉越有利。
- **口才**特技：可进行"持久的交涉"（延长谈判回合/提高成功率）。
- **心证（印象）**：外交选项有门槛，心证不到一定程度无法选择某些项目。
- **折冲之策**：解锁后可用**兵力、秘策、技法**作为交涉材料；其"辩舌"献策可让所有势力心证变 100。
- **交涉之策**：提高所有势力友好度，也可交换秘策/技法。

### 5.2 外交项目（已确认存在，细节可靠性不一）

| 项目 | 说明 | 可靠性 |
|---|---|---|
| 同盟 | 相互不攻击、避免被夹击；默认约 2 年后自动解除（单一低可信来源） | 中/低 |
| 停战 | 短期停火 | 中 |
| 共同军/邀请盟友 | 请求盟友出兵/共同作战 | 中 |
| 劝降 | 邻接兵力 ≥ 对方全势力总兵力约 10 倍时，派高政治武将/君主劝降可成功；心证不影响该判定（玩家实测，单一来源） | 低 |
| 破弃/解除同盟 | 无直接解除按钮；到期自动解除，或通过敌对行为促使破裂（低可信来源） | 低 |

### 5.3 外交的设计特征

- 原版外交的**判定层很薄**（钱粮+声望+口才+心证），**表达层几乎没有**——只有固定台词和选项。
- 这正是 LLM 的切入点：让 AI 势力根据性格、利益、关系值"说出来"，但**是否成交仍由规则引擎按数值判定**，避免 LLM 破坏平衡。

## 八、原版 AI 行为观察（供算法设计参考）

> 说明：以下为玩家攻略中可观察到的行为，不是官方 AI 文档；原版 AI 内部算法未公开。

## 九、对《国男志》的设计映射建议

### 9.1 微缩规模建议

|---|---:|---:|---|

| 武将 | 400+（测试版 444） | 30~50（群友 20 + NPC） | 内容可控；群友是核心卖点 |
| 内政设施 | 8 类 | 6~8 类（可全保留） | 设施是内政乐趣核心，成本不高 |
| 兵种 | 枪/骑/弓 + 冲车/投石 | 保留 3+2 | 三角关系是战斗骨架 |
| 战法 | 数十个 | 20~30 个 | 够用且可平衡 |
| 秘策 | 30+ | 8~12 个核心 | 砍长尾，保留绝道/求财/求贤/名工/用众/无策/援兵/伏兵 |
| 外交项目 | 同盟/停战/共同军/劝降/破弃 | 全保留 | LLM 的主要舞台 |
| 单局时长 | 数十小时 | 3~6 小时（目标） | 社区娱乐节奏 |
| 部队数 | 6~10 支/场 | 6~10 支/场 | 实时微操上限 |

### 9.2 人机 AI：内政与军事用算法

**内政 AI（每城独立评估 + 全局预算）：**

```
每 N 个 tick：
  1. 计算每座城的边际收益：
     - 市场/农园的产出增量 ÷ 升级成本
     - 兵舍的兵力增量 ÷ 成本（按威胁加权）
     - 技法/秘策的长期收益
  2. 按"边际收益/成本"排序，在预算内分配升级与武将
  3. 用城市模板约束：
     前线城 = 兵舍 + 计略 + 巡查；后方城 = 市场/农园；商业城 = 市场；农业城 = 农园；大都市 = 兵舍
  4. 每 K 回合重评（避免每 tick 抖动）
```

- 关键参数：预算比例、前线/后方判定阈值、武将政治权重、难度资源系数。
- 可解释性：每个决策记录"因为 城市X 市场边际收益 3.2 > 兵舍 2.8"——方便调试和给玩家看 AI 逻辑。

**军事 AI（威胁图 + 机会评分）：**

```
每 N 个 tick：
  1. 威胁图：对每个邻接敌城计算 (敌军兵力 - 我军守备) × 距离权重
  2. 机会评分：目标城价值 × (1 - 防御/800) × 兵力优势 × 外交风险
  3. 出兵决策：机会评分 > 阈值 且 守备充足 → 出征
  4. 援军调度：邻城守备富余 → 支援受威胁城
  5. 战斗内 AI：
     - 目标优先级：本阵 > 落单部队 > 城门/城墙
     - 战法释放：采配 ≥ 战法消耗 且 目标密度/血量满足条件
     - 撤退：兵力低于阈值 或 本阵受威胁
```

- 难度档：资源系数（0.8/1.0/1.2）、侵略性（出兵阈值）、反应延迟（ticks）、战法释放频率。
- 不做"2 倍兵力"作弊；用参数化难度替代。

### 9.3 LLM 的两个接缝：外交 + 军师

**总架构：**

```
确定性游戏引擎（唯一状态源）
   ├── 算法 AI（内政/军事）→ 命令
   ├── 外交系统
   │     ├── 规则层：关系值/利益/筹码 → 是否接受、成交条件（唯一判定）
   │     └── LLM 层：生成谈判文本/提案措辞/人物语气（不判定）
   └── 军师系统
         └── LLM：读 snapshot → 建议 + 理由 + 引用数据（只读）
                ↓
        JSON Schema 校验 → 规则闸门 → 合法命令/纯文本建议
```

**外交 LLM 设计要点：**

- 输入：双方势力状态、关系值、历史恩怨、当前筹码、对方君主性格（结构化字段）。
- 输出：`{ stance: accept/reject/counter, terms: {...}, dialogue: "..." }`。
- **规则闸门**：校验筹码是否存在、是否超预算、是否违反同盟/停战期限、是否符合人物性格红线；不合法直接回退到模板话术。
- LLM 不可见隐藏信息（战争迷雾、对方未公开的兵力）。
- 失败回退：模板化外交台词 + 规则判定；LLM 超时不影响游戏。
- 成本：只在玩家发起外交/对方提出外交时调用；缓存常见场景话术；按项目成本纪律控制频次。

**军师 LLM 设计要点：**

- 输入 snapshot：城市/兵力/资源/外交/威胁/秘策状态（可复用 nono 的 snapshot 思路，见 `prd/01-需求文档/07-自习室/诺诺感官架构设计.md` 的 snapshot 设计）。
- 输出：建议列表（建设/出兵/外交/秘策时机）+ 理由 + 引用的具体数字。
- **只读**：军师不能直接改状态；玩家点击"采纳"才执行命令。
- 军师可有人格/立场（例如某位群友担任军师），但建议必须基于 snapshot 数据，禁止编造不存在的兵力/城市。
- 反幻觉：所有数字由引擎注入，LLM 只做解释与排序；输出经 schema 校验；无数据时明确说"情报不足"。
- 游戏内效果：可把"军师"做成一个可任命职位，提供情报摘要/建议次数，与"军师"特技（延长秘策）区分。

### 9.4 人物设计（群友武将化）

- 四维 + 2~4 特技 + 1 招牌战法 + 1 句人设台词。
- 平衡：总点数预算（例如四维总和 260~320），避免"人人 90+"。
- 战法命名与效果分离：名字可以玩梗，效果必须落在统一模板里（伤害/增益/弱化/恢复）。
- 立绘：可复用现有 AI 出图管线；风格统一；黑机出图、白机不入图片资产（遵守 AGENTS 美术纪律）。
- **授权**：真人角色需本人同意；提供"退出/删除"机制；不使用真实隐私/负面信息；参考 R-054 内容红线。

### 9.5 技术选型

| 方案 | 优势 | 劣势 | 适用 |
|---|---|---|---|
| **Web（Vue 3 + TS + Canvas/PixiJS）** | 与主站/账号/群友数据天然集成；UI 开发快；白机可开发；部署简单 | 3D 战场弱；大量单位性能需优化 | **首版推荐** |
| Unity 2022.3 | 3D 战场/动画资产复用（nono 经验）；表现力强 | UI 开发慢；双机 merge 冲突；包体分发；编辑器依赖黑机 | 后续 3D 化/独立客户端 |

- 首版建议：**Web 单机 + JSON 数据驱动 + 纯 TS 引擎（可单测）**；战斗用 2D 俯视/Canvas，保留实时+暂停。
- 数据结构：`cities.json` / `officers.json` / `tactics.json` / `policies.json` / `events.json`；存档 JSON；引擎与 UI 分离。
- 若后续要 3D 战斗，再评估 Unity 迁移；不要首版就上 3D。

### 9.6 可直接借鉴的数值清单

| 数值 | 原版 | 借鉴方式 |
|---|---|---|
| 城防 | 800，按百分比扣 | 直接采用；攻城器械/秘策按百分比削减 |
| 市场产出 | 基础 300~500 + 收入改善 50~300 + 政治×0.0116~0.01335 | 缩小数量级后采用；保留"薪资 vs 产出"张力 |
| 秘策消耗 | P = A - 智力/2 - 3×(智力-80) - 军师 50 | 直接采用公式结构，A 值按秘策数量重设 |
| 战法采配 | 1~10 点 | 直接采用；按战法强度分档 |
| 特殊暴击 | 0.5s 攻速，约 15s 触发，武力差放大 | 可简化（如 10s 触发），保留"持续交战"概念 |
| 城型倍率 | 农业 1.5 / 商业 1.5 / 大都市 1.2 | 直接采用 |
| 都市技术 | 5 系统、每城最多 5 个、设施等级解锁 | 微缩为每城 1~3 个技术 |
| 劝降 | 邻接兵力约 10 倍 | 改为"兵力优势 × 政治 × 声望"综合判定（原版过于粗暴） |
| 同盟 | 约 2 年自动到期 | 采用固定期限 + 可续约，避免无限同盟 |

> 标注：市场公式、秘策点数公式、劝降 10 倍、同盟 2 年、战法系数均为**单一来源**，建议在《国男志》中用自洽数值重设，不追求 1:1 复刻。

### 9.7 不建议照搬的点

1. **40 城 / 400+ 武将的内容量**——单人不可持续，且会稀释群友角色的存在感。
2. **"2 倍兵力"橡皮筋 AI**——体验差；用显式难度参数替代。
3. **内政自动分配的糟糕 AI**——自研边际收益算法。
4. **30+ 秘策 / 13 新兵种 / 名品收集的长尾**——首版砍到核心。
5. **单挑作为核心系统**——可保留为可选小游戏，不做主玩法。
6. **网络对战**——首版单机，避免重蹈"多人同步拖垮项目"的覆辙。
7. **纯数值堆叠的武将设计**——群友角色应有记忆点（招牌战法/台词/特技），而非四维竞赛。
