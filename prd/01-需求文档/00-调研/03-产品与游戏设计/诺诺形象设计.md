## 一、人设核心（院长 5 条属性 + AI 补充）

| # | 属性 | 值 |
|---|---|---|

### AI 补充设定（自由发挥部分，院长可否决）

| 项 | 设定 | 理由 |
|---|---|---|
| 记忆点 | **左眼下泪痣** + 微垂眼 + 长睫毛 | 清冷系的"一眼识别"符号；泪痣在直播镜头特写下极具记忆点（美学基础§2.6"氛围感利器"） |
| 气质锚点 | GBC 海老塚智（垂眼贝斯手）的疏离感 × MyGO 素世的黑长直冷感面 | 番剧审美对标内的高挑冷感代表 |
| 声音暗示 | 低语速、清亮偏冷的女声，语尾不拖音（TTS 选型参考，定版轮验证） | 外冷内热的声音层表达：毒舌用平调，温柔场景语速放慢而非音调变甜 |
| 肢体语言 | 待机=双手交叠/单手撩发；高好感专属=转头回避+指尖卷发（傲娇动作） | 3D 骨骼动画阶段用；VRM 标准骨骼+three-vrm 均可支持 |
| 直播行为映射 | 低好感=简短回复+吐槽；高好感=主动关心+嘴硬式温柔（"才不是担心你，只是顺手"） | 性格→文案层映射，供对话系统 prompt 设计参考 |

**名字**：诺诺（已定）。直播间昵称/自称待定版轮。

## 二、外形参数定稿

> 数值依据《VRoid捏模参数手册》方向 B 档+高挑/贫乳修正。精确滑杆操作见捏模指导单。

### 2.1 身材（高挑+贫乳）

| 部位 | 设定 | 对应参数方向 |
|---|---|---|
| 身高 | **165cm**（VRoid 高挑档；蒂法 167 为天花板参照） | Height + |
| 头身比 | **7~7.5 头身**（成年写实女性区间=高挑感来源） | Head Size -10 配合身高 |
| 腿 | 腿长拉满比例感（腿长≥身高 1/2） | Leg Length +15 |
| 胸 | **贫乳**（Chest/Bust -30~-40） | — |
| 腰 | 细腰（配合贫乳形成"鹤"感长线条，不追求沙漏） | Waist - |
| 肩 | 窄肩 -10（高挑+窄肩=清冷挺拔） | Shoulder - |
| 颈 | 天鹅颈微长 +10（长直发的展示台） | Neck + |
| 体型 | 瘦（体脂 -10~-15），肌肉 0 | — |

### 2.2 脸（清冷毒舌系·方向 B 档）

| 部位 | 设定 |
|---|---|
| 脸型 | 长脸 +15、脸颊收窄 -20~-25、下巴收窄 -30~-40、下颌缘清晰（蒂法结构档：圆颏基础上取清晰下颌缘，不跨向方颏） |
| 眼 | 眼大小 -30（写实向）、**眼位回正偏高**、眼距窄 -5~-10、**眼轴微垂**（垂眼=疏离清冷；非上挑小恶魔）、双眼皮褶窄、长睫毛 |
| 眉 | 细长**平直眉**微降（弯眉温柔/平眉冷感）、眉眼距窄 |
| 鼻 | 鼻梁 +15~+20、鼻翼收窄、鼻尖挺直 |
| 唇 | 薄唇 -20~-25、**嘴角默认平**（不做常驻微笑）、唇色淡豆沙 |
| 肤 | 冷白调、**腮红关闭或极淡**（清冷系大忌重腮红） |
| 记忆点 | 左眼下泪痣 1 颗（Face Paint 层） |

### 2.3 发型（多发型体系）

| 发型 | 用途 | VRoid 实现方式 |
|---|---|---|
| 披发（默认） | 直播常态 | 长直发预设 |
| 高马尾 | 活跃场景/游戏环节 | 发束选中+扎起（预留） |
| 低马尾 | 正式场合/读信环节 | 同上（蒂法同款位置） |
| 侧马尾/半扎 | 差分补充 | 同上 |

- 颜色**暂定深蓝黑**（Texture 层可改，不锁死；暖色系与清冷人设冲突，冷调为安全区）
- 刘海：**中分或侧分露额头**（露额=清冷自信；齐刘海=幼态，否决）
- 发梢：直发微内收，不打卷

### 2.4 服装（初始定版 1 套，差分后续）

初始套装「学院知性风」：深色高领打底+衬衫马甲+长裙（或长裤）+乐福鞋——清冷知性，与"男德学院"世界观兼容。服装差分（家居服/节目特典）待定版轮与院长过目后出。

## 三、好感度 × 表情体系（外冷内热的实现）

| 好感度段 | 神态基调 | VRM 表情实现 |
|---|---|---|
| 低（0~30） | 默认脸=微垂眼+平嘴角；JOY 也只到"嘴角微弯" | NEUTRAL 定制为主，标准表情幅度调小 |
| 中（30~70） | 偶尔真笑；被戳穿温柔时**转头+脸红**（傲娇名场面） | JOY 正常幅度+BLUSH blendshape |
| 高（70+） | 眼神软化（下睑微抬）、真笑+泪痣同框特写 | 定制 SOFT 表情（表情编辑器） |

- 表情编辑器定制原则：**默认脸绝不带笑**（清冷人设的底线）；所有"温柔"必须靠场景解锁，这是傲娇感的技術实现。
- 脸红（blush）强度与好感度挂钩由 three-vrm 运行时控制，不在建模层定死。

## 四、验收基线（捏完自检→院长过目）

1. 正脸：三庭五眼成立、眼距窄但不挤、泪痣在位
2. 3/4 侧：鼻梁立体、下颌线干净、长发垂坠自然
3. 正侧：四高三低（额-鼻尖-唇珠-下巴尖；山根-人中沟-颏唇沟）
4. 全身：7 头身±0.5、高挑感（腿长/身高比）、贫乳确认
5. 表情五件套（NEUTRAL/FUN/JOY/ANGRY/SORROW）不穿模
6. VRM 导出试渲染复查（MToon 下的实际观感，VRoid 预览≠渲染端）
