# 项目管理（PM）

> 本目录存放**项目管理类**文件，与 `prd/`（产品定义）严格分离。
> AI 新会话接手时，本目录的 ROADMAP.md 是**第二份必读文件**（第一份是 `.ai/handoff.md`）。

---

## 文件索引

| 文件 | 用途 | 更新频率 |
|---|---|---|
| [ROADMAP.md](./ROADMAP.md) | 战略级路线图（里程碑/山丘图/假设簿/完成记录） | 里程碑状态变化时 |
| [需求池.md](./需求池.md) | 全局需求池（R-XXX 编号，待开发/已完成） | 需求新增/完成时 |

## 与 prd/ 的边界

| 目录 | 定位 | 内容 |
|---|---|---|
| `pm/` | **项目管理** | 路线图、需求池、进度跟踪 |
| `prd/` | **产品定义** | 世界观、需求文档、ADR、技术架构、开发规范 |

| 文件 | 废弃原因 | 替代 |
|---|---|---|
| `项目进度.md` | 内容过时，职能被 ROADMAP.md + 需求池.md 取代 | ROADMAP.md |
