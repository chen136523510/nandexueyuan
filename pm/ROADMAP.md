## 路线图管理规则

### 山丘图标注（Hill Chart）

每个任务标注状态，AI 接手时据此判断行为：

| 标注 | 含义 | AI 行为约束 |
|---|---|---|
| ⛰️ uphill | 探索中，方案未定 | **禁止直接写代码**，先做 PoC/调研/方案验证 |
| ⛰️ downhill | 方案已定，可预估 | 可直接执行，按步骤清单推进 |
| ✅ done | 已完成 | 记录完成日期，不再修改 |

### 假设登记簿

每个里程碑的关键假设必须登记，标注验证状态。AI 在 uphill 假设未验证前**不得**在其上铺代码。

### 节点完成记录

每个里程碑/节点完成时，在该节点下方追加：

```
> 完成日期：YYYY-MM-DD
> 完成内容：简述
> 产出物：commit 号 / 文件 / 部署版本
```

## 当前阶段：德塔形态重构（横版像素 -> 等距俯视手绘风）

**战略方向**：从泰拉瑞亚式横版像素风，重构为饥荒式展示形态（等距俯视角 + 环境氛围叙事 + 手绘暗黑童话美术风）。

**决策依据**：ADR-005 预留的 2D 俯视角升级路径，院长 2026-07-27 确认方向。

**关键决策门**：M-1（等距 PoC）和 M-2（美术 PoC）是 go/no-go 节点，失败则回退/降级。
