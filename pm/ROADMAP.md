## 路线图管理规则

### 山丘图标注（Hill Chart）

每个任务标注状态，AI 接手时据此判断行为：

| 标注 | 含义 | AI 行为约束 |
|---|---|---|
| ⛰️ uphill | 探索中，方案未定 | **禁止直接写代码**，先做 PoC/调研/方案验证 |
| ⛰️ downhill | 方案已定，可预估 | 可直接执行，按步骤清单推进 |
| ✅ done | 已完成 | 记录完成日期，不再修改 |

### 假设登记簿

每个里程碑的关键假设必须登记，标注验证状态。AI 在 uphill 假设未验证前**不得**在其上铺代码。

### 节点完成记录

每个里程碑/节点完成时，在该节点下方追加：

```
> 完成日期：YYYY-MM-DD
> 完成内容：简述
> 产出物：commit 号 / 文件 / 部署版本
```

## 当前阶段：德塔 视觉小说 重构

**战略方向**：废弃原 2D 动作/俯视游戏方向，基于原世界观重构为 视觉小说（叙事驱动、立绘+背景+对话文本、分支世界线）。

**决策依据**：院长 2026-07-29 确认。世界观设定集 v1.3 足够庞大，适合叙事驱动；视觉小说 核心三件套（立绘+背景+对话）已有 AI 出图管线支撑；战斗数值/HUD/多人同步等俯视游戏基础设施工作量过大且无法展现世界观深度。

**引擎选型**：Vue 3 Web 自研（ADR-006），网站 `/nde` 路由直接进入，与社区功能无缝集成。

**保留资产**：世界观设定集 v1.3、5 角色形象设计文档、AI 出图精选资产（睿/杰/丘）、ComfyUI 出图管线、Express+Prisma 后端。

**并行线**：R-058 诺诺·自习室（3D 虚拟直播间）自 2026-09-20 起为活跃开发线，与视觉小说线并行独立，见下方「并行线：R-058 诺诺·自习室」节。
